# Agent / AI instructions (TravelTrust)

## Deployment phases (always apply)

Work is ordered in **three phases**. **Finish what the current phase means before claiming the next.** **Do not skip phases.**

| Phase | Typical scope |
|-------|----------------|
| **① Local** | Dev machine / Docker; unit tests, `cargo test`, Vitest, optional local E2E. |
| **② Testnet** | Test hosts, test DB, Stripe test mode, staging-like callbacks/gateway. |
| **③ Public / production** | Production PSP, public webhooks, mainnet / real funds, `go-live`, **Production GO** — **separate gates**. |

**Do not** present **① or ②** results as **③** unless the user explicitly asks to verify **③** in this session.
