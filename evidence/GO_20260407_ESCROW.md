## 2. 不变量（出现 / 不出现）

以下均要求 **`data_source == "chain_read"`** 且 **`is_chain_ssot == true`**（若三键出现）；**禁止**用 DB **`order.state`**、订单金额字段或人工裁决记录**推导**或**回填**缺失键。

### 2.1 `escrow_chain_state*`

- **出现**：**仅当** **`RPC` + `ESCROW_FACTORY_ADDRESS`** 就绪且 **`chain::get_escrow_status` → `Ok(Some(_))`**。
- **不出现**：**`Ok(None)`**、**`Err`**、未配置链 — **不出现三键**（不写 **0**、空串、**`false`** 占位）。

### 2.2 `escrow_release_state*`

- **出现**：**仅当**链上 **`Escrow.status()`** ∈ **`Completed` / `Refunded` / `Resolved` / `PartiallyRefunded` / `Slashed`**（放款类终态）。
- **不出现**：**`Created` / `Funded` / `Disputed` / `None`** 等**未**入放款终态 — **不得**出现三键。

### 2.3 `escrow_dispute_state*`

- **出现**：**仅当**链上 **`Escrow.status()`** ∈ **`Disputed` / `Resolved`**（争议生命周期）。
- **不出现**：**其它**链上态 — **不得**出现三键。

### 2.4 `escrow_locked_amount*`

- **出现**：**仅当** **`factory.escrowOf(orderId)`** 指向**有效** Escrow、**`Escrow.token()`** **非零地址**、**`ERC20.balanceOf(escrow) > 0`**；**`escrow_locked_amount`** 为规范 **`0x` + 64 位 uint256 hex**（与 **`chain::balance_read::eth_call_erc20_balance_of_u256_hex`** 输出同源）。
- **不出现**：零余额、无 Escrow、**token** 零地址、RPC 失败 — **不得**出现三键（**不**写 **0**）。

**单测信封排除**（列表/占位不得带上述任一键）：**TT-ESCROW-SSOT-ORDER-STATE-AGGREGATE-EXCLUDE-002**（`crates/api/src/routes/orders/mod.rs`）。
