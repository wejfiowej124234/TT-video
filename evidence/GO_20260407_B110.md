## 1. 覆盖范围（四根级链上主读）

| 根级字段族 | 环境闸（示例） | 链上锚（摘要） |
|------------|----------------|----------------|
| **`pool_balance`**（与整行 **`data_source` / `is_chain_ssot`** 同响应） | **`GOVERNANCE_POOL_BALANCE_CHAIN_SSOT`** | FeeRouter 相关 SSOT 读（见 **04**） |
| **`country_pool*`** | **`GOVERNANCE_COUNTRY_POOL_BALANCE_CHAIN_SSOT`** | RegionVault **`balanceOf`**（SSOT 代币 **`GOVERNANCE_POOL_SSOT_TOKEN_ADDRESS`**） |
| **`treasury_pool*`**（原生 Wei） | **`GOVERNANCE_TREASURY_POOL_BALANCE_CHAIN_SSOT`** | **`eth_getBalance(GovernanceTreasury)`** |
| **`treasury_erc20_pool*`** | **`GOVERNANCE_TREASURY_ERC20_POOL_BALANCE_CHAIN_SSOT`** | **`ERC20.balanceOf(GovernanceTreasury)`**（**`GOVERNANCE_TREASURY_SSOT_TOKEN_ADDRESS`**） |

四门闸 **相互独立**；开闸后仍须 **RPC + ChainConfig + 各闸所需地址** 齐全，否则 API **不**写对应根级主读三键（或按 **04** 降级），见 **[Runbook §7.1](../ops/RUNBOOK.md)** 族叙述。

## 2. 不变量声明（审计须核对）

1. **SSOT 呈现**  
   链上主读成功时，对应根级族须满足：**`*_data_source == "chain_read"`** 且 **`*_is_chain_ssot == true`**（**`pool_balance`** 路径下为响应根级 **`data_source` / `is_chain_ssot`** 与 **04** 一致，见实现与 **04** 大表）。

2. **Σ 与主读隔离**  
   **`GET …/governance/fee-pool-aggregates`**（**B-084 Σ**）响应根级 **永不** 出现 **`country_pool*`**、**`treasury_pool*`**、**`treasury_erc20_pool*`**。**`pool_balance`** 非 **Σ** 体字段；聚合仅 **`fee_router` / `region_vault`** 投影树。

3. **失败语义**  
   链上读失败或关闸时：**不得**用 **`0`** 或无依据数值 **冒充** 链上主读；**不得**用 **Σ** 结果 **fallback** 顶替根级链上 SSOT。失败路径下根级主读键 **缺失** 或按 **04** 明确降级（与代码及 **04** 一致）。

4. **观测腿**  
   **`chain_alignment_hint.ssot_parallel_chain_snapshot`** 内字段为 **并行观测**，**`is_chain_ssot`** 为 **false**；**不得**与根级 **`country_pool*`** / **`treasury_pool*`** / **`treasury_erc20_pool*`** 混名混读。

## 3. 验证方式

### 3.1 自动化测试（必选）

在仓库根目录执行（与工程惯例一致）：

```bash
cargo test -p traveltrust-api
```

**期望**：全部通过；其中 **`governance`** 路由测试含 **`fee-pool-aggregates`** 对 **`country_pool*` / `treasury_pool*` / `treasury_erc20_pool*`** 根级键的 **显式缺失** 断言（**Σ 防冒充**）。

### 3.2 Runbook 演练（预发 / 生产切换前）

| 演练 | Runbook 锚点 | 闸 / 根级重点 |
|------|----------------|---------------|
| **country_pool** | **[§7.1.1](../ops/RUNBOOK.md)**（**TT-RUNBOOK-COUNTRY-POOL-DRILL-001**） | **`GOVERNANCE_COUNTRY_POOL_BALANCE_CHAIN_SSOT`** |
| **treasury_erc20_pool** | **[§7.1.2](../ops/RUNBOOK.md)**（**TT-RUNBOOK-TREASURY-ERC20-POOL-DRILL-007**） | **`GOVERNANCE_TREASURY_ERC20_POOL_BALANCE_CHAIN_SSOT`** |

**`pool_balance`** 与 **`treasury_pool`（Wei）`**：与 **§7.1** 族及 **`.env.example`** 同型——切换对应闸后 **重启 API**，用 **§7.1.1 / §7.1.2** 同风格的 **`curl` + `jq`** 检查 **`GET …/governance/pool`** 根字段 **出现 / 消失**，并复用 **§7.1.1 / §7.1.2** 中 **`fee-pool-aggregates`** 的 **`jq`** 规则确认 **Σ 无后三池根键**。

### 3.3 `jq` 验证规则（可复制）

**主读（pool 路由）**

```bash
# pool_balance 与整行 chain_read 徽标（与 04 一致；闸：GOVERNANCE_POOL_BALANCE_CHAIN_SSOT）
curl -sS "${API_BASE:-http://127.0.0.1:8080}/api/v1/governance/pool" \
  | jq '{pool_balance,data_source,is_chain_ssot,currency}'

# country_pool*（闸：GOVERNANCE_COUNTRY_POOL_BALANCE_CHAIN_SSOT）
curl -sS "${API_BASE:-http://127.0.0.1:8080}/api/v1/governance/pool" \
  | jq '{country_pool,country_pool_data_source,country_pool_is_chain_ssot,data_source,is_chain_ssot}'

# treasury_pool*（闸：GOVERNANCE_TREASURY_POOL_BALANCE_CHAIN_SSOT）
curl -sS "${API_BASE:-http://127.0.0.1:8080}/api/v1/governance/pool" \
  | jq '{treasury_pool,treasury_pool_data_source,treasury_pool_is_chain_ssot}'

# treasury_erc20_pool*（闸：GOVERNANCE_TREASURY_ERC20_POOL_BALANCE_CHAIN_SSOT）
curl -sS "${API_BASE:-http://127.0.0.1:8080}/api/v1/governance/pool" \
  | jq '{treasury_erc20_pool,treasury_erc20_pool_data_source,treasury_erc20_pool_is_chain_ssot}'
```

**成功（链上主读生效时）**：对应 **`*_data_source == "chain_read"`** 且 **`*_is_chain_ssot == true`**，且余额为规范 **全宽 `0x` hex**（**`pool_balance`** 路径以 **04** 与响应根级 **`data_source`** 为准）。

**Σ（fee-pool-aggregates）— 后三池根键须恒不存在**

```bash
curl -sS "${API_BASE:-http://127.0.0.1:8080}/api/v1/governance/fee-pool-aggregates" \
  | jq '{data_source,anchor,
    has_country_pool_ssot: (.country_pool != null),
    has_country_pool_flag: (.country_pool_is_chain_ssot != null),
    has_treasury_pool: (.treasury_pool != null),
    has_treasury_pool_ds: (.treasury_pool_data_source != null),
    has_treasury_pool_flag: (.treasury_pool_is_chain_ssot != null),
    has_treasury_erc20_pool: (.treasury_erc20_pool != null),
    has_treasury_erc20_ds: (.treasury_erc20_pool_data_source != null),
    has_treasury_erc20_flag: (.treasury_erc20_pool_is_chain_ssot != null)
  }'
```

**期望**：上述 **`has_*` 均为 `false`**；**`data_source`** 为 **`projection`** 或（无 DB 时）**`placeholder`**，且 **不因** 任一主读闸在 Σ 根级 **新增** **`country_pool*` / `treasury_pool*` / `treasury_erc20_pool*`**。
