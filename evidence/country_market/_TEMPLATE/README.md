# Country Market Launch Evidence Template

Copy this directory to `evidence/country_market/{ISO}/` when starting a new market launch.

| File | Purpose |
|------|---------|
| `intake.json` | Phase 0 — Owner, approval refs |
| `legal-checklist.json` | Phase 1 — Compliance sign-offs |
| `geo-validation-snapshot.json` | Phase 3 — C-S5 meta-parity export |
| `go-live-bundle/` | Phase 6 — Final audit artifacts |
