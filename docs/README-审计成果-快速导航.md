## ❓ FAQ

**Q: Doc 34/35/36 和原有 doc 01.md 重复吗?**  
A: 不重复。原有 doc 01 是业务/功能需求；新文档是 **代码实现的完整映射表**，两者互补。

**Q: Doc 35 的表结构是否和仓库迁移一致?**  
A: 以 **`crates/api/migrations/`**（SQLx 时间戳迁移）与 [04-附录-DDL草案](spec/04-附录-DDL草案.md)、[41-后端数据库接库与落地清单](spec/41-后端数据库接库与落地清单.md)、[55 §1.2](spec/55-阶段-数据同步与数据库功能同步.md) 为对照单源。仓库根 **`migrations/001_*.sql` 等为遗留草稿**，可能与 API 实迁不一致；勿再以「001/002/003」作为唯一解读。新增表须同步 04、55 §1.2、41。

**Q: 为什么是 91% 而不是 100%?**  
A: doc 09-技术架构中的**版本号需更新** (ethers-rs, sqlx 等)。集成主干后可达 92%+。

**Q: 新文档需要维护吗?**  
A: 是的。每当添加新 API、新表、新事件时，需同步更新对应文档。
