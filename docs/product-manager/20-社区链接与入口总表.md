# 社区链接与入口总表

## 这份文档是干什么的

这份文档用于统一记录所有社区入口，防止社区链接分散、过期、找不到。

当前版本按“真实现状”填写。

也就是说：

1. 当前仓库里已经能确认的社区相关入口，会直接写出来。
2. 当前仓库里没有看到的公开社群，不会假装已经有，只会如实写成“未建立”。

**端口**：表中 **`localhost:3012`** 为示例；以 **`.env` 中 `PORT`** 与 **[`frontend/README`](../../frontend/README.md)** 为准。**路由与 API 真值**以 **[spec/04 §3.4](../spec/04-后端与API.md)** 与 **[spec/07 §零 0.6](../spec/07-开发流程与顺序.md)** 为 SSOT；PM 人话边界见 **[README 快照](README.md)**。
