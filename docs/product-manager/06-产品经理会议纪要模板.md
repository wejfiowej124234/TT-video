# 产品经理会议纪要模板

## 用途

用于产品经理组织“融资方案 + 治理币方案 + 权限方案 + 合规方案”类会议时统一记录，避免每次都重新搭结构。

如果你是第一次主持这种会，也可以直接照着填。你不需要一次把所有专业词都说对，但你必须把结论、负责人和依据记清楚。

## 新手主持会议的 4 个原则

1. 一场会只解决少数几个关键问题，不要贪多。
2. 争论再多，没有原始单源和 owner 也不算结论。
3. 听不懂专业词时，先记下来，回 [07-产品经理术语表](07-产品经理术语表.md) 查，不要现场硬解释。
4. 会议涉及 **链上命名、质押、治理控制台** 时，先区分 **向导身份质押（`IdentityStakingPool` 系）** 与 **`/governance` / TTG** 两条叙事，会前可扫 **[README · 与仓库实现对齐的快照](README.md)**。
