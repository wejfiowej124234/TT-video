# 产品经理专业任务卡

## 这份文档是干什么的

这份文档是 [17-产品经理企业级任务母表](17-产品经理企业级任务母表.md) 的配套执行卡。

母表解决“总共有多少事要做”。

任务卡解决“某一件事具体怎么做、由谁做、做到什么算完成”。

## 使用规则

1. 先在母表里确认任务 ID，再开任务卡。
2. 一张任务卡只解决一件事，不要把很多事塞进一张卡。
3. 任务卡必须写清来源文档、产出物、验收标准、风险点。
4. 任务完成后，先更新任务卡，再回母表打勾。

## 任务卡编号建议

- `PM-CARD-001` 融资 PDF
- `PM-CARD-002` One Pager
- `PM-CARD-003` 抖音账号注册
- `PM-CARD-004` FAQ 成品

任务母表是总地图，任务卡是单兵作战卡。

如果你要真正把这个 PM 体系跑起来，就不要只看文档，要用母表管全局、用任务卡管交付。
