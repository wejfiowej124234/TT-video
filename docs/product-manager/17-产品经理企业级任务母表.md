# 产品经理企业级任务母表

## 这份文档是干什么的

这份文档是 TravelTrust 产品经理的总进度母表。

它不是解释项目的文档，而是执行管理文档。

你可以把它理解成：

1. 产品经理总任务地图。
2. 企业级推进顺序表。
3. 完成一项勾一项的周推进底板。
4. 和任务卡、资料总表、渠道表、内容资产表联动的总控台账。

## 使用规则

1. 先按阶段推进，不要跳着做。
2. 先在这张母表登记，再开单项任务卡。
3. 达到完成标准后才打勾，不要把“开始做了”当成“做完了”。
4. 涉及对外资料时，要同步更新资料类台账。
5. 每周至少更新一次负责人、截止日期、状态和备注。

## 状态约定

- `[ ]` 未完成
- `[x]` 已完成
- `状态` 列建议填写：`未开始 / 进行中 / 待复核 / 已完成`

## 企业级推进顺序总览

| 阶段 | 阶段名称 | 目标 | 通过标准 |
|------|------|------|------|
| P0 | 入门与认知 | 先学懂项目，不乱讲 | 能讲清项目是什么、强在哪里、不能怎么讲 |
| P1 | 决策与边界 | 把融资、治理币、权限、合规边界拉清楚 | 有明确结论，不靠口头理解 |
| P2 | 对外成品 | 把理解型内容整理成对外资料 | 至少形成 One Pager、融资 PDF、FAQ、资料室索引 |
| P3 | 平台与社区 | 建立账号、内容、社区和承接入口 | 平台矩阵和社区机制开始运转 |
| P4 | 一级市场推进 | 建立渠道研究、推进节奏和投递管理 | 前 3 个高优先级渠道进入可推进状态 |
| P5 | 协同与治理 | 把 owner、deadline、纪要、签核、周复盘跑起来 | 不靠临时沟通推进，而是靠机制推进 |
