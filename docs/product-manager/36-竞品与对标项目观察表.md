# 竞品与对标项目观察表

## 这份文档是干什么的

这份文档用于持续记录 TravelTrust 的竞品、对标项目和可参考对象，避免每次对外沟通都只凭印象说“我们不一样”。

## 使用规则

1. 不要求一次研究很多项目，先抓最常被提及的 3 到 5 个。
2. 竞品不只看 Web3 项目，也要看传统旅游平台和信任交易平台。
3. 每次更新时，只写可验证事实，不写主观吹捧。

## 对标维度

| 维度 | 要看什么 |
|------|------|
| 项目定位 | 它到底在解决什么问题 |
| 主入口 | 用户先看到什么 |
| 核心交易链路 | 有没有订单、托管、履约机制 |
| 信任机制 | 有没有评分、信誉、证据或争议结构 |
| 社区承接 | 有没有社区、帮助或固定内容入口 |
| 对外表达 | 它如何讲自己，不如何讲自己 |
