# 一级市场渠道研究表模板

## 这份文档是干什么的

这份文档不是告诉你某个平台一定能上，而是给你一个统一模板，用来逐个平台研究。

产品经理在做一级市场工作时，不能只停留在“我知道 CoinList、DAO Maker、Seedify 这些名字”。

你需要把每个平台都研究成可推进状态。

## 与技术文档对齐（企业级）

本模板中的「项目能力、已上线、合规可讲边界」须与 **`docs/spec/`** 及 **[README 快照](README.md)** 对读；可勾选 **[29 自检表](29-产品经理多维度深度检查与新增缺口.md)**。入口：**[spec/00-文档索引](../spec/00-文档索引.md)**、**[07 §零 0.6](../spec/07-开发流程与顺序.md)**、**[缺口官方总表](../spec/缺口与待补-官方总表.md)**（**P0** 真值）。

## 使用方法

1. 每个平台复制一份模板。
2. 按字段逐项补全。
3. 明确适配度和当前缺口。
4. 做出优先级判断，不要一窝蜂全做。

## 建议怎么推进

1. 先做 [13-一级市场资料包总表](13-一级市场资料包总表.md)，确认资料缺口。
2. 再选 3 个最高优先级渠道先研究，不要一口气研究 10 个。
3. 每研究完一个，就给出适配度和下一步动作。
4. 做成持续更新的推进表，而不是一次性文档。
