# 外部内容资产总表

## 这份文档是干什么的

这份文档用于统一管理所有对外内容资产。

目标是防止下面这些问题：

1. 不知道 One Pager 有没有版本。
2. 不知道融资 PDF 是不是最新。
3. 不知道 FAQ、视频脚本、承接页是不是同一口径。
4. 不知道哪些内容已经能对外，哪些还没过法务。
