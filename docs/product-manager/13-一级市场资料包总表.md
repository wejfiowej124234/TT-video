# 一级市场资料包总表

## 这份文档是干什么的

这份文档是给产品经理直接拿来做“融资投递资料包管理”的。

不要再靠脑子记“我们是不是缺 Deck”“FAQ 有没有写”“视频有没有版本”“官网链接是不是最新”。

这份总表的目的，就是把一级市场要用到的资料一次列清，并且能持续打勾更新。

## 使用方法

1. 先逐行确认“有没有”。
2. 再确认“能不能对外”。
3. 再确认“是不是最新版本”。
4. 最后补 owner 和截止日期。

## 状态说明

- 已有基础版：仓库里已经有相关内容或原始单源，但还不是可直接对外投递版本。
- 待整理对外版：内部资料存在，需要整理成面对外部渠道的版本。
- 待补：当前没有看到可直接使用的成品，需要新建。
- 已完成：已有明确成品并可纳入资料包。

## 建议优先级

### 第一优先级，必须先补齐

1. 项目一句话介绍
2. One Pager
3. Pitch Deck
4. 产品介绍页
5. FAQ
6. Token / 治理边界说明
7. 法务口径确认表
8. 外部账号与联系入口执行清单落地

### 第二优先级，补足解释和转化能力

1. 动画视频解说脚本
2. 中英文项目介绍
3. 中英文 FAQ
4. 审计 / 安全说明

### 第三优先级，增强外部转化能力

1. 动画视频成片
2. 更完整的社区说明
3. 针对不同渠道的定制版本材料


## 这轮检查后的结论

目前这张表里，多数“理解型资料”已经有基础版，但多数“可直接对外投递的成品资料”仍然缺失。

也就是说：

1. 学懂项目的材料已经比较完整。
2. 执行管理层模板已经补到位，但大多数模板还没有填入真实内容。
3. 真正对外融资投递的成品包还没有完整成型。
4. 下一步重点不是继续补纯解释文档，而是把已有初稿推进到法务签核版、双语版和可投递版。
5. 如果要把这张表真正跑起来，直接配合 [16-对外成品资料建设路线图](16-对外成品资料建设路线图.md) 和 [17-产品经理企业级任务母表](17-产品经理企业级任务母表.md) 一起推进。

## 你每周怎么维护这张表

1. 每周更新一次状态。
2. 每周新增一列“本周变化”。
3. 每周确认一次哪些资料已过法务、哪些还没过。
4. 每周至少推动 1 到 3 个资料项闭合。

## 低标准和高标准的区别

### 低标准

- 资料分散在聊天记录和个人电脑里
- 没有统一状态
- 没有 owner
- 没有版本管理

### 高标准

- 所有投递资料都有总表
- 每项都有状态和负责人
- 每项都知道能不能对外
- 所有外部资料都能回到统一索引页
