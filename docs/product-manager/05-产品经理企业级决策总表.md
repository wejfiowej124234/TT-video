# 产品经理企业级决策总表

## 用途

这份总表用于把产品经理当前要推进的企业级问题压缩成一页决策表。

如果你是新手，可以把它理解成“现在别乱抓，先抓这些最会影响全局的问题”。

使用方法：

1. 按主题逐行开会
2. 每行只回答 5 个问题：现状、决策点、原始单源、负责人、输出物
3. 没有结论的行，不视为闭合

## 新手怎么用这张表

1. 不要试图一次全部搞懂，先选你本周最重要的 3 行。
2. 先读“当前要决策什么”这一列，判断自己是否听得懂。
3. 看不懂就先去 [07-产品经理术语表](07-产品经理术语表.md) 查词。
4. 再去“原始单源”列找依据，不要反过来一头扎进全部规范。

## 建议状态定义

- 必须先定：不定这个，后面容易全部漂移
- 高优先级：可以并行推进，但不能长期悬空
- 发布前必须完成：不影响早期讨论，但影响正式对外

## 建议配套动作

1. 每次会议只处理 3 到 5 行，不要一口气开完全部主题。
2. 每行必须落一个 owner 和一个截止日期。
3. 每行都要回到原始单源确认，禁止只按口头印象做结论。

## 给零基础产品经理的优先顺序

如果你只能先推进 5 行，建议从这里开始：

1. 业务边界
2. 融资主叙事
3. 治理币定义
4. 后台角色矩阵
5. 合规表述边界
