# TravelTrust 任务母表（Backlog）

**定位**：**任务来源层（Source of Truth for “要做什么”）**，与 [AI任务卡索引.md](./AI任务卡索引.md)（**执行层 / TT**）分离。

| 层级 | 文档 | 作用 |
|------|------|------|
| 需求与规格 | `docs/spec/*` | 产品/流程 SSOT |
| **任务母表（本文件）** | `docs/任务母表.md` | Backlog：条目、模块、状态、是否已落 TT |
| 执行索引 | `docs/AI任务卡索引.md` | 可执行的 TT：路径、验收、封口 |
| 执行方式 | Low-Latency + 话术文档 | 单卡、≤8 文件、锚点 |

**流程（必须遵守）**

1. **先**在本表登记或更新一行（`B-xxx`）。  
2. **再**将「当前要做」的条目 **派生**为 `TT-xxx`，写入 [AI任务卡索引.md](./AI任务卡索引.md)。  
3. **最后**对 AI 说：**执行任务卡 TT-xxx**（或从母表指定：`B-xxx → 生成 TT 并执行`）。

不做母表 → 易出现重复劳动、遗漏能力、TT 索引与「是否做完项目」脱钩。
