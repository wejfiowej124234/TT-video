## §1 流程主线（与 01 状态机对齐）

Happy 路径记忆：**选向导 → 下单 → 向导接单 → 游客支付进 Escrow → 行程 → 链下「行程完成」确认（非放款）→（若产品启用）行后评分与双方确认 → 合约 `release` / 结清 → 评价归档**。  
**禁止**口语化成「先放款再评价」；顺序与 **[53](../../spec/53-阶段开发技术文档.md)**、**[18](../../spec/18-TravelTrust-全系统架构图.md)** §七、**[04 §3.4](../../spec/04-后端与API.md)** 一致。

| 环节 | 规则要点 |
|------|----------|
| **两步确认** | 仅向导已接单后允许游客支付；**Created / Accepted** 须 **EIP-712** 等留痕，与 **01 §3 / §5** 一致。 |
| **超时** | 接单超时、支付超时、完成侧超时可配置；**数值真源**以 **53 §3.5**、**[08-3](../../spec/08-3-参数与门禁表.md)**、**04** 字段为准；本文「如 24h」仅为可读示例。 |
| **完成 vs 放款** | 链下 `confirm-completion` 与 **`release` 解耦**；**超时自动完成**、单方确认 + 争议窗口等路径见 **01 §1 / §5** 与 **spec/03 §一**。 |
| **服务开始证据** | **`release` 前**须满足最小证据集，否则 **`refundIfNotStarted`** 等路径见 **01 §5 十一**、**01 §7**。 |
| **争议窗口** | **`disputeDeadline ≥ autoCompleteAt`** 等硬约束见 **01 §5**、**01 §10** 12 缝 #3。 |
| **档期** | **Accepted** 占档、**Created** 软占 TTL；迁移时副作用幂等见 **01** 状态机 P0。 |

**角色边界（Region Steward / `provider`）** 不改变上述状态机语义，见 **[87](../../spec/87-TravelTrust-角色体系技术文档-融合架构版.md)** §3～§6。

## §2 取消、退款与质押

- **支付前 / 行程前游客取消**：按时间阶梯（全退 / 部分 / 临期不退）；**platformFee、仲裁费** 与 **01 §10** 12 缝 #12 矩阵一致。  
- **向导取消已接单**：违约记录、信誉或质押扣罚；游客全额退；**Registry 撤销后存量已 Escrowed 订单**走冻结/争议，见 **01 §4** P0。  
- **行程中协商取消**：双方确认或争议 → 人工裁决比例。  
- **向导质押 / 游客侧押金（MVP）**：设计依据 **[81](../../spec/81-经济模型-向导质押与订单押金.md)** §4～§7.1；**链上参数**与 **[08-3](../../spec/08-3-参数与门禁表.md)**「向导订单质押与 81 对齐」一致。**不要求**游客在 Escrow 外另缴「游客订单质押」；若产品未来引入须同步 **01 / 04 / 合约 / 81 / 08-3 / spec/03 §1.2.1**。

## §3 评分公平（Sybil 与评价 P0）

- **仅资金终态可评**：`Completed` 或争议已关闭且执行完毕；与 **01 §4** 一致。  
- **双向评价**、**`order_id` 绑定**、**reviewHash**、频次与封号后展示策略 → **01 §4** 表体。  
- **权重**：金额 / 账户年龄 / 异常折扣等，实装参考 **`ReviewWeight`**（见 **spec/03 §2** 公式叙述）。  
- **防刷与风控**：设备/IP/支付指纹、冷却限频、申诉调权重；**rate limit** 与 **01 §4**、**04** 对齐。

## §4 争议与人工裁决

- **平台人工**可依照片、视频、聊天记录、行程单裁决；**合约不判责**，只执行已结构化裁决（退款比例、扣罚等）。  
- **发起争议**：Escrowed 下任一方可发起；**仲裁费**、重复争议递增、裁决驳回不退费 → **01 §5**、**01 §7** 8 项 #5。  
- **裁决签名**：须含 **`arbiterRoleSnapshotHash` / `arbiterAuthVersion`** 等 **01 §7** P0。  
- **执行器**：代发链上执行；**resolutionId 幂等、双人审批、额度上限** → **01 §7**、**[02](../../spec/02-架构设计.md)** §六/§七；仲裁员不直接持链上私钥。  
- **证据**：类型、存储、DoS 白名单、可用性、时间戳、隐私与保留删除 → **01 §6**、**01 §10** 12 缝 #10、**02** §六、**04**。
