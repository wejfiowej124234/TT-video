## 1. 模块职责（L1）

- **解决**：把「谁已登录、凭据如何下发与失效、**Me** 读谁」收敛为**可审计**的 HTTP 与中间件行为。  
- **角色**：**A 域**入口；订单/市场等 B 域接口依赖 **`require_session_user`** 等守卫（见 **`routes/*`** 与 **04**）。

---

## 2. 核心机制（L2）

- **路由挂载**：**`crates/api/src/routes/auth.rs`** 经 **`routes/mod.rs`** **`merge(auth::router())`** 暴露 **`/auth/*`**；**`me.rs`** 经 **`merge(me::router())`** 暴露 **`/api/v1/me*`** 等（**`merge` 相对顺序**影响 **`router::app`** 主栈与 **93 A-ME-*/A-LOG-*** 互补测试，见 **`auth_register_login_logout_db_api_tests.rs`** 头注释）；与 **04** 路径表对读。  
- **Cookie / Body 策略**：部分响应可配置 **`TRAVELTRUST_AUTH_OMIT_TOKEN_BODY`** 等（见 **`auth.rs`** 内 `json_strip_token_for_response`）；**不得**在文档中发明未在 **04** 出现的字段名。  
- **审计 fail-closed**：**`AUTH_AUDIT_FAIL_CLOSED`** / **`AUTH_AUDIT_FAIL_CLOSED_EVENTS`** 控制审计落库失败时是否硬失败（**`auth.rs`**）；调参须回归 **93 A 域** 相关用例。  
- **代理头信任**：**`AUTH_TRUST_PROXY_HEADERS`** 仅在有可信反向代理时开启（同文件）。

**为何相对「薄」**：认证面以**显式守卫 + 少状态迁移**为主；复杂资金状态仍在 **B 域** 与 **01/03**。

---

## 3. 数据与状态模型（L2～L3）

- **会话**：服务端会话存储与 **`users`/`sessions`** 表（细节以 **04** 与 **`db/`** 为准）。  
- **角色与 87 双读**：**`role` / `role_traveltrust`** 等与 **04**、**87** 对齐；改 DTO 须同步前端 **`apiClient`**（见 **CONTRIBUTING**）。

## 5. 工程使用方式

- **改 `auth` 公共路径**：先 **[04 §3.4](../../spec/04-后端与API.md)** → **`auth.rs`** → **`bash scripts/run-check-04-routes.sh`** → **93 §8.4** 相关脚注 / **`matrix_93_a_*`** 名（见 **[02](./02-生产级文档约束与合入门禁.md)**）。  
- **改 `me` 或依赖会话的 handler**：同步 **04**、**`me.rs`**、**`routes/mod.rs`** 挂载序；回归 **`auth_register_login_logout_db_api_tests`** 或 **`matrix_93_a_me_*`** 族。  
- **改审计语义 / 环境闸**：对齐 **97** + **93**；避免只改 UI 文案。  
- **影响面**：**B/C 域** 凡 **`require_session_user`** 守卫的写口均依赖本会话语义；契约变更须与 **04** 同批。

## 7. 调试与排错

| 现象 | 优先查看 |
|------|----------|
| 401 / `unauthorized` | 请求是否带 **`Authorization`** 或 Cookie；**`session_store`** 是否可用 |
| 403 与审计相关 | **`AUTH_AUDIT_*`** 环境变量；**97** 对应节 |
| 注册/登录 400 | **04** 错误码表；**`auth_register_login_logout_db_api_tests`** 中同名用例 |
| **`router::app` vs `merge(auth|me)` 行为不一致** | **`auth_register_login_logout_db_api_tests.rs`** 头注释与 **93** **A-ME-*/A-LOG-*** 脚注；**`routes/mod.rs`** **`merge` 序** |
| 缺 **`DATABASE_URL`** 导致测试 **skip** / 假绿 | **[05](./05-本地环境与常用门禁速查.md)**、**TT-9618**；**禁止**在无库环境下宣称 **A 域** 已验毕 |
