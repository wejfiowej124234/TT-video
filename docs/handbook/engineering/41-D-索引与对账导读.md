## 1. 模块职责（L1）

- **解决**：让工程师在**不读完全文 110** 的前提下，能**按契约**调用 **Admin 只读**与 **`internal` 索引器探针**，理解 **persist 干跑 vs 写库**、**对账报告**与 **Runbook / 脚本**的对应关系，并与 **93** **D-IDX / D-ADM** 自动化矩阵对拍。  
- **与 [96-08](../../spec/96-08-索引器对账与财务.md)**：本册定义 **生产态** **lag / 投影一致 /（若启用）财务导出** 与 **95** 的边界（**96-08 §0**）；**本篇**只给 **API·脚本·门禁** 入口，**不**复述 **96-08** P0/P1 表体。  
- **边界**：**队列消费、NATS、outbox 分发** 仍以 **[30-C](./30-C-执行器调度机制.md)** + **[250](../../spec/250-阶段Job-Queue-异步任务系统.md)** 为 SSOT；**本篇不写** worker 主循环与 **async_jobs** 状态机细节。

<a id="d41-2-mechanism"></a>

## 2. 核心机制（L2）

1. **双凭证面**：**Admin Bearer**（**`GET …/admin/*`** 只读观测、**`GET …/admin/schema/migrations`** 等）与 **`INTERNAL_API_SECRET`**（**`POST …/internal/indexer-reconcile`** 等）**不得混用**；与 **[70](../../spec/70-管理员系统开发文档.md)** 读前摘要、**[40-D](./40-D-Admin机制.md)** 一致。  
2. **读探针**：**`GET /api/v1/internal/indexer-status`** 提供 **JSON 形状**与 **reorg_recovery** 等键子集（与 **04**、**110** 对读）；**93** **D-IDX-001** 族绑定 **`matrix_93_d_idx_001b_*`** 等（见 **93 §4.5.1** 脚注，**不**在此抄表）。  
3. **对账 reconcile**：**`POST …/internal/indexer-reconcile`** 支持 **`persist:false`**（干跑）与 **`persist:true`**（写 **`reconciliation_reports`** 等）；PASS 判据与 **D-IDX-002/003** 以 **93** 为准。  
4. **运维脚本封装**：**`scripts/ops/indexer-reorg-recovery.sh`** 封装 **status / replay / reconcile / rewind** 等 **curl** 序列（须 **`INTERNAL_API_SECRET`** 与 **`jq`**）；与 **Runbook §2.55** 互证。  
5. **证据快照**：**`scripts/indexer-public-snapshot.sh`**（及 **`scripts/ops/indexer-public-snapshot.sh`**）合并 **`/health`**、**`/meta`** 与可选 **admin/internal** 响应，落盘到 **`evidence/GO_YYYYMMDD/`** 口径见 **`scripts/README`**、**[evidence/README](../../../evidence/README.md)**。  
6. **三源 lag 最小门闸（B-425）**：**`scripts/check-indexer-lag-locate-gate.sh`** 串联 **`GET /meta`**、**`GET …/internal/indexer-status`**、**`GET …/admin/indexer/health`** 的 **HTTP 200** 与 **`chain_id`** 一致性（须 **`ADMIN_BEARER_TOKEN`** + **`INTERNAL_API_SECRET`** + **`jq`**）；与 **96-08 §1**「Indexer lag」生产必查项同向，**不**替代 **go-live** 签字。

<a id="d41-3-model"></a>

## 3. 数据与状态模型（L2～L3）

- **`reconciliation_reports`**（及 **110** 所述快照字段）：**persist:true** 成功时返回 **`report_id`** 等；字段级契约以 **04** 散文窗 + **110 §3.1** 为准。  
- **`_sqlx_migrations` vs `migration_histories`**：**D-ADM-003** 族在 **93** 中定义 **HTTP 与 PG 同事务锚**；详见 **`internal_indexer_admin_db_api_tests.rs`** 头注释。  
- **finality / checkpoint**：链上消费与回滚语义以 **110**、**01** 相关节为准；**本篇**只要求「改代码时打开 **110** 哪一节」。

<a id="d41-7-debug"></a>

## 7. 调试与排错（强制）

| 现象 | 优先查看 |
|------|----------|
| **401/403** on **internal** | **`x-internal-secret`** 或 env 是否匹配 **`INTERNAL_API_SECRET`**；**04** internal 段。 |
| **reconcile 200 但体非预期** | **`persist`** 取值；**110** 与 **93 D-IDX-002/003** 脚注。 |
| **IT 全 skip** | **`DATABASE_URL`**；迁移是否应用。 |
| **`indexer-reorg-recovery.sh` 失败** | **`jq`** 是否安装；**`API_BASE_URL`**；链未就绪时 **warnings[]** 见 **110**。 |
| **`check-indexer-lag-locate-gate` 缺 env** | 须 **`ADMIN_BEARER_TOKEN`** + **`INTERNAL_API_SECRET`**；见脚本 stderr 首行。 |
| **与 Admin observability 键不一致** | **04** **B-152/B-167** 互斥段；**`GET …/meta`** 与 **`GET …/admin/observability/overview`** 分工。 |
