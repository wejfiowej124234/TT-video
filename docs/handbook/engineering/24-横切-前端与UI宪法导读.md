<a id="x24-5-usage"></a>

## 5. 工程使用方式

- **只改 UI 文案、不动路由**：仍建议本地跑 **`frontend`** 侧 **`lint` + `tsc`**（见 **§6**）；合 PR 前看 **[02](./02-生产级文档约束与合入门禁.md)**。  
- **改 `frontend/app/**` 正式路由或 04/13-1 表**：须 **同批** 维护 **[04 §3.4](../../spec/04-后端与API.md)** 与 **13-1 §2 表 1**（与 **CONTRIBUTING** 串联脚本一致）；仓库根执行 **`bash scripts/run-check-04-routes.sh`**（与 **Build** CI 同源串联）；触 **93** 域行时更新 **§8.4** 脚注。  
- **Owner 对拍（建议）**：发版或大改 **UI 路由/顶栏/五主路由页身** 前，由 **Owner** 抽审 **[FIVE-MAIN-ROUTES-PHASE1-FREEZE](../../../frontend/evidence/GO_local_marketing_front_closure/FIVE-MAIN-ROUTES-PHASE1-FREEZE.md)**（**单一前端版本**）、**04 §3.4**、**13-1 表 1** 与 **`frontend/app`** 是否同频；动 **`/` · `/market` 主/子站数据链**（**`landingItinerarySession`** · **`useMarketPage`** · **`marketFavoritesStorage`** 等）另对拍 **[LANDING-MARKET-PAGES-CODE-SSOT](../../../frontend/evidence/GO_local_web3_pages_closure/LANDING-MARKET-PAGES-CODE-SSOT.md)** 与 **`run-web3-itinerary-l5-green.sh`**（**①**；**UI freeze** 与 **数据链** 分轨）；本簇**永久 partial**、**不**参与 **§2b verified**，**不**豁免上列契约表。  
- **大改 onboarding / 发版前构建**：见 **`bash scripts/gates/check-frontend-npm-build.sh`**（**无 node 时默认 skip**，见脚本头注释；CI 强约束时设 **`STRICT_FRONTEND_BUILD=1`**）。  
- **改本文或同批 `engineering/NN-*.md`**：跑 **`bash scripts/check-handbook-frontmatter.sh`**（与 **§6** 一致）。  
- **影响面**：**Next 路由** 与 **apiClient** 路径、**04** 表、**13-1 表 1**、**93** 脚注为**同一闭环**；避免只改页面不改表体。
