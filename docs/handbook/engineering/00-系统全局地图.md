## 2. 核心数据流（主链，非全量架构图）

1. **匿名 / 会话**：浏览器 **Cookie / Bearer** → **`/auth/*`**（公开认证写路径）与 **`/api/v1/me*`**（已登录 **Me**；**非** 已废弃 **`/api/v1/auth/*`**）→ 会话存储与 **[97](../../spec/97-登录找回密码钱包态企业级审计清单.md)** 审计字段。  
2. **行程草稿**：**`/`** **`POST /api/v1/itineraries`**（**1×** 创单 · **`landingItinerarySession` = `localStorage`** — **[LANDING-MARKET-PAGES-CODE-SSOT](../../../frontend/evidence/GO_local_web3_pages_closure/LANDING-MARKET-PAGES-CODE-SSOT.md)** §2）→ **`GET /api/v1/discover/orders`**（**`/market`** · **`useMarketPage`** **300ms debounce** — 同 SSOT §3）→ **`POST /api/v1/orders`** 成单 → **`routes/orders/*`** 状态写口。  
3. **异步与对账**：API 快路径 + **outbox / async_jobs / scheduler_job_runs**（见 **[250](../../spec/250-阶段Job-Queue-异步任务系统.md)** 与 **[30-C](./30-C-执行器调度机制.md)**）→ Admin/观测只读面。

**与 18/09 大图**：仓库内「一张图看清全部模块」仍以 **[18](../../spec/18-TravelTrust-全系统架构图.md)**、**[09](../../spec/09-技术架构总览-v1.0.md)** 为准；**本页不复制**其图块。
