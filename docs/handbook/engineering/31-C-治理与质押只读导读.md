<a id="c31-1-scope"></a>

## 1. 模块职责（L1）

- **解决**：在**不抄** **93 §3** 矩阵行的前提下，说明 **`/api/v1/governance/*`** 只读面与 **`data_source` / `is_chain_ssot`** 等标签的工程读法，并与 **04**、**合约读数**（**50**、**14**）分工。  
- **与 [30-C](./30-C-执行器调度机制.md)**：**30-C** 管 **250/260/outbox**；**本篇**管 **治理池只读、提案列表、投票权** 等 **HTTP 只读契约**（仍以 **04** 为准）。  
- **与 [41-D](./41-D-索引与对账导读.md)**：索引器 / 对账 / **`internal/*`** 主扛 **41-D**；**本篇**仅当 **governance** 响应与 **链上读数 / meta** 交叉时互指。

<a id="c31-2-mechanism"></a>

## 2. 核心机制（L2）

1. **路由族**：**`GET …/governance/pool`**、**`…/proposals`**、**`…/voting-power`**、**`…/fee-routes`**、**`…/vault-forwards`** 等以 **04 §3.4** 为准；**93 §3** 给出 **C-GOV-\*** 族 PASS/FAIL 口径。  
2. **链上 vs 投影**：**`SourceKind`**（**chain_read / projection / reference**）与 **`validate_body_matches_source_kind`** 的契约测试见 **`governance_read_contract_contract_tests.rs`**；**禁止**把 **projection** 占位冒充 **主网真值**（与 **93 §3** 环境前置一致）。  
3. **`GET /meta`**：**`governance`** 对象键序与 **807 / B-177** 等机读旁注以 **04** 散文窗 + **`meta_contract_keys.rs`** 为准；**本篇不**维护键全表。  
4. **ABI / 地址**：合约方法与 **`contracts/abi`** 同步见 **[50](./50-链上与ABI导读.md)**、**`bash scripts/check-55-s13.sh`**。

## 5. 工程使用方式

- **改路径或 JSON 形状**：先改 **`routes/governance/*`** → **同批** 更新 **04 §3.4** → **`bash scripts/run-check-04-routes.sh`** → 更新 **93 §3** 脚注或 **96-01 §0.3 N/A**（见 **[02](./02-生产级文档约束与合入门禁.md)**）。  
- **改合约读数**：**`contracts/src`** → **`forge test`** → **`sync-abi-from-forge`**（若适用）→ **`check-55-s13`**；若 **04 `/meta` 或 governance 键** 受影响，仍须 **`run-check-04-routes`**。
