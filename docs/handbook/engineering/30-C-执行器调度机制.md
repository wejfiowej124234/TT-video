## 1. 模块职责（L1）

- **解决**：把「**不能阻塞 API** 的副作用」与「**定时触发**」从业务 handler 中剥离，落到 **队列 / outbox / 调度表** 可观测、可重试、可审计。  
- **角色**：横切 **D 域 + 250 阶段**；与 **B 域**订单写路径通过 **outbox item kind**、**档期引擎**等间接耦合（见 **250 §3.1** 与 **`startup/outbox.rs`**）。

---

## 2. 核心机制（L2）

**250 vs 260（边界句，不展开全文）**

| 侧 | 负责 | 仓库线索 |
|----|------|-----------|
| **250** | 队列消费、重试、DLQ、回放；**async_jobs** 投影 | **`crates/api/src/startup/outbox.rs`**、**`db/`** 内 jobs 相关模块、migrations **`async_jobs`** |
| **260** | cron 触发、运行记录、防重锁 | **`db/jobs_scheduler_config.rs`**、**`scheduler_job_runs`** 表族 |

**冲突**：以 **250/260 边界表 + 04 §3.4** 为准（见 **250 §1.1**）。

**Outbox worker**：`process_outbox_item` 按 **`kind`** 分发；失败重试间隔 **`outbox_retry_delay_secs`**；死信写 **`data/outbox_*.json`** 告警工件（见 **`outbox.rs`** 头注释）。

**旁路与双写（示例）**：**96-18** webhook 与 **`async_jobs`** 镜像/主选队闸见 **250 §二** 长注与 **`contracts/planned/ONBOARDING_WEBHOOK_ASYNC_JOBS_MIGRATION_NOTES.md`**（**不**在本篇复述开关矩阵）。

## 3. 数据与状态模型（L2～L3）

- **`async_jobs.status`**：`pending` / `running` / `completed` / `failed` / `dead_letter` / `cancelled`（**migration** `20260328000025_admin_jobs_scheduler_config_releases.sql`）。  
- **`scheduler_job_runs.status`**：`queued` / `running` / `success` / …（同文件）。  
- **与 04**：Admin 只读 **`GET /api/v1/admin/jobs*`** 等若出现须只在 **04** 定义后出现；本篇**不**列字段表。

## 5. 工程使用方式

- **新增 outbox kind**：在 **`process_outbox_item`** 增分支 + **04**（若影响可观测 HTTP）+ **250** 叙述增量；补 **93** 脚注与 **`matrix_93_*`** 名（若触及 **D-ONB-\*** 等族）。  
- **改迁移**：SQL 与 **`sqlx`** 模型同批；跑 **`DATABASE_URL`** 下 **`cargo test`** 相关模组。  
- **改 Admin 只读 `jobs` HTTP**：先 **04 §3.4** → **`routes/admin/*`**（以仓库实际路径为准）→ **`bash scripts/run-check-04-routes.sh`**。  
- **改本文或同批 `engineering/NN-*.md`**：跑 **`bash scripts/check-handbook-frontmatter.sh`**（与 **§6** 一致）。  
- **影响面**：**onboarding webhook**、**`async_jobs` 镜像**、**调度运行记录** 与 **96-18 / 250 §二** 环境闸耦合；勿只改单文件不落 **04/93**。

## 7. 调试与排错

（列表体与旧表同义；避免管道行过密触发 **`HBOOK-ENG-TABLE-WARN`**。）

- **outbox 堆积** → **`data/outbox*.log`**、**`outbox_dead_*.json`**；**`outbox_retry_delay_secs`**。  
- **`async_jobs` 镜像不一致** → **250 §二**、**`ONBOARDING_WEBHOOK_ASYNC_JOBS_*`** 环境变量；**`matrix_93_d_onb_008b_*`**。  
- **调度只排队不跑** → **`scheduler_job_runs`** 行 **`queued`** 是否被 claim；**`jobs_scheduler_config.rs`**。  
- **`run-check-04-routes` 失败** → 是否新增/修改 **`/api/v1/admin/jobs*`** 等而未同步 **04 §3.4**；**`routes/mod.rs`** **Admin** 挂载。  
- **`onboarding_app_stack_db_api_tests` 大量 skip 或 0 测** → **`DATABASE_URL`**、迁移是否就绪；**[05](./05-本地环境与常用门禁速查.md)**、**TT-9618**。  
- **`check-handbook-engineering-content` 失败** → 缺 **`../../spec/`** 外链或 **§6** fenced；见 **[06](./06-工程模块技术文档编制契约与验证闭环.md)**。
