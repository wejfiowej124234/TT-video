## §2 合 PR 前默认命令（按改动范围取舍）

与 **[CONTRIBUTING](../../../CONTRIBUTING.md)**「提 PR 前（本地）」**同源**，此处为**最短路径**。**改公共 API / 域行为**时须与 **[engineering/04 · §1a](./04-HTTP与路由契约导读.md#hb-eng-04-drift-checklist)** 同 PR 闭包**叠加**自检（**04 §3.4**、**93**、**`run-check-04-routes`**、**`cargo test`**）。

```bash
# 后端（几乎任何 Rust 改动）
cargo check -p traveltrust-api
cargo test -p traveltrust-api
```

```bash
# 触及 crates/api 路由、04 §3.4、frontend 契约路径时（须 Python 3）
bash scripts/run-check-04-routes.sh
```

```bash
# 改 docs/handbook 下编号正文或栏 README 时（文首元数据门禁）
bash scripts/check-handbook-frontmatter.sh
```

```bash
# engineering 域篇（NN≥10）、EVIDENCE-*-cluster-verified.md，或大量 handbook→spec 外链卫生
bash scripts/check-handbook-engineering-content.sh
```

```bash
# 可选：engineering 内相对路径断链（contracts/corpus/…；**09 · I5**）
bash scripts/check-handbook-engineering-local-md-links.sh
```

**触及 04 §3.4 / `routes/**` / `frontend` 下与 `/api/v1` 相关契约**：合并前**应**跑通 **`run-check-04-routes`**（与 **Build** CI 同源），见 **CONTRIBUTING**「路由与 `04`」节。

**触及 96-18 / onboarding / `matrix_93_*_onb_*` 等**：在已配置 **`DATABASE_URL`** 的库上跑 **`bash scripts/gates/tt-9618-onboarding-pg-evidence.sh`**（见 **CONTRIBUTING** 与 **[TT-9618 §3.5.3](../../runbook/TT-9618-onboarding-local-testnet.md#tt-9618-pg-evidence-one-shot)**）。

## §3 改动类型 × 建议门禁（速查矩阵）

| 你改了 | 至少跑 |
|--------|--------|
| **`crates/**`（非纯注释）** | `cargo test -p traveltrust-api` |
| **`crates/api/src/routes/**`、**`04 §3.4`**、相关 **frontend API 路径** | `bash scripts/run-check-04-routes.sh` |
| **`docs/handbook/**` 下 `NN-*.md` / `REG-*.md` / 各栏 `README.md`** | `bash scripts/check-handbook-frontmatter.sh` |
| **`engineering` 域篇（`NN≥10`）、`EVIDENCE-*-cluster-verified.md`，或大量指向 `../../spec/` 的 Markdown 外链** | `bash scripts/check-handbook-engineering-content.sh` |
| **engineering 内链仓根（`contracts/`、`corpus/` 等）** | 可选：`bash scripts/check-handbook-engineering-local-md-links.sh`（**09 · I5**） |
| **`contracts/src` / `contracts/abi` / `frontend/dapp/abis`**（非仅注释） | **`forge test`（`contracts/`）** → **`./scripts/sync-abi-from-forge.sh`** → **`bash scripts/check-55-s13.sh`**；若 **04 §3.4** 或 **`/meta`** 变更 → **`bash scripts/run-check-04-routes.sh`**（顺序与 [**Runbook §12.4**](../../../ops/RUNBOOK.md)、**[50 §6](./50-链上与ABI导读.md#b50-6-verify)**、**CONTRIBUTING**「合约 / ABI」段一致） |
| **`frontend/` 逻辑与页面** | `cd frontend && npm run lint && npx tsc --noEmit && npm test`（见 **CONTRIBUTING**） |
