### 2a. 覆盖率量化（**与 §3 表同步；每轮审计须重算**）

**定义**：**N** = 下文 **§3**「叙事簇」表之**行数**（当前 **N = 19**）。每行归类为 **not_started** / **partial** / **migrated** / **verified** 四态之一（与 **§1.2** 同词表）。**簇级**不展开 **302** 个根文件。

**怎么读 §2a（与 §3 同行对拍，避免混名）**：**§3「叙事簇」表**每一行的 **not_started / partial / migrated / verified** 与本小节符号 **Z / Y / X / Fv** **一一对应**（计数关系见下段 **§2a 与 §3 对拍**）。**三张「指标」表**的分母均为 **N**，**只统计簇行**。**再下的「篇级」段落**另有分母 **12**（当前已落盘的 **`engineering/[1-9][0-9]-*.md` 且 NN≥10** 域样板篇数，**含** **[24](./24-横切-前端与UI宪法导读.md)**），与 **N = 19** **不是同一计数**——**勿**将「篇级强证率 **11/12**」与「**Fv = 10**（§3 中 **verified** 行数）」当成同一对象；**X / N** 仅统计 **§3** 标 **`migrated`** 之行（当前 **01 总库**、**02 架构**、**03 流程**、**97 Auth**、**95/96/97 真值塔 · T-017**）；**不**表示无 **verified** 簇。**勿**将 **§4.1** 之「**九节完备**」与 **§3** 簇态 **`migrated`**（**X**）混名（见 **§1.2** 段末 **用词实名**）。

| 符号 | 含义 | 当前值（**2026-04-30** 清点） |
|------|------|-------------------------------|
| **Z** | **未迁移**（**not_started**） | **0** |
| **Y** | **部分承接**（**partial**） | **4** |
| **X** | **全量承接**（**migrated**，整簇叙事可由 handbook/corpus 主导且 SSOT 外指清晰） | **5**（**01 总库**、**02 架构**、**03 流程**；**97 Auth**；**95/96/97 真值塔 · T-017**） |
| **Fv** | **强证闭合簇数**（**verified**，须 **§2b**） | **10** |
| **N** | **主序列簇总数** | **19**（**X + Y + Z + Fv = 19**；含 **100～330 阶段体系 §2b.7**、**93·C §2b.9**） |

**§2a 与 §3 对拍（强制）**：**Y** = **§3** 表「覆盖状态」为 **`partial`** 之行数；**Fv** = **`verified`** 之行数；**Z** = **`not_started`** 之行数；**X** = **`migrated`** 之行数；四态**互斥**（同一行只计一栏）。当前 **§3** 共 **19** 行：**partial 4**（**00/93/05·06·13/根余量**）、**migrated 5**（**01 总库**、**02 架构**、**03 流程**、**97 Auth**、**95/96/97 真值塔 · T-017**）、**verified 10**，故 **Y=4**、**Fv=10**、**Z=0**、**X=5**。历史 **变更记录** 中的 **Y/Z** 为当时快照；**重算以本轮 §3 表 + 上行计数为准**。

<a id="audit-quant-semantics"></a>

**§2a 指标与 §3 四态对读（强制）**：**§3** 每一行**互斥**归入 **not_started / partial / migrated / verified** 之一；**verified** 行**不**再计入 **Y** 或 **X**。  
- **簇级任意承接率** 表内公式 **(X + Y) / N** 的**操作定义**：仅为**覆盖状态 ∈ {partial, migrated}** 之行占比，**不含 verified**（后者单列 **Fv**）。若需「**至少 partial 及以上任意一档（含 verified）」**，用 **(N − Z) / N = (X + Y + Fv) / N**（当 **Z = 0** 时为 **100%**）。  
- **簇级强证闭合率** 表内 **(X + Fv) / N**：**X** 为 **migrated** 整簇、**Fv** 为 **verified** 整簇；**X > 0** 时 **(X + Fv) / N** **不等同** 单独 **Fv / N**。**不得**将 **(X + Y) / N** 误读为「含 **verified** 的触达率」。  
- **簇级全量闭合率 X / N** 仅指 **migrated**，**与 Fv 无加总**；**X / N > 0** **仍不**表示可删 **spec**（见 **§11**）。

| 指标 | 公式 | 当前值 |
|------|------|--------|
| **簇级全量闭合率** | **X / N** | **5 / 19 ≈ 26.3%** |
| **簇级 partial∪migrated 占比（不含 verified）** | **(X + Y) / N** | **9 / 19 ≈ 47.4%** |
| **簇级强证闭合率（migrated ∪ verified）** | **(X + Fv) / N** | **15 / 19 ≈ 78.9%** |
