## §2 合入前一票否决（文档 + 契约 PR）

满足**任一条**即不应合入（或须拆 PR / 先补证据）：

1. **公共 API 变更**而不同批更新 **04 §3.4**（及 CONTRIBUTING 要求的 **`api.ts`/`apiClient`** 若适用），或 **`run-check-04-routes`** 未绿。  
2. **路由域增删改**而不同步 **[14 §2.1](../../spec/14-合约-API-ABI-前后端对齐.md)** / **07 §零 0.6** 约定对拍说明（若该次变更要求对拍）。  
3. **声称域行为已验收**但 **93** 无对应脚注/用例族规划，且未在 **96-01 §0.3** 等束表声明 **N/A** 及理由。  
4. **声称 95 §8.2 / §3 某行已闭**但与当前 **93** 脚注或 **`report.json`** **`release_gate`** **矛盾**。  
5. **07 文首 `Version:`** 有改时，未做 **07 + 00 §六 6.5 + 表顶** 三线同批或未跑 **`bash scripts/check-07-version-triple.sh`**（见 **[07 §六 6.1](../../spec/07-开发流程与顺序.md)**）。  
6. **在任意 `.md` 中写入密钥、生产 token、私钥材料**（示例须用占位符并指向 **`.env.example`**）。  
7. **修改 `**/report.json`** 时违反 **go-live** 文首 **PARTIAL_GO 日落**、**`is_final_truth` 唯一**、**关键路径须带真值报告** 等 CI 已强制规则。  
8. **宣称 Production GO** 但未满足 **[go-live · GO Decision](../../go-live-checklist.md#go-decision-entry-point)** 四维或未并联 **缺口 P0 / 15 附录〇** 所要求的签字与勾选。  
9. **删 `docs` 下 `spec` 子树** 而无 **Owner 逐路径指令**、或未更新 **00 / 引用方 / workflow 锚**（见 **[98 §4](../../spec/98-以代码为真源的文档体系与旧文档替代路线图.md)**、**真值塔 删旧门禁**）。  
10. **Hub / Declaration** 相关变更而不同步 **[96-索引](../../spec/96-索引-全链路外生产验收分册.md)** 文首与 **`[00]`** 版本表（见 **go-live** 文首 **Declaration** 段）。  
11. **新增或修改 `docs/handbook/`** 下 **`engineering|product-manager|learn` 的 `NN-*.md`**、**`corpus/REG-*.md`** 或**任一栏 `README.md`**，导致 **`bash scripts/check-handbook-frontmatter.sh`**（**`scripts/gates/check-handbook-frontmatter.py`**）**未通过**（缺 **Version** / **与 spec 关系** 等；见 **[手册 00 §2.2](../00-手册总览与编制规范.md#hb-00-naming)**、**[engineering/05](./05-本地环境与常用门禁速查.md)**）。  
12. **修改 `docs/handbook/engineering/`** 下 **`[1-9][0-9]-*.md` 域篇**（**NN≥10**），导致 **`bash scripts/check-handbook-engineering-content.sh`** 未通过（**`docs`/`spec` 链接断裂**、**缺验证段** `cargo test`/`run-check-04-routes`/`bash scripts/` 等；见 **[engineering/05](./05-本地环境与常用门禁速查.md)**、**[06 §12](./06-工程模块技术文档编制契约与验证闭环.md#eng-06-pr-checklist)**）。  
13. 落入 **§2 附**「**须写 ADR**」的变更而未落盘 **ADR**（**`docs/adr/*.md`**，格式见 **[07](./07-架构决策记录ADR规范.md)**），且无 **Owner** 书面豁免。
