## §2 仓库顶层骨架（只记方向）

- **`crates/api`**（Rust 包名 **`traveltrust-api`**，见 **`crates/api/Cargo.toml`**）：HTTP API 聚合、**`api_router()`** 域挂载。  
- **`frontend/`**：Next.js 应用与 **`lib/api`** 等客户端。  
- **`contracts/`**：链上合约与 **ABI**；与 **`check-55-s13`** 对拍。  
- **`scripts/`**、**`.github/workflows/`**：机读门禁与 CI。

**易腐数字**（如 **`merge` 次数**）以 **`routes/mod.rs` + 00 读前 B-181** 或当次脚本输出为准，本手册**不锁数字**。
