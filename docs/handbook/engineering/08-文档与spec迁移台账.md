### 1a. **partial** 与「承接完成」（**强制**）

| 词 | 含义 | **不得** |

| **partial**（[09 §3](./09-文档迁移覆盖审计报告.md#audit-coverage) 簇态 / 本表「覆盖度」列） | 已有 **导读 / REG / 样板**，**SSOT 仍在 spec 或 04/93** | 在 PR、纪要、对外口径中写「**已替代**该 spec」「**可删**该路径」 |
| **full**（本表） | **叙事与验收链**在 handbook/corpus 侧可主导，**且**仍满足 **04/93** 机读真源 | **不等价**于 **`删除 spec=yes`**（仍须 **§2** 五条件 + **SPEC-MIGRATION**） |

## 2. 「删除 spec」判定（**强约束**）

**本表的 `删除 spec=yes` 不是充分条件**；它只表示：**该叙事簇在 handbook 侧已具备替代读本的最小工程闭环**。真正执行 `git rm ../../spec/...` 仍须：

1. **[SPEC-MIGRATION-STATUS](../corpus/SPEC-MIGRATION-STATUS.md)** 中 **P-C**（脚本不再硬编码 `docs`/`spec` 等）与 **真值塔** 会签；  
2. **[98 §2](../../spec/98-以代码为真源的文档体系与旧文档替代路线图.md)** 主张表登记；  
3. **CI / 链接** 不因删路径而红。

**列 `删除 spec=yes` 的必要条件（全部满足才可填 yes）**

| # | 条件 |
|---|------|
| 1 | **handbook** 有 **[06](./06-工程模块技术文档编制契约与验证闭环.md)** 意义下的**合格域文**或 **REG-* 正文再生**（九节或 REG 等价结构） |
| 2 | 承接文档 §6（或等价节）含 **`cargo test` / `run-check-04-routes` / `bash scripts/`** 之一，且与 **CI** 或脚本**真实同名** |
| 3 | 已登记 **[手册 00 §3](../00-手册总览与编制规范.md#hb-00-master-table)**（主序列表有行） |
| 4 | **无** **04/93** 表体复制（人工审 + **`bash scripts/gates/check-handbook-engineering-content.sh`** 链路与验证段检查） |
| 5 | **至少一次**合并后流水线或 Owner 记录的 **「按文档能跑通验证」**（盲测四问见 **[20-B](./20-B-订单机制.md#b20-blind)** 同类） |

**默认**：未评估或任一条件不满足 → **no**。

<a id="mig-verified-gate"></a>

### 2a. 「**verified**」标记门禁（**强制**）

在 **[09 §10a](./09-文档迁移覆盖审计报告.md#audit-task-list)**、**[09 §3](./09-文档迁移覆盖审计报告.md#audit-coverage)** 或 **任一 PR 描述** 中，将某 **域篇 / 簇 / 任务** 标为 **verified** 前，**须**满足下列 **V-1～V-3 至少其一**；**否则**只能标 **migrated** 或 **partial**。**禁止**无证据写 **verified**（含历史文案「视同已验」**不得**自动升格）。

| 代号 | 证据类型 | 最低要求 |
|------|----------|----------|
| **V-1** | **PR 运行证据** | PR **正文或评论**贴 **终端截图**或**可复制日志**，含 **exit 0**、与域篇 **§6** **同名**命令；**或**附 **CI run URL** 指向含该命令的 job log |
| **V-2** | **CI 显式跑文档命令** | **`.github/workflows`** 中 **具名** step 执行该域篇 **§6** 所列 **`cargo test …` / `bash scripts/run-check-04-routes.sh` / `bash scripts/…`** 之一，且 **log / artifact** 可复核 |
| **V-3** | **Owner 文档签收** | 目标 **Markdown** 内增加 **`Reviewed-by: <Name> <YYYY-MM-DD>`**（须 **Owner** 或 **其书面委托的文档 Owner**）；**须**随合并 PR 进入默认分支 |

**检索自查**：`rg -n 'verified' docs/handbook` — 命中处**须**能在同 PR 或同文档找到 **V-1～V-3** 之一。

**口径全文与计数**：**[09 · §2a～§2b](./09-文档迁移覆盖审计报告.md#audit-quant-coverage)**。

### 2a.1 台账维护排错（常见误填）

| **HTTP 契约漂移** | **不**在本表改路径；回到 **[04 §3.4](../../spec/04-后端与API.md)** + **[engineering/04 · §1a](./04-HTTP与路由契约导读.md#hb-eng-04-drift-checklist)** |
