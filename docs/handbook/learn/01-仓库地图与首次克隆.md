## §2 目录树（只记大块）

- **`crates/`** — Rust 后端（API 在 **`traveltrust-api`**）。  
- **`frontend/`** — Web 前端。  
- **`contracts/`** — 智能合约。  
- **`../../spec/`** — **权威规格与矩阵**（长、全）。  
- **`docs/handbook/`** — **本手册**：按角色、**按号排序**的短读本。  
- **`scripts/`** — 门禁与辅助脚本。
