## §1 推荐用语（与研发同频）

| 你想表达 | 建议说法 | 研发会落到 |
|----------|----------|------------|
| 功能做完了 | **「93 矩阵是否覆盖？04 是否已登记？」** | **93** 脚注 + **04 §3.4** |
| 能上生产吗 | **「go-live 四维是否全满足？」** | **[go-live GO Decision](../../go-live-checklist.md#go-decision-entry-point)** + **缺口 / 15** |
| 全链路还差什么 | **「95 §8.2 / §9 开放项是什么？」** | **95** + **95-附录** |
| 怎么收口执行 | **「96 哪几个分册要跑？」** | **96-索引** → 分册 |

**避免**：把 **「UI 做完」** 直接等同于 **「生产 GO」**；把 **07 文首 %** 与 **95 完成度**混谈（见 **96-索引 Declaration**）。

## §2 需求写到什么粒度就够

- **用户故事 + 验收口径**：可进 PRD / Issue；验收口径**须**能映射到 **93** 域别行或明确 **本轮不做（N/A）**。  
- **接口字段级**：以 **04** 与研发双签为准，**不在**产品侧另起「第二份契约表」长期维护。
