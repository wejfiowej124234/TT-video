## 一、当前还存在的问题

### 1.1 需后端/产品落点（前端无法单独闭环）

| 问题 | 说明 |
|------|------|
| **数据全 mock** | 帖子、评论、关注、粉丝、好友、私信、收藏均为前端 mock，刷新即恢复；无法真实发帖、评论、关注、私信。 |
| **点赞/收藏/关注不持久化** | 点击后仅本地态，刷新丢失；需接点赞/收藏/关注 API 并做乐观更新与失败回滚。 |
| **视频为占位** | 视频帖点击为占位层，无真实媒体 URL、进度条、静音切换；需接媒体 API 后接入 `<video>` 或播放器。 |
| **举报/审核未落地** | 举报仅 toast「已提交」，无后端记录与限流；内容审核策略待产品/法务定稿。 |
| **上传为占位** | 发帖多图为本地 blob 预览，未实际上传；接后端后需做文件类型/大小/时长校验与安全策略。 |

### 1.2 前端可改进的问题（无后端也可做）

| 问题 | 说明 | 建议 |
|------|------|------|
| **评论抽屉「登录后评论」常显** | 未登录时显示登录提示条，但登录后该条仍占位 | ✅ `CommentDrawer`：`!isLoggedIn && !authPending` 才展示去登录条 |
| **目的地与类型筛选未联动** | 热门目的地与「类型」分两块，无「当前筛选」汇总提示 | ✅ `CommunityFeedFilterBar`：「当前：…」汇总 + `community_filter_clear` |
| **Feed 桌面端无侧栏** | 对标 INS/抖音有「热门/推荐」侧栏，当前仅单列 | ✅ `CommunityFeedDesktopAside`（热门目的地 + 推荐关注 + 规范链接）；移动端仍单列 |
| **轮播无键盘/手势** | 多图轮播仅点击箭头/指示点，无左右键、无滑动 | ✅ `CommunityFeedCardMedia`：多图 `tabIndex=0` + 方向键/Home/End；touch 滑动切换 |
| **会话未读与已读未区分** | 消息列表有未读角标，但单条会话无「已读/未读」视觉 | ✅ `/community/messages`：有未读时行左侧强调条 + 背景 + `aria-label`（依赖后端 `last_read` / 未读计算） |
| **离线无提示** | 无统一网络离线提示 | ✅ `community/layout`：`offline`/`online` 顶栏条 + `community_offline_hint` / `community_online_hint` |
| **社区规范无入口** | 条款/社区规范未链 | ✅ 顶栏/桌面导航/侧栏/发现/「我的」快捷入口链至 `/terms/community-guidelines`（正式稿仍待法务）；规范页 **`main`** 带 **`aria-label`**（`community_guidelines`）；**`/terms`**（服务条款）、**`/privacy`**（隐私政策）**`main`** 同批 **`aria-label`**；63 烟雾覆盖 **`/terms/community-guidelines`**、**`/terms`**、**`/privacy`** |

## 二、可添加的功能与展示（按优先级）

### 2.1 内容与发现（对标小红书/抖音/INS）

### 3.2 功能流程与反馈

| 优化项 | 说明 |
|--------|------|
| **发帖成功** | ✅ **`CommunityFeedMain`**：toast（`community_publish_success` / `community_publish_success_hint`）+ 链 **`/community/me/posts`**（`community_publish_view_my_posts`）。短时自动跳转未做。 |
| **评论/私信发送** | 评论已接 API + 乐观更新；失败 **`community_comment_send_failed`** + 重试。**离线**：`navigator.onLine === false` 时不入乐观队列，提示 **`community_comment_offline`**。 |
| **发帖离线** | **`useCommunityFeed.handlePublishSubmit`**：离线时 **`community_publish_offline`** + `publishSendFailed`，不插入本地假帖。 |
| **反馈离线** | **`/community/feedback`** 提交：若 **`!navigator.onLine`** 直接 **`saveOfflineDraft()`**（与网络失败一致，toast **`community_feedback_offline_saved`**）。 |
| **互动离线** | **Feed**：点赞/收藏/关注/游标「加载更多」toast **`community_interaction_offline`**。**非 Feed 列表**（作者页/我的帖子/收藏等）：**`useCommunityPostLikeCollect`** 同文案 + 无乐观变更。**作者页**：关注、评论（**`community_comment_offline`**）、删帖/改可见性 → **`deleteError`** / **`visibilityError`**。**好友页**：取关、加好友申请、处理收到申请 → toast。**举报** / **私信** 见前文。 |
| **加载更多** | ✅ **`CommunityFeedList`**：`IntersectionObserver` 近底触发 + 手动按钮；游标与离线拦截在 **`useCommunityFeed.handleLoadMore`**。 |
| **重试统一** | ✅ Feed/发帖/评论、**私信列表与线程**、**好友**、**我的帖子/收藏**、**用户主页帖子**、**举报列表与工单详情**（`common_retry`）、**活动中心获赞摘要**（`CommunityInteractionSummary`）已统一；其余接 API 时沿用同模式。 |
