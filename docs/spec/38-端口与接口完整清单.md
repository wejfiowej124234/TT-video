## 3. Smart Contract ABIs (链上接口)

### 3.1 Escrow.sol (托管合约)

**合约地址** (本地): 见 `contracts/abi/Escrow.json`  
**规范引用**: Doc 01 §5-7, Doc 08-3, Doc 19

#### 3.1.1 Functions (6)

| Function | 参数 | 返回值 | 权限 | 说明 |
|----------|------|--------|------|------|
| `init(address _token, address _guide, address _tourist, uint256 _amount)` | token地址, guide地址, tourist地址, 金额 | - | Public | 初始化托管合约 |
| `deposit(uint256 _amount)` | 金额 | - | Tourist Only | 旅行者存入托管金 |
| `release()` | - | - | Tourist Only | 旅行者确认释放托管金给向导 |
| `refund()` | - | - | Arbitrator | 仲裁员退款给旅行者 |
| `openDispute(bytes32 _evidenceHash)` | 证据哈希 | uint256 disputeId | Tourist/Guide | 开启纠纷 |
| `executeResolution(uint256 _resolutionId, uint256 _guideAmount, uint256 _touristAmount)` | 解决方案ID, 向导金额, 旅行者金额 | - | Arbitrator | 执行仲裁结果 |

#### 3.1.2 Events (6)

| Event | 参数 | 说明 | 触发时机 |
|-------|------|------|---------|
| `EscrowCreated` | `orderId, token, guide, tourist, amount, createdAt` | 托管创建 | `init()` 调用后 |
| `Deposited` | `orderId, payer, amount, timestamp` | 存入托管金 | `deposit()` 成功 |
| `Released` | `orderId, recipient, amount, timestamp` | 释放托管金 | `release()` 成功 |
| `Refunded` | `orderId, recipient, amount, timestamp` | 退款 | `refund()` 成功 |
| `DisputeOpened` | `orderId, disputeId, opener, evidenceHash, timestamp` | 纠纷开启 | `openDispute()` 成功 |
| `ResolutionExecuted` | `orderId, resolutionId, guideAmount, touristAmount, timestamp` | 仲裁执行 | `executeResolution()` 成功 |

#### 3.1.3 State Variables

| 变量 | 类型 | 可见性 | 说明 |
|------|------|--------|------|
| `orderId` | bytes32 | public | 订单ID（链外关联） |
| `token` | IERC20 | public | 托管代币合约地址 |
| `guide` | address | public | 向导地址 |
| `tourist` | address | public | 旅行者地址 |
| `amount` | uint256 | public | 托管金额 |
| `state` | EscrowState (enum) | public | 托管状态 (Created/Deposited/Released/Refunded/Disputed) |

### 4.3 Blockchain Indexer (链上事件监听)

**内部调用路径**:
```
Blockchain Event
  ↓ (anvil/hardhat emit)
EventListener (backend/indexer)
  ↓ (POST /api/internal/indexer/process-event)
EventHandler (crates/api/src/chain_on/event_handler.rs)
  ↓ (INSERT/UPDATE)
PostgreSQL orders_projection, escrows 表
```

**监听的事件**:
- `EscrowCreated` (from EscrowFactory or Escrow)
- `Deposited` (from Escrow)
- `Released` (from Escrow)
- `Refunded` (from Escrow)
- `DisputeOpened` (from Escrow)

```rust
pub async fn fetch_tourist_rank(address: &str) -> Result<RankResponse> {
    let url = format!("{}/rank/tourist/{}", DID_RANK_BASE_URL, address);
    let resp = reqwest::get(&url).await?.json::<RankResponse>().await?;

}
```
