## 1. 订单撤回（旅行者侧）

| 场景 | 说明 | 与 03 一致 |
|------|------|------------|
| **Draft 撤回** | 旅行者在订单为 Draft 时可**撤回发布**（或删除草稿）；不涉及资金与向导档期占用（未接单）。 | 无争议；不扣信誉。 |
| **已接单未 deposit** | 旅行者在向导已接单（Accepted）但未 deposit 前取消：按 **payment_window 超时**或**主动取消**处理；可约定**取消次数/频率**限制，超限影响信誉或冷却。 | 与 01 订单状态机、80 §4.9/4.15 一致。 |
| **已 deposit** | 已托管后不再视为「撤回」，按**取消/争议/退款**流程（03、合约）。 | 03 争议与裁决。 |

---

## 2. 撤回次数与信誉

| 规则 | 说明 |
|------|------|
| **撤回次数限制** | 建议：每用户**自然日/周**内 Draft 或 Accepted 未支付订单的**主动取消次数**设上限（如 5 次/日）；超限时限制再发布或需冷却。 |
| **信誉惩罚** | **confirm 后超时未支付**：扣旅行者信誉或记「未支付次数」（80 §4.15.3）；与 03、81 信誉规则一致。**恶意撤回/刷单**：可记入信誉或黑名单。 |
| **与 03 一致** | 争议、裁决、信誉积分等以 03、81 定稿为准；本文仅约定「撤回」与「未支付」对信誉的影响方向。 |
