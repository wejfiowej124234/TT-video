## 0. 总原则

- **旅游**负责情绪与选择：目的地、行程、图片、沉浸。  
- **Web3**负责可信与结算：状态、金额、签名、finality。  
- **融合方式**：同一种「温和科技感」贯穿全站，**不是**旅行风 + Web3 风拼贴。  

与 [13-协议级UI设计宪法](13-协议级UI设计宪法.md) 一致。

---

## 1) 视觉语言（Gentle Tech Travel）

### 1.1 设计关键词（锁死）

温和科技感 / 可信 / 空间感 / 旅行叙事 / 克制动效  

### 1.2 禁用词（出现即返工）

霓虹赛博、重玻璃叠加、**按钮发光**、**数字跳动**、3D 入侵资金区  

与 [13](13-协议级UI设计宪法.md) 宪法 1️⃣、2️⃣、6️⃣ 一致。

**例外（企业级闭环 · 与 13 §一 1️⃣ 补充款、[86 §0.4](86-UI-双系统未来风-风格与动效技术规格.md) 一致）**：在 **`/`**、**`/traveltrust`** 的 **非资金决策 UI**（Hero、叙事、融资展示等），允许 **克制的** 按钮发光与数字滚动；**Escrow / 支付 / 争议等资金区** **不适用**本例外。

---

## 2) 颜色体系（双主轴：Travel + Trust）

不要求定死具体 Hex，但必须定「角色」和「用法」。

### 2.1 两条主色轴

| 轴 | 用途 |
|----|------|
| **Travel Primary（旅行）** | Landing、**`/market` 自由市场**（Discover 叙事）的情绪引导：标题点缀、选中态、插画/图片蒙版 |
| **Trust Primary（可信）** | Protocol Console（Escrow / Dispute / Governance）的主按钮、状态标签、边框强调 |

### 2.2 状态色（金融区固定语义）

| 语义 | 用法 |
|------|------|
| **Success** | 已完成 / 已释放 |
| **Warning** | 待确认 / 未 final |
| **Danger** | 争议 / 失败 / 冻结 |
| **Neutral** | 草稿 / 开放中 / 浏览态 |

**规则**：状态色只表达状态，不用于装饰。

---

## 3) 字体与排版（「旅行叙事」vs「协议控制台」两套节奏）

### 3.1 Experience 区（旅行叙事）

- 大标题 + 叙事性副标题（强调目的地与氛围）  
- 图片占比高，文字跟随滚动「讲故事」  

### 3.2 Protocol Console（协议控制台）

- 信息密度高但留白充足  
- 字体层级**固定顺序**：状态（最大）→ 金额（第二大）→ token/地址/链信息（等宽或小号）→ 操作按钮（单一主按钮 + 次按钮）→ 风险提示（持续可见）  
- **规则**：资金区「先信息、后按钮」，按钮永远不抢戏。  

与 [13](13-协议级UI设计宪法.md) 1️⃣、[13-1](13-1-UI产品级SSOT与页面规范.md) 表 4 信息层级一致。

---

## 4) 圆角、阴影、玻璃质感（分级使用）

### 4.1 圆角等级（建议 3 档）

- **卡片**：中圆角  
- **弹窗**：大圆角  
- **金融操作面板**：小圆角（更严肃）  

### 4.2 阴影等级（建议 3 档）

- **Experience**：可柔和阴影（增强空间感）  
- **Console**：更浅的阴影或细边框（避免「炫」）  
- **Modal**：更明显的遮罩与层级（强调风险确认）  

### 4.3 玻璃（Glassmorphism）使用规则

- **只允许**：Landing 的背景层或卡片轻度使用  
- **禁止**：签名弹窗、资金金额区域、Escrow 主面板  

---

## 5) 动效规范（Motion Budget）

### 5.1 动效等级表（锁死）

| 页面/区域 | 等级 | 说明 |
|-----------|------|------|
| **Landing** | 中 | 页面转场 + 轻量视差 + 3D 缓慢呼吸 |
| **自由市场 `/market`**（Discover 叙事） | 中 | 卡片 hover、筛选展开、滚动出现 |
| **Booking / OrderFlow** | 低 | 步骤条、校验提示 |
| **Escrow / Dispute / Governance** | 极低 | 状态变化淡入、按钮 loading |

### 5.2 动效的「允许类型」

- **允许**：淡入淡出、位移 4–12px、轻微缩放 1–3%  
- **不允许**：闪烁、霓虹呼吸灯、金额数字跳动  
- **金融区**：动效只允许「可用性提示」，不允许「装饰性炫技」。  

与 [13](13-协议级UI设计宪法.md) 5️⃣ 一致。

---

## 6) 3D 规范（只做「情绪层」）

### 6.1 3D 允许出现的页面

- **Landing Hero**（必须）  
- 品牌/故事页（可选）  
- 「资金流抽象可视化」（可选、仅展示）  

### 6.2 3D 禁止出现的页面

**EscrowDetail、Dispute、Governance、签名弹窗** — 绝对禁止。  

与 [13](13-协议级UI设计宪法.md) 2️⃣ 一致。

### 6.3 3D 风格建议（旅游 + Web3 的折中）

- **主题**：抽象旅行符号 + 抽象链路（地球弧线/航线轨迹/光点节点/路径流线，表达「旅行路径 + 可信网络」）  
- **材质**：哑光/半透明低反射，避免高亮金属镜面  
- **色调**：与 Travel Primary / Trust Primary 协同，不要高饱和霓虹  

### 6.4 3D 交互限制（防跑偏）

- **只允许**：轻微跟随鼠标/陀螺仪（小幅度）、滚动触发轻微变化  
- **不允许**：可玩化交互（拖拽旋转、强交互小游戏）  

### 6.5 性能预算（强烈建议写死）

- 首屏 3D 必须**可降级**：低端设备自动 fallback 为静态图/视频  
- 模型：低面数 / 压缩纹理 / 懒加载  
- 目标：保持 50–60fps（不达标就降级）

## 7) 页面级 UI 结构（旅游站模板 + Web3 要素嵌入）

目标：可接近 dribbble「旅行动效质感」，但按区块嵌入 Web3，不破坏可信度。

### 7.1 Landing（情绪 + 信任）

- **Hero**：3D + 一句话定位（「链上托管、旅行更可信」）  
- **信任条**：Escrow / On-chain / Dispute / No custody 四个徽章  
- **示例行程卡**：展示「AI 行程单」质感（图文串联）  

### 7.2 自由市场 `/market`（文中沿用「Discover」叙事名；**`/discover`→`/market`**）

- **筛选**：目的地/日期/天数/预算/酒店/美食/交通  
- **卡片**：图片 + 天数 + 预算范围 + 赏金状态  
- **Web3 元素**：只在「角标」出现（Supported tokens、Escrow enabled），不抢占主视觉  

### 7.3 Itinerary（AI 行程单）

- **招牌页**：图文长卷 + 分段预算  
- **页面底部唯一强 CTA**：Publish bounty  
- 未登录点击 CTA：弹出注册（邮箱）— 此处允许较温和动效  

### 7.4 OrderFlow / Chat（协商区）

- 旅行叙事仍在，但开始克制  
- **右侧固定**：「当前报价摘要卡」（金额、币种、版本号）  
- 每次改动产生 version，最终确认生成 snapshotHash（显示在摘要卡里）  

### 7.5 EscrowDetail（金融区，像银行）

- **顶部**：状态 + 金额 + token  
- **中部**：finality、事件时间线、交易哈希  
- **底部**：单一主按钮（Deposit / Release / Refund）+ 风险提示  
- **绝对禁止**：大图、3D、炫动效、花哨渐变  

与 [13](13-协议级UI设计宪法.md) 1️⃣、[13-1](13-1-UI产品级SSOT与页面规范.md) 表 4 一致。

## 8) 组件级清单（按区域模块给开发）

| 区域 | 组件 |
|------|------|
| **Experience** | Hero3D、TrustBadges、DestinationCard、FilterBar、ItinerarySection（图文段落）、BudgetBreakdown（表格/清单） |
| **Marketplace** | OrderCard（图片+金额+状态）、ChatPanel（会话）、QuoteSummaryCard（版本/价格/snapshotHash）、ConfirmFinalPlanModal（生成 snapshotHash） |
| **Protocol Console** | EscrowStatusHeader、AmountPanel（金额+token）、FinalityBadge、OnchainEventTimeline、SignatureModal（强制字段展示）、RiskNoticeBar |

## 9) 验收清单（UI/3D 防跑偏门禁）

- [ ] **3D 只存在于 Landing / 品牌展示**，不得进入资金页  
- [ ] **EscrowDetail 信息层级顺序正确**：状态 → 金额 → finality → 动作 → 风险  
- [ ] **金融区无霓虹/渐变/玻璃重叠/金额跳动**  
- [ ] **交易操作必须经过 SignatureModal**，字段齐全  
- [ ] **自由市场（`/market`）/ Itinerary 允许旅行动效**，但 CTA 不喧宾夺主  
- [ ] **低端设备 3D 可降级**（静态 fallback）  

与 [13](13-协议级UI设计宪法.md)、[13-1](13-1-UI产品级SSOT与页面规范.md) 一致；发版前/设计评审前建议勾选。
