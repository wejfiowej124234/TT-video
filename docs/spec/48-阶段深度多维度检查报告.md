### 7.4 是否企业级分层？

| 层级 | 对应模块 | 职责 |
|------|----------|------|
| **表现层（Presentation）** | routes/*、router.rs、middleware | HTTP 路由、鉴权占位、幂等/ traceId/ 超时/ CORS |
| **业务/应用层（Application + Domain）** | chain_off/* | 用例编排、状态机（订单/争议）、档期（schedule_engine）、链下 mock 与双写 |
| **数据/基础设施层（Infrastructure）** | db/*、chain/*、startup（hydrate/ingest/outbox） | 持久化、链上读/写、索引器、outbox |

**结论**：**已满足企业级分层**。routes 仅做参数提取与调用 chain_off，chain_off 不直接依赖 axum，db/chain 为底层；若未来规模扩大，可在 chain_off 内再拆「应用服务」与「领域模型」，当前规模非必须。
