## P15 目标

**功能目标**（17 ①）：生成旅行方案与预算，生成 Draft Order。

| 维度 | 内容 |
|------|------|
| 链上/链下 | 链下 |
| 输入 | 目的地、城市、出行日期、天数、酒店类型、美食偏好、交通需求、预算范围、额外备注 |
| 输出 | 每日行程（图片+文本）、费用明细、version=1、状态=Draft |
| 存储 | 数据库表 `itineraries`、`orders (status = Draft)` |

## P15 与现有实现对照

| 17 ① 要求 | 当前仓库状态 | 缺口/状态 |
|-----------|----------------|------|
| 数据库表 `itineraries` | 04-附录-DDL §7.5 + chain_off 内存存储 `itineraries: HashMap<Uuid, ItineraryBundle>` | **已实现** |
| `orders (status = Draft)` | core/chain_off Draft；itinerary_create_impl 创建 Draft 订单（guide_id=nil）并写入 store.orders | **已实现** |
| 行程生成输入与 API | POST /api/v1/itineraries 接收 CreateItineraryBody（目的地/城市/日期/天数/酒店/美食/交通/预算/备注）；main 接入 chain_off 时 200 返回 | **已实现** |
| 行程生成逻辑与输出 | generate_itinerary_mock 产出每日行程+AmountBreakdown；version=1、order_status=draft | **已实现**（规则 mock；可后续换 AI） |
| 前端入口与表单 | app/itinerary/new 完整表单（17 ① 全部输入字段），提交后展示 daily_itinerary、amount_breakdown | **已实现** |
| 查看 Draft 行程 | GET /api/v1/orders/:id 当 status=Draft 时响应含 itinerary（version、daily_itinerary、amount_breakdown） | **已实现** |

**结论**：P15 **已全部实现**；链下模式（CHAIN_OFF=1）下输入→生成→Draft 订单与行程存储→前端展示可调通。
