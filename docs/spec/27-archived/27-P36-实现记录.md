## 一、压测场景定义表

与 [27-P31 §二](27-P31-实现记录.md) 关键路径一致；用于发版前或回归时压测与验收。

| 场景 | 路径 | 方法 | 并发/持续时间（占位） | 通过标准 |
|------|------|------|----------------------|----------|
| 健康检查 | /health | GET | 顺序 N=20 或并发 5×10s | 错误率 0；总耗时见 §二 |
| 元数据 | /meta | GET | 顺序 N=20 或并发 5×10s | 错误率 0；总耗时见 §二 |
| 指标 | /metrics | GET | 顺序 1 次可接受 | 可访问即可（P35 已验收） |
| 列表-向导 | /api/v1/guides | GET | 顺序 N=20 | 错误率 0；总耗时见 §二 |
| 列表-发现订单 | /api/v1/discover/orders | GET | 顺序 N=20 | 错误率 0；总耗时见 §二 |

**说明**：并发/持续时间为占位；实际可用 [p31_load_baseline.sh](../../scripts/p31_load_baseline.sh) 顺序执行，或 hey/ab 等做并发压测。通过标准以 §二 验收阈值为准。

## 二、基线阈值验收标准

与 P31 §二 基线（占位）一致；满足以下条件即视为 P36 基线验收通过。

| 路径 | 验收阈值（占位） | 说明 |
|------|------------------|------|
| /health | 错误率 = 0；单次 &lt; 10 ms 或 N=20 总耗时 &lt; 5s | 无 DB/链依赖 |
| /meta | 错误率 = 0；单次 &lt; 50 ms 或 N=20 总耗时 &lt; 15s | 读 env 与状态 |
| /api/v1/guides | 错误率 = 0；N=20 总耗时 &lt; 30s（链下） | 依赖 store/DB |
| /api/v1/discover/orders | 错误率 = 0；N=20 总耗时 &lt; 30s（链下） | 同上 |

**执行方式**：在目标环境启动 API 后执行 `./scripts/p31_load_baseline.sh [BASE_URL]`（可选 `P31_BASELINE_N=20`）；若输出各路径 **ok/N = N**（全成功）且 **elapsed** 未超过上表总耗时上限，即通过。**可选**：执行 `./scripts/p36_acceptance.sh [BASE_URL]` 自动校验上述阈值（见 §四 4.2）。实测后可将占位阈值替换为实测值或迁至 08-3/运维文档。
