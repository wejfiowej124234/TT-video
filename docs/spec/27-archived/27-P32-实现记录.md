## 二、链 ID 与必填项矩阵

| 模式 | 必填环境变量 | 说明 |
|------|--------------|------|
| **链下** | P3_CHAIN_OFF=1 | 可不设 CHAIN_RPC_URL、CHAIN_ID、ESCROW_FACTORY_ADDRESS |
| **链上** | CHAIN_RPC_URL、CHAIN_ID、ESCROW_FACTORY_ADDRESS | 08-3、Runbook §10；执行器代发时另需 CHAIN_EXECUTOR_PRIVATE_KEY |
| **可选** | CHAIN_EXECUTOR_MAX_AMOUNT_PER_TX、CHAIN_EXECUTOR_MAX_AMOUNT_PER_DAY、CHAIN_EXECUTOR_RETRY_COUNT | 0 或不设表示不限制/默认；08-3 定稿值见变更记录 |

**链 ID 示例（非穷举）**：31337（Anvil）、80002（Polygon Amoy）、137（Polygon Mainnet）；与 08-3 及前端一致。

**前端链 ID 与后端一致**：前端 DApp 链 ID 须与后端 CHAIN_ID 一致；可通过 NEXT_PUBLIC_CHAIN_ID 或从 API（如 GET /meta）获取 chain_id，见 05 §四、06、27-P5/09。

| **脚本** | scripts/p32_check_env.sh：P3_CHAIN_OFF 判断链下/链上；链上时校验必填项、CHAIN_ID 白名单（31337/80002/137，可覆盖 P32_ALLOWED_CHAIN_IDS）、OUTBOX_WORKER=1 时 CHAIN_EXECUTOR_PRIVATE_KEY | 部署前或 CI 可选调用 |
