## 一、发版后检查清单表

发版后须或建议执行的检查项；可与 Runbook §4 演练历史、evidence 归档、08 变更记录一并使用。

| 检查项 | 说明 | 必选/可选 |
|--------|------|-----------|
| 监控/告警通道可用 | 确认 Prometheus/Webhook/日志告警已触达值班；与 P28/P35 一致 | 建议 |
| evidence 归档与 08-2 Evidence 列 | 发版产出 evidence/GO_YYYYMMDD/ 已归档；08-2 对应工单 Evidence 列已填路径或 hash | 建议 |
| 08-3 变更记录 | 若发版涉及 08-3 参数变更，已在 08-3 变更记录登记 | 须 |
| Runbook 演练登记 | 若执行过资损或人因演练，已在 Runbook §4 或 evidence/DR-* 留痕 | 可选 |
| P34 发版前检查留痕 | 发版前已执行 p34_pre_release_checks.sh 并保存输出（见 27-P34） | 建议 |
| 00 版本表与文档版本 | 发版后 00 版本表、08-4 文末版本号与实发版本一致 | 须 |

**说明**：上表为占位清单；项目可增删项并与 Runbook、08 系列定稿一致。
