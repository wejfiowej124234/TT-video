## 一、06 对照表

### 1.1 钱包连接（06 §三）

| 06 要求 | 当前实现 | 状态 |
|---------|----------|------|
| wagmi + WalletConnect v2；检测/连接、地址与 chainId | WagmiProvider、useAccount、useChainId（EscrowDetail、page.tsx）；createConfig 含 http/injected | **符合** |
| 不托管私钥、仅连接用户钱包 | 无私钥存储、仅 wagmi 连接 | **符合** |

### 1.2 签名与交易（06 §三、§四）

| 06 要求 | 当前实现 | 状态 |
|---------|----------|------|
| deposit/release/refund/openDispute 须钱包签 | useEscrowDeposit/Release/Refund/OpenDispute（useWriteContract + useWaitForTransactionReceipt） | **符合** |
| 支付须经 deposit()（17 条 #2） | deposit(amount) 调合约 deposit，无直转 | **符合** |
| 交易状态由 txMachine 管理，终态 Finality 12 blocks | useWaitForTransactionReceipt 等待确认；finalityN 在 Modal 展示，链上终态可后续 watchContractEvent 加强 | **部分**（终态 12 块可加强） |
| 防连点、幂等（17 条 #14） | 按钮 isPending 时 disabled | **符合** |

### 1.3 合约交互（06 §三）

| 06 要求 | 当前实现 | 状态 |
|---------|----------|------|
| viem 构造交易、写仅通过用户签名 | wagmi useWriteContract 调 Escrow ABI（deposit/release/refund/openDispute） | **符合** |
| 读链状态、监听事件 | 订单/托管地址与金额来自 API；事件监听可后续 watchContractEvent | **部分**（读以 API 为主） |
| 业务数据唯一来自 04 API | EscrowDetail getOrder(escrowId)；订单/参与方/金额从 API | **符合** |

### 1.4 与 01 §7、业务数据同源（06 §二、§四）

| 06 要求 | 当前实现 | 状态 |
|---------|----------|------|
| UI 事实：已支付仅链上/对账；pending 展示 confirmations | 订单状态来自 API；链上成功由 useWaitForTransactionReceipt 反馈；confirmations 可加强 | **部分** |
| 12 缝 #11 钱包换绑与已支付订单 | 个人中心/me 有钱包相关；换绑逻辑与 01 一致见 05 §六 | **符合** |
| 签名前展示支付对象与金额、合约/订单（05 §九 9.0.5） | EscrowDetail 签名前 Modal 含 chainId、contract、function、amount、token、gas、finalityN | **符合** |

## 二、13-1 交易交互规范与异常态对照表

### 2.1 Signature/Tx Modal（13-1 §三）

| 13-1 要求 | 当前实现 | 状态 |
|-----------|----------|------|
| 链上动作必须经 Signature/Tx Modal | EscrowDetail 中 confirmAction 时弹出固定 Modal | **符合** |
| Modal 内展示 chainId、contract、function、amount、token、gas、finalityN | Modal 内：chainId、合约地址、function、金额、token、gas 文案、finalityN（12） | **符合** |
| 状态机可见：idle→signing→pending→confirmed→final/failed | txStatusLabel：空闲→等待签名→确认中（pending）→已确认（final）/失败（failed） | **符合** |

### 2.2 异常态（13-1 §四）

| 异常态 | 13-1 要求 | 当前实现 | 状态 |
|--------|-----------|----------|------|
| 钱包未连接 | 明确提示 + 连接入口 | EscrowDetail「连接钱包后可执行…」；首页有 Connect/Disconnect | **符合** |
| 链不对 | 提示切换网络、chainId | Modal 展示 chainId；错链提示可加强 | **部分** |
| allowance 不足 / OFAC / disputeWindow 过期 | 提示与引导 | 可后续加强 | **缺口**（可选） |
| reorg/回滚 | 提示刷新 | 风险提示块含 reorg 文案 | **符合** |
