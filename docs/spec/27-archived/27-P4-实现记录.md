## P4-2：集成测试

**要求**：完整订单链下闭环可调通（Postman/脚本），支付与链为 mock。

| 项 | 落点 | 状态 |
|----|------|------|
| 脚本 | `scripts/p4_chain_off_e2e.sh`：注册旅行者/向导 → 创建向导/质押 → 下单 → 接单 → mock-pay → 确认完成 → 提交评价 | ✓ |
| 环境 | 需先启动 API 且 `P3_CHAIN_OFF=1`；可选参数为 BASE_URL（默认 `http://127.0.0.1:8080`） | ✓ |
| 争议路径 | 脚本说明：启动时设 `P3_SEED_ARBITRATOR_EMAIL=arb@p4.test`，注册该邮箱后调用 POST `/api/v1/disputes/:id/resolve` 可验证裁决闭环 | 文档说明 |

**运行方式**：
```bash
# 终端 1：启动 API
P3_CHAIN_OFF=1 cargo run -p traveltrust_api

# 终端 2：执行闭环（Git Bash / WSL / Linux）
./scripts/p4_chain_off_e2e.sh
# 或指定地址
./scripts/p4_chain_off_e2e.sh http://127.0.0.1:8080
```

**结论**：P4-2 通过；完整链下闭环由脚本可调通，支付与链为 mock。
