## P18 目标

**功能目标**（17 ④）：Escrow 托管层（链上）；MVP 合约只做 4 件事：createEscrow(params)、deposit()、release()、refund()；状态机 Created→Funded→Completed/Refunded/Disputed→Resolved；资金结构 Traveler 存全额、平台抽成 8~12%、Guide 收剩余。

| 维度 | 内容 |
|------|------|
| 链上/链下 | 链上（合约 + 前端/后端对接） |
| 合约 | Escrow.sol、EscrowFactory.sol；EIP-1167 clone；EscrowParams 与 19 一致 |
| 衔接 | 后端/索引 escrow_address 投影；前端 deposit/release（与 P17 可调通） |

## P18 与现有实现对照

| 17 ④ / 19 要求 | 当前仓库状态 | 缺口/状态 |
|----------------|----------------|-----------|
| createEscrow(params) | EscrowFactory.createEscrow(EscrowParams)；Escrow.init(params)；EIP-1167 clone | **已有** |
| deposit() | Escrow.deposit(amount)；仅 traveler、amount=totalAmount | **已有** |
| release() | Escrow.release()；guide + platformFee 分账 | **已有** |
| refund() | Escrow.refund()；traveler 收回 totalAmount | **已有** |
| EscrowParams 结构 | Escrow.sol struct 与 19 一致（chainId, orderId, snapshotHash, parties, token, totalAmount, platformFeeBps, timing, arbitrator） | **已有** |
| 事件契约 | EscrowCreated, Deposited, Released, Refunded, DisputeOpened, ResolutionExecuted | **已有** |
| 状态机 | Status: None→Created→Funded→Completed/Refunded/Disputed→Resolved | **已有** |
| 合约单测 | Escrow.t.sol：test_CreateDepositRelease、test_Refund | **已有** |
| 后端 escrow_address | chain_off order.escrow_address；list_escrow_addresses_for_indexer；事件投影写入 | **已有**（P5/P6） |
| 前端 deposit/release | useEscrowDeposit、useEscrowRelease；EscrowDetail **Deposit 存款** 按钮（order 金额解析 + Modal 确认）+ Release 按钮 | **已有**（P17 衔接；Deposit 已实现） |
| 前端 createEscrow 入口 | 创建托管由**后端/执行器**或链下 mock 写入 order.escrow_address（P5/P6 事件投影或 **POST /api/v1/orders/:id/set-escrow-address**）；前端有地址后可 deposit；EscrowDetail 提供 **模拟写入托管地址** 区块（无 escrow 时显示，仅链下 mock 可用） | **已定稿**（链下 mock API + 前端模拟写入入口已实现，门禁 2 可调通） |
| 前端 refund 入口 | useEscrowRefund + EscrowDetail「Refund 退款」按钮；Signature Modal 支持 refund() | **已实现** |

**结论**：P18 **已实现**（合约 4 件事 + 事件 + 状态机 + 合约测 + 后端投影 + 前端 deposit/release/refund）；创建托管由后端/执行器或链下 mock 提供 escrow_address，前端 deposit/release/refund 与 P17 可调通。

## P18 实现时落点建议

| 落点 | 建议 |
|------|------|
| **合约** | 保持与 19 一致；openDispute/executeResolution 已实现，门禁 4 为可选 |
| **后端** | EscrowCreated 事件投影写 order.escrow_address（P5/P6 已有）；createEscrow 若由后端/执行器发起则需 04 API 或 outbox 定稿 |
| **前端** | 若 Traveler 自行调用 createEscrow：需 EscrowFactory ABI、writeContract createEscrow、成功后写 order 或轮询；若由后端创建则前端仅需 deposit/release/refund。Refund 按钮 + useEscrowRefund 可与 P17 操作区并列 |
| **门禁 2** | 集成：链下 CHAIN_OFF=1 时可为 mock；测试网时 createEscrow→deposit→release 或 refund 可调通即达标 |
