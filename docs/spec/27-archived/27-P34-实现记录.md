## 一、发版前可执行检查脚本清单

| 脚本 | 用途 | 通过标准 | 与 27-P14/08 对应 |
|------|------|----------|-------------------|
| check-08-consistency.sh [base_ref] | 08-3 与 08-4 一致性（关键 key 变更须同步 08-4 版本） | exit 0；否则 PR/合并应阻断 | Runbook §10 W-DRIFT-CI；08-3 映射表 |
| p32_check_env.sh [.env] | 多环境必填项（链下/链上、CHAIN_ID 白名单、执行器私钥） | 输出 OK；MISSING/CHAIN_ID_NOT_ALLOWED 时 exit 1 | P32；08-3 CHAIN_*；Runbook §10 |

| check-ssot-deploy.sh / ssot-deploy-preflight.sh | SSOT 部署前校验（版本、sha256、运行时快照） | 见脚本说明；drift 时非 0 | Runbook §10 SSOT drift；08-3（脚本已移除则按 Runbook 手工） |
| 可验证发布 | 按 evidence/README 可验证发布段落手工（build-frontend-manifest.sh 已移除） | 产出 manifest.json、manifest.sha256；闭环 #7 相关 |
| check-invariants.sh | 不变量/合约等检查 | exit 0 | 01 §10、17 条 |

**用法**：发版前或 PR 前在仓库根执行；可先执行 p34_pre_release_checks.sh（§三）做部分检查的汇总。

## 三、可选汇总脚本 p34_pre_release_checks.sh

| 项 | 说明 |
|----|------|
| **脚本** | scripts/p34_pre_release_checks.sh：依次执行 check-08-consistency、p32_check_env（可选）、check-08-evidence-pointer（可选）；全部通过则 OK |
| **用法** | 在仓库根执行；可选传 .env 路径供 p32_check_env；可选跳过 env/evidence 检查（仅跑 08-consistency） |
| **输出** | 每项 PASS/FAIL；全部 PASS 时 exit 0，任一项 FAIL 时 exit 1 |

**说明**：汇总脚本不替代 27-P14 定稿时操作清单；发版前可先跑本脚本做自动化检查，再执行人工闭环 12 项。
