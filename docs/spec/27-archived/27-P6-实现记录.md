### P6-2 执行器/内部 API 验证步骤

1. 启动 API：`cargo run -p traveltrust-api`（默认 http://127.0.0.1:8080）。
2. 另终端执行：`./scripts/p6_verify_internal_apis.sh`。
3. 预期：未配置链时两接口返回 HTTP 503（chain_not_configured）；配置 CHAIN_RPC_URL、ESCROW_FACTORY_ADDRESS 后返回 200（outbox 空时 processed: 0；indexer 拉取一轮）。配置 CHAIN_EXECUTOR_PRIVATE_KEY 后 process-resolution-outbox 可真实消费一条并发 tx。
