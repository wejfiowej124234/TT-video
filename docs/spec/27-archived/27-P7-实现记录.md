### P7 验收步骤

1. **安装与构建**：`cd frontend && npm install && npm run build`（需已安装 Node；tailwindcss/autoprefixer 已在 devDependencies）。
2. **联调**：终端 1 启动后端（`cargo run -p traveltrust-api`，可选 `P3_CHAIN_OFF=1`）；终端 2 启动前端（`cd frontend && npm run dev`）。打开 http://localhost:3000，首页应显示「API 版本: x」或「后端未就绪」；登录/注册、向导列表、订单、争议列表等页应能请求 04 接口。
3. **基地址**：未设时默认 `http://localhost:8080`；可通过 `NEXT_PUBLIC_API_BASE_URL` 覆盖。
