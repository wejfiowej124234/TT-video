## 一、05 §九 对照表

### 1.1 设计语言与风格（9.0.1）

| 维度 | 05 要求 | 当前实现 | 状态 |
|------|---------|----------|------|
| 资金区严肃 | 订单/托管/支付/争议区：严肃、留白、信息优先；禁止渐变/炫光/跳动/3D | EscrowDetail 白底卡片、金额与状态清晰；无 3D | **符合** |
| 主色与氛围 | 深色或浅色、科技蓝·青·紫点缀、高对比 | 当前多白/灰+蓝按钮；可后续统一 token | **部分** |
| 状态与 04 枚举一致 | 订单状态与 01 §1、04 status 一致（含 PartiallyRefunded、Slashed、Cancelled） | StatusBadge + order.status；枚举覆盖可补全 | **部分** |
| 金额与代币 | 金额+代币符号统一、与 04 一致 | 金额+currency 展示 | **符合** |
| 动效与反馈 | 加载/成功/失败、防连点（17 条 #14） | 按钮 loading+disabled、错误文案 | **符合** |

### 1.2 页面层级 L1～L4（9.0.2）

| 层级 | 05 要求 | 当前实现 | 状态 |
|------|---------|----------|------|
| L1 全局壳 | 顶栏/侧栏、品牌、全局导航、钱包与用户 | 各页内链（首页/订单/me/向导等），无统一顶栏/钱包入口 | **缺口**（可后续补 layout 顶栏） |
| L2 区域布局 | 按角色二级导航（旅行者/向导/仲裁） | 扁平 app 路由，无显式 tourist/guide/arbitrator 分区 | **部分**（功能按页存在，未按角色分区） |
| L3 页面视图 | 列表、详情、表单与 01～04 对应 | 向导/订单/**自由市场（`/market`）**/me/escrow/disputes/争议详情/行程/注册登录等齐全 | **符合** |
| L4 组件/区块 | 向导卡片、订单卡片、状态标签、钱包/支付/质押/争议签名入口 | EscrowDetail 操作区、OrderActionsBlock、ReviewBlock、StatusBadge、ChatBlock 等 | **符合** |

### 1.3 9.0.5 顶级要求（选检）

| 类别 | 要点 | 当前实现 | 状态 |
|------|------|----------|------|
| 可访问性 | 对比度、焦点、语义/ARIA、表单 label | 基础表单与按钮；未系统 a11y 审计 | **部分** |
| 响应式与触控 | 320～1920、触控目标 ≥44px | 未统一断点与触控规范 | **部分** |
| 状态与反馈 | 骨架屏、空状态、错误/成功、超时/争议窗口展示 | 加载/空/错误有；超时与争议窗口从 API 展示可加强 | **部分** |
| 排版与层次 | 标题/正文/辅助、CTA 突出 | 有层级；可统一 design token | **部分** |
| DApp 专属 | 链上 pending/confirmations、tx 链接、钱包未连接/错链提示 | EscrowDetail 有 tx 状态、链上操作 Modal；未连接有文案 | **符合** |

## 二、13-1 对照表

### 2.1 表 1：页面地图（页面职责）

| 页面 | 13-1 唯一任务 | 当前实现 | 状态 |
|------|----------------|----------|------|
| Landing | 品牌叙事 + 引导进入协议 | **`app/(home)/page.tsx`**（**`/`**）首页 | **符合** |
| Discover / 自由市场 | 目的地/向导卡片、筛选 | **`app/market/`** 列表；**`/discover`→`/market`**；Draft 订单卡片 | **符合** |
| OrderFlow | 草稿→确认→付款→完成 | 行程 new → escrow/[id] + 链上操作 | **部分**（步骤条可加强） |
| EscrowDetail | 状态、金额、参与方、finality、允许动作、风险提示 | 状态/金额/参与方/时间/finality 占位、操作区、风险提示块 | **符合** |
| Dispute | 证据时间线、裁决、执行记录 | disputes/[id] 证据与裁决 | **符合** |
| 个人中心/账号 | 资料、钱包、订单/评价/统计 | me 页编辑、订单链接 | **符合** |
| 向导仪表盘/质押 | 向导端统计、质押 | guide/register、guides/[id] 质押 | **部分**（仪表盘可加强） |
| 注册/登录 | 邮箱注册与登录 | auth/register、auth/login | **符合** |

### 2.2 表 2：角色 × 页面权限

| 角色 | 13-1 可访问/动作 | 当前实现 | 状态 |
|------|------------------|----------|------|
| 旅行者 | Landing、**自由市场（`/market`）**、OrderFlow、EscrowDetail、Profile；下单、付款、确认完成、争议 | 同上页面；接单隐藏（后端校验） | **部分**（无显式角色切换入口） |
| 向导 | 接单、确认完成、争议响应 | OrderActionsBlock 接单/确认完成；争议 | **符合** |
| 仲裁员 | Dispute、裁决 | disputes 列表与 [id] 裁决 | **符合** |
| 角色切换 | 入口写死（如右上角或路由前缀） | 无统一角色切换 UI | **缺口** |

### 2.3 表 3：Zone Control

| 区域 | 13-1 允许/禁止 | 当前实现 | 状态 |
|------|----------------|----------|------|
| EscrowDetail | 金额、状态、签名区；禁止霓虹、强动效、3D | 白底、无 3D、无强动效 | **符合** |
| 自由市场（`/market`） | 卡片；不堆链上按钮 | 卡片+链接到 escrow | **符合** |
| OrderFlow / 金融区 | 低动效、无 3D | 符合 | **符合** |
| Dispute | 极低动效、无 3D | 符合 | **符合** |

### 2.4 表 4：EscrowDetail 信息层级（13-1）

| 区块 | 13-1 要求 | 当前实现 | 状态 |
|------|-----------|----------|------|
| 状态 | 不可忽略、不可折叠 | StatusBadge 置顶 | **符合** |
| 金额与币种 | 不可误读、统一小数位 | 金额+currency 突出展示 | **符合** |
| 参与方 | 旅行者、向导、仲裁 | 参与方列表 | **符合** |
| 时间与 finality | 创建时间、finality 可验证 | created_at、finality 占位文案 | **部分**（块高待索引） |
| 允许动作 | 按状态与 RBAC | OrderActionsBlock + 链上 Deposit/Release/Refund/Dispute | **符合** |
| 风险提示 | 永远可见 | 常驻风险提示块 | **符合** |
| Signature/Tx Modal | chainId、contract、function、amount、token、gas、finalityN | Modal 含 chainId、contract、function、amount、token、gas、finalityN | **符合** |
| tx 状态机 | idle→signing→pending→confirmed→final/failed | txStatusLabel 与 pending/success/failed | **符合** |

### 2.5 异常态与风控态（13-1 §四）

| 异常态 | 13-1 要求 | 当前实现 | 状态 |
|--------|-----------|----------|------|
| 钱包未连接 | 明确提示 + 连接入口 | EscrowDetail 内「连接钱包后可执行…」 | **符合** |
| 链不对 | 提示切换网络、chainId | 可加强 | **部分** |
| disputeWindow 过期 | 明确「已过争议窗口」 | 可加强 | **部分** |
| reorg 提示 | 引导刷新 | 风险提示块已含 reorg 文案 | **符合** |

## 三、缺口汇总与建议

| 类型 | 内容 | 建议 |
|------|------|------|
| L1 全局壳 | 统一顶栏/品牌/导航/钱包入口 | 后续 layout 或 P25 补 |
