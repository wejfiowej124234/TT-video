## 如何查找某个 Phase 的内容？

1. **若需要执行 Phase N**：查看 [27-P0至P50开发流程勾选清单](../27-P0至P50开发流程勾选清单.md)，里面有该 Phase 的清单
2. **若需要 Phase N 的详细执行记录**：在本目录中找 `27-PN-实现记录.md`（如 [27-P5-实现记录](27-P5-实现记录.md)）
3. **若需要发版前准备**：查看 [27-P14-实现记录](../27-P14-实现记录.md)（12 项闭环清单）
4. **若需要 12 缝/17 条/安全检查等**：查看 [27-P0至P47-深度检查报告](../27-P0至P47-多维度深度检查报告.md)

## 归档原因与瘦身效果

**原因**：
- 56 个 Phase 记录分散在主 spec 中，造成 file browser 笨重
- 实际执行和权威参考只需 5 个核心文档
- 历史记录（P0 已做、P5 已做等）不需要每次都看

**瘦身效果**：
- 前：61 个 27-*.md 文件（主 spec 目录列表中）
- 后：5 个 27-*.md 文件（主 spec）+ 56 个在 27-archived/（子目录）
