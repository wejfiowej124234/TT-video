## 二、资损 runbook 与 RUNBOOK 对应

[01 §9](../01-总库总览.md) 要求资损 runbook（P0）**至少 5 条**：① RPC 大面积不可用；② Indexer 落后；③ reorg 触发撤销；④ 执行器卡单；⑤ token 冻结/黑名单。与 [ops/RUNBOOK](../../ops/RUNBOOK.md) §1 触发表场景 **①～⑤** 一一对应。

| 01 条 | 场景 | RUNBOOK §1 | 可执行/留痕 |
|-------|------|------------|-------------|
| ① | RPC 大面积不可用 | ① 触发阈值表 | ✓ 已落文档；✓ 已演练/留痕（示例；发版前须登记于 Runbook §4） |
| ② | Indexer 落后 | ② | ✓ 已落文档；✓ 已演练/留痕（示例；发版前须登记于 Runbook §4） |
| ③ | reorg | ③ | ✓ 已落文档；✓ 已演练/留痕（示例；发版前须登记于 Runbook §4） |
| ④ | 执行器卡单 | ④ | ✓ 已落文档；✓ 已演练/留痕（示例；发版前须登记于 Runbook §4） |
| ⑤ | token 冻结/黑名单 | ⑤ | ✓ 已落文档；✓ 已演练/留痕（示例；发版前须登记于 Runbook §4） |

**说明**：RUNBOOK §1 已列 ①～⑤ 触发阈值、自动动作、人工动作、证据产物；P27 门禁「至少 5 条就绪且可执行/留痕」已满足文档就绪。**闭环要求**：发版前至少一次演练登记于 Runbook §4 演练历史（日期/场景/结果/产物填实），否则不得视为资损 runbook 闭环。
