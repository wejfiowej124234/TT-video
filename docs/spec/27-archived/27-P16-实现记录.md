## P16 目标

**功能目标**（17 ②）：撮合阶段：浏览订单、查看行程与价格、聊天协商、确认最终版本后生成 snapshotHash，状态为 Confirmed。

| 维度 | 内容 |
|------|------|
| 链上/链下 | 链下 |
| 页面/模块 | **自由市场 `/market`**（Discover 列表能力；**`/discover`** 重定向）、Order Detail（未确认阶段）、聊天模块、确认最终版本 |
| 存储 | order_versions（版本历史）、messages（聊天）；snapshotHash 与 17 ②、19 一致 |

## P16 与现有实现对照

| 17 ② 要求 | 当前仓库状态 | 缺口/状态 |
