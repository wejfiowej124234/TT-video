### P8 验收步骤

1. **单测**：`cd frontend && npm run test`，预期 6 个测试通过（lib/api 3 个、lib/apiClient 3 个）。
2. **集成**：先启动 API（`cargo run -p traveltrust-api`，建议 `P3_CHAIN_OFF=1`），再执行 `./scripts/p8_frontend_api_flow.sh`，预期 /meta、注册、登录、me、guides、orders 均返回 200。
3. **前端主流程**：`cd frontend && npm run dev`，浏览器访问首页→登录→向导列表→订单列表，确认与 04 接口联调正常。
