本目录为 **TravelTrust 权威技术文档** 的唯一定位目录，便于 **AI 与人类** 直接找到实现与审计所依据的文档。

- **入口**：[00-文档索引.md](00-文档索引.md) — 文档列表、阅读顺序、版本表、发版前必做清单。
- **命名与排序规范**：[00-文档命名与排序规范.md](00-文档命名与排序规范.md) — 企业级命名、排序、迁移兼容规则。
- **范围**：00～27、08-0～08-5、13-1、企业级审计报告等；实现、发版、审计均以本目录为准。
- **临时文档**：开发过程产生的临时/草稿文档请放在 **`docs/` 根目录**（与 `spec/` 并列），不要放入本目录。

文档版本与最后更新见 [00-文档索引](00-文档索引.md) 内版本表。
