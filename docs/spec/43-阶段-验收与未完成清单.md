### 1.2 §五 验收勾选（CustomItineraryModal 模块）

**5.1 拆分与结构**

| □ | 验收项 | 结果 |
|----|--------|------|
| ☑ | 原超长文件已按 §2 分类分区拆分为多文件/多目录 | 已拆为 index + constants/types/utils + hooks + sections + DayCard |
| ☑ | 单文件行数 ≤ 500（建议 ≤ 400） | index ~275；TouristForm 418；GuideForm 398；其余未超 |
| ☑ | 单文件单一主职责 | 每文件一主组件或一 hook |
| ☑ | 常量/类型/配置已抽到独立文件 | constants.ts、types.ts、utils.ts 已存在并被引用 |

**5.2 质量与规范**

| □ | 验收项 | 结果 |
|----|--------|------|
| ☑ | 无重复 UI 或重复逻辑 | DayCard 抽成 TouristDayCard / GuideDayCard，复用 constants |
| ☑ | 依赖方向正确，无循环依赖 | App → 组件 → hooks/utils → lib |
| ☑ | TypeScript 无 any，关键类型共享 | types.ts 导出，无 any |
| ☑ | 样式符合 22/34 Token | 使用 var(--radius-*)、travel-* 等，无裸色裸圆角 |

**5.3 可测试与可维护**

| □ | 验收项 | 结果 |
|----|--------|------|
| ☑ | 抽出的 hook/纯函数可单测，且已有或计划有用例 | 已落地：useQuoteCalculation.test.ts、useItineraryForm.test.tsx |
| ☑ | 复杂逻辑有注释或与文档（如 42）对应 | 与 42-自定义行程弹窗 实现位置一致 |
| ☑ | i18n 与 a11y 符合 37、05 §9 | 文案 t(key)；表单/按钮有 aria-label 等 |

**结论**：CustomItineraryModal 满足 43 §五 5.1～5.3（5.3 第 9 项为「已有或计划有用例」，当前为计划），**该模块拆解达标**。
