## 2. 进阶闭环（9～17）— 含义 × 本仓库映射 × 状态判断

| # | 闭环 | 含义（一句话） | TravelTrust 映射（从哪验） | 状态判断（闭了 = 能复述） |
|---|------|----------------|------------------------------|---------------------------|
| **9** | **数据一致性** | 展示 = API = DB =（若涉链）链上投影，**不出现 A/B/C/D 四套真值** | **chain_off** 灌库与双写（**`startup/hydrate`**、**`try_persist_order_to_db`**）；**55** 与 **04** 列表/详情字段；**`GET /meta`** 与 **`order_chain_sync_status`** 等观测与 **EscrowDetail** 同源；**discover/orders** 与 **orders** 列表 **同形**（**04** 行） | **同一 `order_id`**：**UI 卡片**、**`GET /api/v1/orders/:id`**、**DB 行**、**链上事件投影**（若 scope 含链）**无互斥**；对账脚本或 **96-08** 抽检 **无未解释 diff** |
| **10** | **状态机** | 订单/争议等 **只能按规则迁移**；**所有入口** 同一套规则 | **03**、**01** 状态与缝、**04 §3.4** 写路径；**`chain_off/orders`** 与 **mutations**；**禁止**前端「越级跳态」**冒充**后端已放行 | **任意合法操作** 后：**状态字面值集合** 与 **04/03** 一致；**非法迁移** 在 **API** 层 **4xx/409** 且 **不脏写**；**E2E / 矩阵** 覆盖主迁移边 |
| **11** | **错误处理** | **失败 → 可读提示 → 可恢复路径**（重试/重登/降级） | **`mapApiReadError` / `mapOrderWriteError`**、**96-13 D4**；**501 `not_impl`** 与 **`chain_off_unavailable`** 在 UI **有句人话**；**幂等键** 与 **409** 文案（**96-18** / **04-附录**） | **主路径每类失败** 至少一条 **E2E 或 Vitest**；用户 **不**看到裸 **`error` 码**；**重试** 不造成 **重复扣款/双单**（与 **10、13** 交叉） |
| **12** | **权限与身份** | **前端隐藏 ≠ 安全**；**后端强校验** 谁读谁写 | **`extract_user` / session**、**`admin`** 路由；**96-17**、**64**、**87**；**`product_roles`**（**GET /meta**）与 **Me** 展示 | **越权请求** 一律 **401/403**；**向导/旅行者/商户/区域/管理员** 各取 **一条 API** 做 **负例**；**96-17 §4** 范围触发时 **有留痕或 N/A 一句** |
| **13** | **资金与托管安全** | **不丢、不重付、不绕托管** | **01**、**Escrow** 与 **04** 托管/释放/争议；**`mock-pay`** **仅**声明环境；**Stripe / webhook**（**TT-9618**）；**Idempotency-Key**（**01 §10**） | **Happy 路径** 与 **01/03/04** 叙事 **一致**；**支付意图** 与 **订单状态** **可审计**；**③** **另闸**（生产 PSP / 真链） |
| **14** | **观测与日志** | 能回答 **卡在哪一步、哪条 API、哪笔单异常** | **`x-request-id`**（**01 §9**）；**38**、**120**；**Admin observability**；**索引器 / reconcile**（**110**、**96-08**） | **任一 P0 故障演练**：**5 分钟内** 能从 **日志/指标/审计表** 追到 **request_id 或 order_id**；**关键写** 有 **审计或 DB 痕迹**（与 **17** 交叉） |
| **15** | **配置与环境** | **dev/staging/prod** 切换 **不串味**；**开关可解释** | **`.env.example`**、**96-10**、**`ONBOARDING_*` / `TRAVELTRUST_*`**；**`NEXT_PUBLIC_*` vs 密钥**；**Feature flag**（**04** / **admin flags**） | **换环境** 有 **清单**；**敏感键** **不进前端包**；**kill switch** 行为与 **96-10** **一致**（与 **96-18** 交叉） |
| **16** | **部署与回滚** | **能上线、能回滚、能恢复** | **20**、**140**、**`ops/RUNBOOK.md`**、**96-11**；**镜像/迁移顺序**（**07**） | **至少一条** **回滚演练记录**（或 **Runbook** 步骤 **Owner 已签**）；**DB 迁移** **可逆或有备份策略**（**96-06**） |
| **17** | **证据与审计** | **事后可证、可追责** | **`evidence/`** 约定（**solo-dev §3**）；**`forge_*.log`** 白名单；**合规审计表**（**onboarding**、**96-04**）；**Admin audit logs** | **本轮里程碑** 有 **证据目录或 JSON**；**删 spec / 改 registry** 走 **四门**（**08 / 98 / STATUS / 96-索引**）；**与 3 文档规范闭环** **可对拍** |
