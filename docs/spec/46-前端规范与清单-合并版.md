## 一、分层规划

### 1.1 分层总览

| 层级 | 路径 | 职责 | 可依赖 |
|------|------|------|--------|
| **App** | `frontend/app/` | 路由、layout、page；组合 components，最小业务逻辑 | components、lib、hooks |
| **Components** | `frontend/components/` | 按域 UI + 共享组件；含域内 hooks（如 useCommunityFeed） | lib、dapp（仅链上相关）、hooks |
| **Hooks（顶层）** | `frontend/hooks/` | 跨域复用 hook（如 useFocusTrap） | lib |
| **Lib** | `frontend/lib/` | API 客户端、类型、常量、纯工具、i18n 数据 | 无（不依赖 app/components） |
| **Dapp** | `frontend/dapp/` | 链上合约、ABI、useEscrowActions 等 | lib、abis |

**依赖规则（单向）**：App → Components、Lib、Hooks；Components → Lib、Dapp、Hooks；**禁止** components 引用 `@/app`、**禁止** Lib 引用 Components/App/Hooks；Dapp 仅被业务组件间接使用。

### 1.2 各层细则

- **App**：仅做路由、layout、page 组合与取数；单文件建议 ≤300 行，超则抽 section 或域内 hook。
- **Components**：按域（community、market、escrow、landing、me、did-rank、trust）+ 根目录共享；复杂模块单目录多文件、单文件 ≤400 行。
- **Hooks**：`frontend/hooks/` 跨域复用；域内 hook 放对应域下；`dapp/hooks/` 仅链上。
- **Lib**：api、apiClient、countries、cityDetails、i18n、类型、纯函数；禁止引用 components、app、hooks。
- **Dapp**：abis、useEscrowActions；由 EscrowDetail 等组件间接使用。

### 1.3 新增代码归属（决策表）

| 场景 | 放置位置 |
|------|----------|
| 新页面/新路由 | `app/<route>/page.tsx`，layout 放 `app/<route>/layout.tsx` |
| 页面内一块 UI 区块 | 对应域下 section 或组件，如 `components/market/XXXSection.tsx` |
| 多页复用 UI | `components/` 根目录或共享子目录 |
| 仅某域使用的状态/逻辑 | 该域下 `useXxx.ts` |
| 多域复用的 hook | `frontend/hooks/` 并 `hooks/index.ts` 导出 |
| 新 API/类型/常量 | `lib/apiClient` 或对应 lib 子模块 |
| 链上读写 | `dapp/hooks` 或 dapp 下新模块，由 components 调用 |

### 1.4 当前分层优化状态

已落实：App → Components → Lib 单向；dapp 隔离；frontend/hooks 存在；apiClient、communityMockData 已按域/场景拆分；各层单文件 ≤400 行或已拆子模块。持续遵守：新加功能按 §1.3 放码；禁止 Lib 引用 Components/App。
