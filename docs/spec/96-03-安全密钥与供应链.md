## §1 P0 · 生产必查

| # | 生产必查项 | 证据 / SSOT | 执行要点 |
|---|------------|-------------|----------|
| 3.1 | **渗透 / SAST / CVE** 闭环或 **已接受风险** 登记 | **[缺口官方总表](缺口与待补-官方总表.md)**；`cargo audit` / `npm audit` / SBOM | 仓库根：`cargo audit`；`frontend`：`npm audit --omit=dev`（或团队约定等价）。**高危未修**须在官方总表有 **NO-GO / Target** 与 Owner。 |
| 3.2 | **`INTERNAL_API_SECRET`**、**`/internal/*` 禁公网** | **[go-live](../go-live-checklist.md) §3.4** | WAF / API Gateway **拒绝**公网 `*/api/v1/internal/*`；内网调用须 **`X-Internal-Api-Secret`**（与 **`.env.example`** 一致）。 |
| 3.3 | **CORS / STRICT_SSOT / SSOT_SHA256** 生产值与发布物一致 | **go-live §3.2～3.3**；**08-3** | **`CORS_ORIGINS`** 为真实前端 origin；**`STRICT_SSOT=1`** 时 **`SSOT_SHA256`** 与构建产物同源。 |
| 3.4 | **Secret 轮换** 与 **[230](230-阶段Secret与Key管理系统.md)** 一致 | 轮换工单（脱敏） | DB、JWT、INTERNAL、云厂商密钥：**轮换窗口 + 回滚** 已演练或书面等效。 |
| 3.5 | **Admin 强认证、反自审、高危双人** | **[70](70-管理员系统开发文档.md)**；审计日志抽样 | 抽样 **admin 操作** 与 **订单/赔付/冻结** 类路径：**双人 / 工单** 符合 **70** 与内审结论。 |
| 3.6 | **媒体签名 URL、证据桶** 默认私有 | **[270](270-阶段文件媒体证据存储系统.md)**、**[08-3](08-3-参数与门禁表.md)**、**[08-4](08-4-对外口径包.md)** | 桶策略 **无** public-read；**预签名 TTL** 与 **删除/协助** 口径见 **08-4**。 |
