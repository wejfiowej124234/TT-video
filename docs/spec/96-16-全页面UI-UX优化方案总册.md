## §2 分域「通用优化方案」（适用于域内所有页面）

以下每条均为 **该域内每页** 的默认检查；页面特例在 **code-maps/62-补充-***、**29/31/89/70** 等专项文中展开。

### 2.1 公共与品牌（`/`、`/traveltrust`、`/network`、`/trust`、`/help`、`/discover`、`/did-rank`、`/terms*`、`/privacy`、`/staking`）

- **D1**：营销区默认 **X/G**；任何「收益 / 托管已确定」类表述须法务口径。  
- **D2/D3**：与 **88** 五主路由一致；Landing 真值 **`app/(home)/page.tsx`**（非根 `app/page.tsx`）。  
- **D7/D8**：Hero 动效遵守 **86**；禁止 **F 区**强粒子。  
- **D5**：`traveltrust`、`header_*`、法务页双语完整。

### 2.2 认证（`/auth/*`）

- **D4/D6**：表单错误聚焦、验证码/邮件链接过期提示、**密码强度**可见。  
- **D5**：校验文案全键；错误码 → 用户句（与 **96-13** 一致）。  
- **D11**：登录失败不泄露账户枚举（文案与 **04** 一致）。

### 2.3 账户与个人（`/me*`）

- **D1/D10**：钱包状态与顶栏一致；**中英混排**（如 `Wallet · 已连接`）有 i18n 策略。  
- **D3/D6**：设置项表单 **label**、敏感操作二次确认。

### 2.4 市场 · 订单 · 支付 · 托管 · 争议（`/market*`、`/orders*`、`/pay`、`/itinerary/new`、`/escrow*`、`/disputes*`）

- **D1**：整域 **F 偏置**；价格、币种、链名、状态与 **53/04** 一致。  
- **D4**：订单列表/详情 **中间态**（支付中、链上确认中）可理解。  
- **D10**：地址复制、网络切换、交易失败可恢复路径。  
- **专项**：[29](29-自由市场-撮合控制台规范.md)、[94](94-自由市场-商家橱窗与旅行收购-链上托管技术规格.md)、[42](42-自定义行程弹窗-游客与向导UI设计与算法.md)。

### 2.5 社区（`/community*`）

- **D1/D4**：举报、封禁、合规错误与 **OFAC** 话术；Feed 降级态。  
- **D3/D7**：瀑布流/图片懒加载；键盘可达。  
- **专项**：[31](31-TT社区页面设计.md)、[160](160-阶段开发内容与社区系统.md)。

### 2.6 治理（`/governance*`）

- **D1**：提案经济影响只读展示与 **89**、**governance-token** 一致，避免「已执行」误导。  
- **D2**：IA 与 **[89](89-治理UI-全球旅游市场治理控制台设计规格.md)** 对齐；移动端压缩布局。  
- **D10**：投票/委托与链上只读数据一致。

### 2.7 向导与内容（`/guides*`、`/guide*`）

- **D4**：列表空态、城市筛选、**D7** 图片网格。  
- **D1**：向导服务展示不涉及资金承诺越界。

### 2.8 管理后台（`/admin*`）

- **D6/D11**：表格键盘导航、只读/高危写操作二次确认（与 **70** 一致）。  
- **D4**：长列表分页、导出状态、**reconcile** 等大作业进度。  
- **D1**：财务/索引器页默认 **F 偏置** + 审计友好布局。
