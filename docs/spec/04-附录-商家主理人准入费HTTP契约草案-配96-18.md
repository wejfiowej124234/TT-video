## 1. 命名空间与鉴权总述

- **前缀**：建议统一 **`/api/v1/onboarding/`**（**公开读报价** 可例外为 **无需登录**；**写路径** 一律 **须登录**，与 **[04 §三 3.1](04-后端与API.md)** **Session** 一致）。  
- **幂等**：所有 **POST** 写路径 **须** 支持 **`X-Idempotency-Key`**（与 **[93 §2.4.1](93-全站功能验证矩阵-域别回归清单.md)**、**基线 F-028** 叙事一致）。**当前实现（PG 已挂载）**：**`POST …/payment-intents`** **必须** 同时带 **`Idempotency-Key` 或 `X-Idempotency-Key`**（非空、**≤256** UTF-8 字节，超限 **400** **`invalid_onboarding_idempotency_key`**）与 **`Content-Type: application/json`** 体（**`role`** 必填；**`sku` / `return_url`** 可选），否则返回 **400** 及 **`missing_onboarding_idempotency_key` / `invalid_body`**。**`idempotency_key`** 在库中 **全局唯一**：**同一键** 已被 **其它用户** 使用或与已存 **`role` / `sku` / `fee_schedule_version`** 不一致 → **409** **`onboarding_idempotency_conflict`**。  
- **合规筛查（可选 · 非 OFAC 全量）**：**`ONBOARDING_COMPLIANCE_SCREENING_MODE`** — 未设或 **`env_email_denylist`** / **`env_denylist`** / **`default`** → 仅 **`ONBOARDING_COMPLIANCE_EMAIL_DENYLIST`**（逗号分隔；**`users.email`** 转小写后 **`contains`** 任一子串）命中时：**`POST …/payment-intents`** 与 **`POST …/role-confirm`** 在 **有 `db_pool`** 时返回 **403** **`onboarding_forbidden_sanctions`**；**`off`/`none`/`disabled`** → **不**应用子串拒服（**须**书面闸门方可在生产启用）；**`stub_reject_all`/`stub_reject`** → 凡登录写路径 **403**（**IT**；**禁止**生产）；**`list_file`/`email_list_file`/`static_list_file`** → 须 **`ONBOARDING_COMPLIANCE_EMAIL_LIST_FILE`** 指向 UTF-8 名单（每行一邮箱，`#` 注释；**整邮**匹配，大小写不敏感；**≤512KiB** / **≤100k** 行）；命中同 **403**；**路径缺失/不可读/非合法 UTF-8/超限（字节或行数）** → **503** **`onboarding_compliance_screening_unavailable`**（**stderr** **`event`**=`onboarding_compliance_screening_unavailable`；**不**冒充制裁命中）。命中（或 stub）时另写 **stderr** **`audit_schema`**=`traveltrust.onboarding_compliance.v1`（**`decision`/`screening_tier`** 机读；**无** email；**`x-request-id`** → **`request_id`**）并 **best-effort** 插 **`onboarding_compliance_audit_events`**。**Admin 只读**：**`GET /api/v1/admin/onboarding/compliance-audit-events`**（**[04 §3.5](04-后端与API.md)**；**PG·IT**：**`matrix_93_b_onb_006`**、**`006b`**、**`006c`**、**`006d`**、**`006e`/`006f`/`006g`/`006h`/`006i`/`006j`/`006k`/`006l`/`006m`/`006n`/`006o`**、**`matrix_93_admin_onb_028`**，须 **`DATABASE_URL`**；命令汇总 **[96-18 未完成 · §4](96-18-未完成清单与多维检查.md#9618-cmd-cheatsheet)**；**Runbook** **[TT-9618 §3.4.1](../runbook/TT-9618-onboarding-local-testnet.md)**）。  
- **Kill switch**：**`ONBOARDING_PAYMENT_INTENTS_DISABLED=1`** 时 **仅** **`POST …/payment-intents`** → **503** **`onboarding_payment_intents_disabled`**。  
- **报价 GET 专桶限流**：**`ONBOARDING_QUOTE_RATE_LIMIT_PER_MINUTE`**（默认 **30** / **60s** 滑动窗口，与 **`API_RATE_LIMIT_PER_MINUTE`** 全局限流**叠加**；**0** = 关闭本专桶）超限 → **429** **`onboarding_quote_rate_limited`**。  
- **内部 Webhook（已定稿 · G3）**：**`POST /api/v1/internal/onboarding/payments/webhook`**（**须** **`INTERNAL_API_SECRET`**，与 **`internal/*`** 同源）。**JSON 体**（**`schema_version: 1`**）字段上限与 **可选 HMAC** 见 **§2** **F-036**。**可选边缘硬闸**：**`ONBOARDING_INTERNAL_WEBHOOK_ALLOWLIST_CIDRS`**（非空时 **403** 若 **`X-Forwarded-For`** 首跳 / **`X-Real-Ip`** 不可解析或不在 **IPv4** 白名单）；**`ONBOARDING_INTERNAL_WEBHOOK_REQUIRE_HTTPS_FORWARDED=1`** 时须 **`X-Forwarded-Proto: https`**。**mTLS** 在 **Ingress / 网关** 终止，应用层**不**校验客户端证书（**可复制示例**：**[`ops/kubernetes/examples/onboarding-internal-webhook-ingress-nginx.example.yaml`](../../ops/kubernetes/examples/onboarding-internal-webhook-ingress-nginx.example.yaml)**、**[`ops/kubernetes/README.md`](../../ops/kubernetes/README.md)**、**[TT-9618 §3.5](../runbook/TT-9618-onboarding-local-testnet.md)**）。**Stripe 公网 Webhook（可选）**：**`POST /api/v1/hooks/stripe/onboarding`** — **不**使用 **`INTERNAL_API_SECRET`**；**须** **`Stripe-Signature`** 与 **`TRAVELTRUST_STRIPE_WEBHOOK_SECRET`**（**`whsec_…`**）；**`payment_intent.succeeded`** / **`checkout.session.completed`**（**`payment_status=paid`**）与内网 webhook **同源** **`apply_payment_webhook`**；**`charge.refunded`** 按 **Charge** 上 **`amount`/`amount_refunded`** 分支：**部分**（**`0<amount_refunded<amount`**）仅写 **`onboarding_payment_events`**（**`stripe_charge_refund_partial`**），**不**改 **`entitlements.status`**；**全额**（**`amount_refunded≥amount`** 且均为正）推进 **`paid`→`refunded`**；**`charge.dispute.funds_withdrawn`** 推进 **`paid`→`revoked`**（细节见 **§2 F-036-EXT**）。**`read_contract_route_guard`** 仅覆盖 **Admin/Governance GET** 白名单，**不**要求本路径注册于该表。**Ingress 可复制示例（公网 TLS 终止）**：**[`ops/kubernetes/examples/onboarding-stripe-webhook-ingress-nginx.example.yaml`](../../ops/kubernetes/examples/onboarding-stripe-webhook-ingress-nginx.example.yaml)**（签名校验仍在 API）。  
- **运维闭环（local / testnet · 非 SSOT 替代）**：**[TT-9618](../runbook/TT-9618-onboarding-local-testnet.md)**（**§3.1** **②** 检查表 + **§3.2** **Stripe 公网 webhook** + **§2～§5**）— 内网头 **`X-Internal-Api-Secret`**、**JSON webhook** 与 **HMAC** 须同 **raw body** 字节对拍、**Stripe CLI**（**`stripe listen`**）、推荐 **`cargo test` / `npm run build` / Playwright** 命令；**禁止**浏览器直打 **`/api/v1/internal/*`**。本 bullet **不**收窄上文 **HTTP 字面** 真值。
