## §1 真源层级（与 07 / 04 对读）

1. **代码与脚本门禁**（`crates/*`、`scripts/gates/*`、`.github/workflows/*`）为 **行为真源**。  
2. **spec 内 A 类**（见 **[盘点 §1 · A/B/C 分类](../spec-path-dependency-migration-inventory.md#inv-classification-abc)**）为 **契约与叙事真源**，**handbook** 仅 **导读（C）**。  
3. **`git rm docs/spec/...`** **不得**绕过 **[engineering/08 §2](../handbook/engineering/08-文档与spec迁移台账.md#mig-delete-policy)** 与 **STATUS P-A～P-D**。
