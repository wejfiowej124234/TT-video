## 2. 3D 实现证据矩阵

### 2.1 3D引擎与主组件

- `frontend/components/did-rank/Web3SciFiBackground.tsx`
  - `@react-three/fiber` + `three`
  - 粒子场、噪声Shader、视差组
  - WebGL可用性检测（canvas + webgl/webgl2）
  - `DEFAULT_WEB3_SCIFI_BACKGROUND_CONFIG` 与移动端配置合并

- `frontend/components/did-rank/web3SciFiBackgroundConfig.ts`
  - 默认配置与移动端配置分离
  - 支持粒子数、噪声、opacity、parallax强度等参数化

### 2.2 3D 页面落点（2026-03 真值）

- **`frontend/app/did-rank/page.tsx`**：**不**再使用 `Web3SciFiBackground`（**88**）。
- **`frontend/app/community/layout.tsx`**：**壳层不**挂载 `Web3SciFiBackground`（**88**）；与旧版「仅 Feed 启用 3D」描述不一致处以本行为准。
- **`frontend/components/me/MePageBackground.tsx`**（用于 **`/community/me`** 等）：仍可能挂载 `Web3SciFiBackground` + 动效网格（与壳层策略叠加，**88 §二**）。
- **`frontend/app/community/tt/page.tsx`**：以代码为准；若仍含 R3F，须在 PR 中与 **88** 同批说明。
- **`frontend/app/traveltrust/*`**：**TravelTrustAmbientCanvas** 等环境粒子（**85**）— 主 3D/粒子情绪层之一。

### 2.3 非 3D 但符合情绪层的实现

- **`frontend/app/(home)/page.tsx`**（路由 **`/`**）：Landing 使用国家相关**摄影全屏底** + vignette + **`bg-web3-dot-grid`** + 玻璃表单/结果区，**不含** R3F（**88**、**86 §6.1**）。**勿**与已移除的 **`app/page.tsx`** 根路径混读。
- **`frontend/app/market/page.tsx`**：市场页 **`WarmRouteFieldBackdrop`** + 玻璃容器、模糊与层级，**不含** 全屏 R3F（**88**）。

## 3. 与 21 文档条款对齐

### 条款: 3D 仅情绪层，不进资金区

- 代码符合：Escrow 页面未引入 `Web3SciFiBackground`。

### 条款: 3D 要有性能预算与降级

- 代码符合：
  - 社区布局对 Feed/子路由差异化处理（减少卡顿）
  - 3D组件内有 WebGL能力检查与移动端配置

### 条款: Landing Hero 应承载 3D（21 愿景向）

- **当前代码（真值）**：
  - Landing 为 **摄影 Hero + 玻璃**（**`(home)/page.tsx`**），**非** 全屏地球 R3F；与 **21** 部分条文为**愿景 vs 实现**关系。
  - 验收与截图对齐以 **88 §一**、**86 §6.1**、**25 §二十一** 为准；若引入 §5.2 级地球，须 **07 §二 2.4** 与产品排期。

结论:
- 建议将 21 条款从“Landing必须3D”调整为“Landing可3D，默认静态+可选3D增强”。

## 4. 性能与稳定性审视

已落地优点:
- 动态 import 降低首屏阻塞（多处 `dynamic(..., { ssr: false })`）
- 3D只在高价值场景开启
- 社区子路由降级策略明确

待加强:
- 缺少统一性能预算文档化指标（FPS、LCP、TTI门限）
- 缺少 Landing 3D A/B 开关（当前等价于“永久静态”）

## 5. P0/P1 修复建议

P0:
1. 在 `21` 文档新增“落地优先级”:
- L0: 静态图+glass（默认）
