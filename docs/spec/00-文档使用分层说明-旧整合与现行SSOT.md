## 四、**需要整合**的含义——以后怎么写，避免再分裂

**目标状态**：**一个流程入口（07）+ 一张门禁表（治理总册 §8.3）+ 契约真源（04/14）+ 订单执行（53）**。

| 做法 | 建议 |
|------|------|
| **不要再写**新的「全库串联总篇」替代 07 | 新串联类内容写入 **07 对应节**（多为 §零 / §五） |
| **多份企业级 UI/页面审计**（28/29/31/45/50…） | **不强制合并成单文件**（体积与职责不同）；新结论回填 **13-1 / 53 / 04** 或 **缺口总表** |
| **`140～550` 阶段文** | **专题 SSOT**；全局 Wave 与依赖只信 **07 §零 0.4**；阶段文内「文档串联变更」已统一指向 **07 + 00 索引** |
| **发版规则** | **07 §四 4.3** 与 **08 / 15 附录〇** 保持一致表述，避免两套门禁 |
