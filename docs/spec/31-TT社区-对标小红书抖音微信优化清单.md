## 一、对标产品概览

| 产品 | 核心能力（对 TT社区 的参考点） |
|------|--------------------------------|
| **小红书** | 图文/多图笔记、话题与搜索、收藏夹、关注流、评论与回复、个人主页与「我的收藏」、发现 Tab + 关注 Tab。 |
| **抖音** | 短视频单列沉浸、上下滑、推荐/关注、点赞/评论/转发/收藏、话题与热搜、私信、消息中心（赞/评/@）。 |
| **微信** | 好友与群聊、私聊气泡、朋友圈图文/短视频、消息列表未读红点、「我」的资料与设置。 |
| **Instagram (INS)** | **多图轮播帖（Carousel）**、**Stories 快拍（24h）**、**Reels 短视频**、**Explore 发现页**、**个人主页网格（帖子/已保存/被@）**、**#标签 + 地点**、**私信 DM（表情/分享到动态）**、**收藏夹/合集**、**活动/通知中心**、**简介+链接**、**归档/仅自己可见**、**双击点赞**。 |

TT社区 定位为**旅行 UGC 社区**，不做支付与撮合；风格与 DID 赛博风统一。以下按「内容形态」「发现与筛选」「互动」「社交与消息」「个人主页与我的」「体验与性能」六类对照，并标出**当前状态**与**建议优化**。

## 二、内容形态（对标小红书 + 抖音 + INS）

| 能力 | 参考产品 | TT社区 当前 | 优化建议 | 优先级 |
|------|----------|-------------|----------|--------|
| **多图帖子（Carousel）** | INS/小红书：单条多图轮播，左滑/点指示点 | ✅ 卡片已支持 `media_urls` 轮播、指示点、左右箭头 | 发帖端：PublishDrawer 支持多图上传、排序、删除、回显；接后端 `media_ids[]` | P0 |
| **短视频** | 抖音 Reels / INS Reels：即播、进度条、静音/全屏 | **Partial（①）** — `PostDetailDrawer` 内 `<video>` + poster；Feed 点击进详情抽屉（**非**旧 overlay 主路径）；MinIO 未就绪时发布受限 | 列表内静音自动播、CDN/HLS | P0→**① Partial** · **② COM-②-8** |
| **快拍 / Stories（24h）** | INS：竖版全屏、24h 消失、可挂链接/投票 | ❌ 无 | 可选：旅行「今日快拍」竖版、24h 可见；需单独列表与播放逻辑 | P3 |
| **图文混排** | 小红书：正文中插图 | 当前为「媒体区 + 文案块」 | 若产品需要正文内插图，再做富文本；否则维持现状 | P3 |
| **时长与大小限制** | 抖音/INS：视频时长与上传大小限制 | **✅（①）** — `PublishDrawer` 时长/大小校验 + i18n；429/retry-after 见 [31 §7.4](31-TT社区-问题与优化清单-功能与排版.md) | — | P1→**① 已闭** |
| **封面与首帧** | 抖音/INS：视频可选封面 | **Partial（①）** — `cover_url` + Feed/详情 poster；发帖抽屉本机选封面（§7.4 P0-A） | 托管上传后自动填封面 | P2→**Partial** |

## 三、发现与筛选（对标小红书发现 + 抖音推荐 + INS Explore）

| 能力 | 参考产品 | TT社区 当前 | 优化建议 | 优先级 |
|------|----------|-------------|----------|--------|
| **推荐 / 关注 Tab** | 通用 / INS Home | ✅ 推荐 / 关注；关注流按 MOCK 过滤 | 接后端：推荐流算法；关注流按关注列表拉取 | P2 |
| **最新 / 最热排序** | 小红书/INS | ✅ 最新、最热（likes+comments） | 后端 `sort=latest\|hottest`；最热可时间衰减 | P2 |
| **按类型筛选** | — | ✅ 全部 / 照片 / 视频 / 美食 / 旅游 | 保持；可选「纯文字」 | P3 |
| **按目的地筛选** | INS 地点 / 小红书地点 | ✅ 从帖子抽取目的地 pill | 后端 `destination` 参数；热门目的地置顶 | P2 |
| **搜索** | 小红书/抖音/INS：关键词搜帖子/用户/话题/地点 | **Partial（①）** — Feed 客户端过滤 + `#` 话题/`tag=`；空态 `community_search_empty` | 全站搜索 API（用户/地点） | P1→**Partial** · **②** |

| **热门/推荐侧栏** | 抖音/INS：可能认识、推荐 | **Partial** — 桌面 **`CommunityFeedDesktopAside`** 已有热榜/推荐关注 | 桌面端可选右侧「热门目的地」「推荐关注」 | P3 |

## 八、优先级汇总与建议排期（整合 INS 后）

| 优先级 | 建议内容 | 说明 |
|--------|----------|------|
| **P0** | 评论接 API（一级+二级、分页）、多图发帖与展示、视频真实播放 | 内容与讨论闭环。 |
| **P1** | 点赞/收藏/关注持久化、私信会话与消息 API、发帖上传（多图+时长大小校验）、Feed 分页、搜索、异常态与重试、我的帖子/收藏接后端 | 交流与数据闭环；体验达标。 |
| **P2** | 推荐流/关注流后端、话题聚合、目的地强化、**个人主页网格布局**、**简介/链接**、**双击点赞**、下拉刷新、分享扩展、作者统计 | 发现与社交深化；INS 式浏览与互动。 |
| **P3** | Stories/快拍、发现页 Explore 网格、消息中心（赞/评/@）、@ 提及、转发到私信、私信分享帖子、被 @ 列表、归档/仅自己可见、多收藏夹、隐私设置、话题房间 | 增强留存与扩展。 |
