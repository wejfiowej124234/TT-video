# 仓库提交范围：该上传 / 不该上传

### 读前摘要

| 你要找什么 | 单源 |
|------------|------|
| **应提交路径** | 下表 **应上传** |
| **勿提交（密钥、GO 证据包等）** | 下表 **不应上传** + 根目录 **`.gitignore`** |
| **提交前 3 项自检** | **提交前自检**（与 **[15 附录〇 第 17 项](15-多维度文档与技术检查报告.md#发版前勾选总表)** 一致） |

## 应上传（提交到 GitHub）

| 类型 | 路径/说明 |
|------|------------|
| 代码 | `crates/`（core、api；crates/web 为设计态仅 README，可提交）、`contracts/`（含 README） |
| 文档 | `docs/spec/` 下 00～27、08 系列、企业级审计报告等；`docs/` 根目录临时文档 |
| 运维 | `ops/RUNBOOK.md` |
| 证据说明与模板 | `evidence/README.md`、`evidence/GO_YYYYMMDD_template/`、`evidence/GO_placeholder/` |
| 脚本 | `scripts/` 下全部 |
| CI/PR | `.github/`（PR 模板、workflows） |
| 根配置 | `README.md`、`Cargo.toml`、`.gitignore`、`.env.example`（若有） |

## 不应上传（已由 .gitignore 排除）

| 类型 | 路径/说明 |
|------|------------|
| 构建产物 | `target/`、`dist/` |
| 环境与密钥 | `.env`、`.env.*`、`*.pem`、`*.key`、含 `credentials` 的文件 |
| 真实 evidence bundle | `evidence/GO_YYYYMMDD/`（8 位日期目录，过门时产出，可能含内部信息） |
| 备份/临时 | `*.rs.bk`、`*.bak`、`*.tmp` |
| 锁文件（可选） | `Cargo.lock` 已忽略；若希望可复现构建可改为提交 |

## 提交前自检

**以下已按示例勾选**；每次提交或发版前须逐项确认，与 [15 附录〇 发版前勾选总表](15-多维度文档与技术检查报告.md#发版前勾选总表) 第 17 项一致。

- [x] 未包含 `.env` 或真实密钥
- [x] 未包含真实姓名/邮箱/内部链接（除占位说明外）
- [x] `evidence/` 下仅 README、模板、placeholder，无真实 GO_ 日期目录

文档版本与最后更新见 [00-文档索引](00-文档索引.md)。
