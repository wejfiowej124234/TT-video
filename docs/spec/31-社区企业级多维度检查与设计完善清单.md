## 6. 页面切换与流畅度（已做优化）

| 问题 | 处理 | 说明 |
|------|------|------|
| 社区内 Tab 切换白屏 | 增加 `app/community/loading.tsx` | 与赛博风一致的骨架，Next 在切换至 messages/friends/me 等时先展示该 loading |
| 社区内切换后滚动位置错位 | 在 community layout 内 `useEffect` 监听 pathname，`window.scrollTo(0)` | 每次 Tab 切换将滚动条置顶，避免「半屏」残留 |
| Feed 首屏骨架过久 | 将骨架展示延迟由 400ms 改为 180ms | 内容更快露出，仍保留短暂骨架过渡 |
| 市场 / DID 切换无中间态 | 增加 `app/market/loading.tsx`、`app/did-rank/loading.tsx` | 从顶栏进入市场或 DID 时先出 loading，再出正文 |

**可进一步考虑**：根级 `loading.tsx` 已存在；若整站希望统一过渡，可对关键路由补全 loading；View Transitions 需按 Next 15+ 文档选用（实验特性或自包过渡层），若需淡入淡出可自包一层。

## 7. 小结

- **已闭环**：登录态校验、关注流过滤、作者主页、Feed 骨架、prefer-reduced-motion（globals 统一）、i18n、基本无障碍与风格一致；页面切换 loading 与滚动置顶已做。
- **剩余缺口**：真实视频/收藏/好友/关注/发帖评论 API、举报与审核策略、上传安全、部分异常态与反馈细节。
- **设计可完善**：发帖成功 toast、媒体 onError、关注空态 CTA、图片懒加载、抽屉焦点与 Esc、举报入口与规范链接（均已实现）。

实现与发版时可按 **§4 优先级** 与 **§2/§3** 逐项补齐；后端 04 落点后优先对接 API 与内容审核。
