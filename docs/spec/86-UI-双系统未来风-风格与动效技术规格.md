- **一句话**：86 回答 **「看起来像什么、在允许分区内动效如何表现」**；**「能做什么、数据从哪来」** 仍以 **04 / 13-1 / 对应业务规格** 为准。

## 0. 设计目标与企业级 SSOT

### 0.1 设计目标

TravelTrust 界面是 **旅游体验 + Web3 协议表达 + 金融信任** 的融合，而非单一「旅行站」或单一「DeFi 控制台」。

| 目标 | 描述 |
|------|------|
| 旅游体验 | 轻松、明亮、激发出行意愿 |
| Web3 表达 | 科技感、连接感、可感知网络 |
| 协议信任 | 严肃、可读、操作可预期 |
| 动画 | **增强叙事与反馈**，不阻塞主任务、不掩盖风险信息 |

**规则 2 — Token 统一（22 vs 86）**

- **禁止** 代码库长期双轨 Hex。  
- **86 颜色 → 映射到 [22 §一点五](22-Design-Tokens-旅游Web3融合体系-v1.0.md) 命名体系**：**Travel 轴** 接 **86 §2.1**；**Trust 轴** 保持 **银行灰语义**；**蓝紫渐变** 走 **`--cta-gradient-*`**，**不占用 `--trust-*`**。

**规则 3 — 动效统一（25 vs 86）**

- **页面级**（Hero、滚动叙事、section reveal）：**约 600ms**（与 **25**、**`globals.css` `.motion-main`** 一致）。  
- **组件级**（按钮 hover、click、卡片微交互）：**&lt; 300ms**（本文 **§5.1**）。  
- **二者同时成立**：叙事慢、控件快。

**规则 4 — 渐变 / glow / 数字动画合法化**

- **仅允许**：**Experience**（**`/`**、**`/traveltrust`**；**`/network`** 为 **`/traveltrust`** 别名、**永久重定向**，**分区与顶栏**同 Experience，**不**单独作为粒子/Hero 画布宿主）**且** **非资金决策 UI**；**Business** 仅 **克制** 子集。  
- **禁止**：**Escrow**、**支付流**、**争议** 及任何 **主签名/主扣款** 操作区。  
- **已写入** **[13 §一 1️⃣ 补充款](13-协议级UI设计宪法.md)** 与 **21 §1.2 例外**，评审以 **13** 为终裁。

**规则 5 — 28 的处理**

- **28** → **叙事结构参考 + 信息架构 SSOT**（Cinematic flow、三层融合、组件清单逻辑）。  
- **86** → **Experience 视觉 SSOT**。  
- **实现策略**：保留 28 的结构与文案层级，用 86 替换 **Experience** 的外观与动效参数（经 **22** 赋值）。

### 1.3 分层映射（摘要）

- **Experience + 强叙事融资入口**：`**/`**、**`/traveltrust`** — 允许粒子、大范围渐变、Hero 级动效（仍须满足 **§9 性能**）；**`/traveltrust`** 内容与合规叠加 **85**。
- **Business**：**`/market`** — 卡片网格、筛选、轻动效；**不做** 重 3D 场景。
- **TT / DID**：**`/community/*`**、**`/did-rank`** — **内容区** 赛博霓虹以 **30 §4.2～4.4** 为准；**页身基座**（暖场 + 静态赛博叠层、**壳层不挂**全屏 Three）以 **[88](88-五主路由页身实现快照与UX缺口审计-20260330.md)** 为准；**禁止** 把本区做成 **86** 首页级粒子/Hero（易与 **13**「社区不做 28 玻璃 Hero」冲突）。
- **Protocol / 资金**：订单、托管、争议、支付 — **禁止 86 装饰特效**；Escrow **协议控制台区** 视觉以 **53 + 30 §4** 为准，**签名/扣款主操作区** 仍 **13** 银行级。
- **治理 / Ops**、**中性页** — 不动画叙事抢戏；全站 **22** 键名一致。

**结论（是否「全站对齐 86」）**：**否** — **86** 仅对 **Experience + Business（上表前两档）** 担任**视觉主纲**；其余档位为 **30 / 13 / 53 / 70 / 13-1** 主纲，**86** 只划定 **「不得滥用 Experience 特效」** 的边界。详见 **§6.0** 索引表。

## 5. 动画系统（统一规范）

### 5.1 全局原则

- 单次交互动效 **&lt; 300ms**（页面级缓动可略长，但须可中断、不阻塞点击）。
- **尊重 `prefers-reduced-motion: reduce`**：粒子关闭或减配、渐变改为静态、数字直接显示终值。
- Protocol 区默认 **关闭** 粒子与装饰性连线。

### 5.2 粒子系统（仅指定页面）

| 项 | 值 |
|----|-----|
| **允许路由** | **`/`**、**`/traveltrust`**（**`/network`** → **`/traveltrust`**，**不**常驻粒子画布；与 **§0.3 Experience**、**§6.0** 顶栏一致） |
| 数量 | **80** |
| 粒子大小 | **1～3px** |
| 速度 | **0.2～0.6**（相对单位，实现时映射到 R3F / canvas 帧率稳定区间） |
| 颜色 | 蓝 **#3B82F6**、紫 **#8B5CF6**、绿 **#10B981**、橙 **#F59E0B** |
| 连接线 | **开启**（近邻连接，密度上限由 **§9** 约束） |
| 透明度 | **0.3** |

### 5.3 连接线动画（核心特效）

| 表现 | 说明 |
|------|------|
| 点-点连接 | 自动连接最近节点或按图数据连边 |
| hover | **高亮路径**（线宽 + 亮度 + 可选脉冲） |

**用途：** 3D/2.5D **地球**、**国家/区域节点**、**融资流示意**（与 **85** 信息架构兼容即可）。

### 5.4 资金流动画（重点）

| 表现 | 说明 |
|------|------|
| 渐变线 | **A → B** 方向流动（SVG/CSS gradient animation 或 WebGL 折线，择一） |
| 用途 | **`/traveltrust`** 融资叙事、**Escrow 流程教育页/营销切片**（非托管操作表单内） |

### 5.5 数字动画

| 方式 | 说明 |
|------|------|
| 0 → 目标值 | 滚动/odometer，**easing** 出库结束略减速 |
| 用途 | 收益、融资金额、**`/did-rank`** 榜单数值等 |

### 5.6 卡片交互（Business 为主）

| 事件 | 规范 |
|------|------|
| hover | `scale(1.03)`、阴影增强、**边框微发光**（opacity 低） |
| click | `scale(0.98)` |
| transition | **约 0.2s ease** |

**`/did-rank` 补充：** **竖脊** 切换旅行者/向导/商家；**内页** **TOP3 突出** → **列表**。**脊签切换** 可用 **`framer-motion`** 横向翻页感（**[30 §4.3](30-DID排行榜-页面规范.md)**），**`useReducedMotion` / `prefers-reduced-motion`** 须收敛。**排名过渡**、TOP3 高亮、数字滚动等 **须符合 30**，不可照搬 **§5.5** 无限制数字动画到资金相关文案。

## 7. 交互规范（UX Rules）

| 规则 | 说明 |
|------|------|
| 反馈 | 点击后 **立即** 视觉反馈（ripple 可选，须轻量） |
