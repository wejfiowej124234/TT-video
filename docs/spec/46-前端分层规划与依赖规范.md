## 一、分层总览

| 层级 | 路径 | 职责 | 可依赖 |
|------|------|------|--------|
| **App** | `frontend/app/` | 路由、layout、page；组合 components，最小业务逻辑 | components、lib、hooks |
| **Components** | `frontend/components/` | 按域 UI + 共享组件；含域内 hooks（如 useCommunityFeed） | lib、dapp（仅链上相关）、hooks |
| **Hooks（顶层）** | `frontend/hooks/` | 跨域复用 hook（如 useFocusTrap） | lib |
| **Lib** | `frontend/lib/` | API 客户端、类型、常量、纯工具、i18n 数据 | 无（不依赖 app/components） |
| **Dapp** | `frontend/dapp/` | 链上合约、ABI、useEscrowActions 等 | lib、abis |

**依赖规则（单向）**：

- **App** → Components、Lib、Hooks（仅用 `@/hooks` 或相对路径）
- **Components** → Lib、Dapp（仅 escrow/链上相关）、Hooks；**禁止** components 引用 `@/app`
- **Hooks** → Lib；不依赖 Components/App
- **Lib** → **禁止**引用 Components、App、Hooks
- **Dapp** → Lib、dapp/abis；业务页通过 components（如 EscrowDetail）间接使用 dapp

## 二、各层细则

### 2.1 App（app/）

- **仅做**：路由、layout（含 metadata）、page 组合、从 hooks/page 级取数并传给子组件。
- **不做**：长表单逻辑、复杂状态机、直接调 API 多步流程；应下沉到 components 或 hooks。
- **单文件**：page/layout 建议 ≤300 行；超则抽 section 组件或域内 hook。

### 2.2 Components（components/）

- **按域**：community、market、escrow、landing、me、did-rank、trust + 根目录共享（如 LocaleProvider、LoadingText）。
- **域内可含**：该域专属 hook（如 `useCommunityFeed`、`useCommunityFeedFilters`）、sections、modals、drawers。
- **复杂模块**：单目录多文件（如 CustomItineraryModal、EscrowDetail、PublishDrawer），单文件 ≤400 行。
- **禁止**：`import ... from "@/app"` 或 `from "../../app/..."`。

### 2.3 Hooks

- **frontend/hooks/**：跨域复用（如 useFocusTrap）；与 43 §2.5 一致。
- **域内 hook**：放在对应域下（如 `components/community/useCommunityFeed.ts`、`useCommunityFeedFilters.ts`），不强制提到顶层。
- **dapp/hooks/**：仅链上（useEscrowActions）；业务通过 EscrowDetail 等组件间接使用。

### 2.4 Lib（lib/）

- **职责**：api、apiClient（按域拆子模块）、countries、cityDetails、**productCountries**（产品期十国 ISO/中文名 SSOT）、geoOptions（COUNTRY_OPTIONS 等由 productCountries 派生）、communityMockData、constants、i18n、类型、纯函数。
- **禁止**：引用 components、app、hooks（避免循环与耦合）。

### 2.5 Dapp

- **职责**：abis、useEscrowActions；与合约交互的只读/写逻辑。
- **引用关系**：仅 EscrowDetail/useEscrowDetail 等业务组件引用 dapp；app 不直接引用 dapp。

## 三、新增代码归属（决策）

| 场景 | 放置位置 |
|------|----------|
| 新页面 / 新路由 | `app/<route>/page.tsx`，layout 放 `app/<route>/layout.tsx` |
| 页面内一块 UI 区块 | 对应域下 section 或组件，如 `components/market/XXXSection.tsx` |
| 多页复用 UI | `components/` 根目录或共享子目录，或 34 组件清单 |
| 仅某域使用的状态/逻辑 | 该域下 `useXxx.ts`，如 `components/community/useCommunityFeedFilters.ts` |
| 多域复用的 hook | `frontend/hooks/`，并在 `hooks/index.ts` 导出 |
| 新 API 调用/类型/常量 | `lib/apiClient` 或对应 lib 子模块；类型可放 `lib` 或组件目录 `types.ts` |
| 链上读写 | `dapp/hooks` 或 dapp 下新模块，由 components 调用 |

## 四、当前分层优化状态

- **已落实**：App → Components → Lib 单向；dapp 隔离；frontend/hooks 存在且 useFocusTrap 已放入；apiClient、communityMockData 已按域/场景拆分；各层单文件 ≤400 行或已拆子模块。
- **持续遵守**：新加页面/功能时按 §三 决策表放码；禁止 Lib 引用 Components/App；跨域 hook 优先放 `frontend/hooks/`。
