## 2. Web3 融入检查（多维度）

### 2.1 必须露出的 Web3 元素（P28）

| 位置 | 要求 | 当前 | 状态 |

### 2.2 建议增强的 Web3 露出（与截图风格融合）

| 位置 | 建议 | 目的 |
|------|------|------|
| 自由市场订单卡底部 | 在「Escrow pricing」下增加一行小字：**Polygon · USDC · 链上托管** | 与截图「价格/晚」旁有信息行一致，且明确链/币，不抢主视觉 |

### 2.3 禁止项（P28，与截图差异）

- 截图无 Web3，故无「巨大钱包按钮」；我们**不得**在 Landing、**`/discover` 短停**、**`/market`** 加 Connect Wallet 大 CTA。
- 我们**不得**在卡片上放钱包按钮、过多 hash/地址、赛博霓虹、区块链 Logo 墙。

## 3. 缺口汇总与补充优先级

### 3.1 需补充的 UI（按优先级）

| 优先级 | 缺口 | 说明 | 落点 |
|--------|------|------|------|
| **P1** | Hero 内分类 pill | 与截图一致：标题+徽章下方增加 3 个玻璃 pill（发现行程 / 创建行程 / 向导列表），链接到对应页 | **`app/(home)/page.tsx`** Hero 区（**`/`**） |
| **P1** | 订单卡 Web3 一行（自由市场） | 在「Escrow pricing」下增加「Polygon · USDC · 链上托管」小字（text-meta），首卡与列表卡均加 | **`app/market/page.tsx`**、`components/market/OrderCard*` 等（**`/discover`** 仅为 **`/market`** 重定向壳） |
| **P2** | 卡片玻璃感 | 自由市场订单/向导卡容器使用 `bg-bg-console/95 backdrop-blur-sm` 或等效，与截图玻璃卡一致 | **`components/market/*`** 卡片容器 class |
| **P2** | Cookie 同意（若合规需要） | 组件符合 P28 玻璃/Token；文案与交互由产品/法务定 | 新组件 + 文档约定 |
| **P3** | 区块标题带图标/层次 | 「发现行程」等区块标题可加图标或与 hero 重叠式布局 | **Landing** 第二屏、**`/market`** 列表区 |

## 4. 小结

- **设计风格**：**全局顶栏**按 **86 §6.0**（白底深字），与 Voyago **浮条玻璃浅字**不对齐、属产品取舍；Hero 主标题、可信承诺、底部基建墙等与 P28 叙事对齐。**缺口**主要为 Hero 分类 pill、**`/market`** 订单卡 Web3 一行、卡片玻璃态、可选 Cookie/区块标题（**`/discover`→`/market`**，见 **04 §3.4**）。
- **Web3 融入**：已具备三徽章、Escrow 角标、USDC pill、Escrow pricing、TrustInfraWall；**需补充**为卡片上「Polygon · USDC · 链上托管」一行，使 Web3 在列表/首卡上更可感知且不抢主视觉。
- **实施顺序**：先做 P1（Hero 分类 pill + **自由市场（`/market`）** 订单卡 Web3 一行），再做 P2（卡片玻璃感、Cookie 若需要），最后 P3（区块标题/层次）。

## 5. Web3 旅游性质优化（参考图对照）

在参考图（Voyago 风格）基础上，以下为 **Web3 旅游** 必须体现的差异与已落实项：

| 维度 | 参考图 | 本平台（Web3 旅游） | 已落实 |
|------|--------|---------------------|--------|
| 支付与预算 | 通用 $/night | **预算与支付统一 USD，稳定币 USDT/USDC** | 表单预算(USD)、$ 前缀、解锁价 1.99 USD、全流程标注 USDT/USDC |
| 首屏 Web3 露出 | 无 | Hero 下需有支付方式提示 | Hero 增加「Pay with USDT/USDC on Polygon」；三徽章 + 稳定币一行 |

| 盲盒卡片 | 参考图为酒店列表卡 | **虚化玻璃 + 盲盒 + 解锁付费** | 锁态：渐变底 + 🔒 盲盒、解锁价与「使用 USDT/USDC 支付」；解锁态：顶部色条 + 行程摘要 + 预算 $ USD |
| 底部 | 合作方 Logo | **可信基建墙**（Polygon · USDC · WalletConnect） | TrustInfraWall，不采用合作方 Logo |
