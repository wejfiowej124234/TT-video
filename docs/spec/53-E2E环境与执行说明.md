## 二、本地执行步骤（53 主路径 E2E）

**首次运行 E2E 前**：在 `frontend` 目录执行 `npm install` 与 **`npx playwright install`**（安装 Playwright 浏览器），否则 `npx playwright test` 会报错缺少浏览器。依赖已含 `@playwright/test`（见 frontend/package.json），仅需安装浏览器一次。

1. **启动后端**  
   - 根目录：`cargo run -p traveltrust-api`（或 `scripts/start-api-with-seed.bat` 以启用测试账号）。  
   - 确认 `.env` 含 `DATABASE_URL`（若用 DB）或仅内存；可选 `P3_CHAIN_OFF=1`、`SEED_TEST_ACCOUNTS=1`。

2. **启动前端**  
   - `cd frontend && npm run dev`；确认 `NEXT_PUBLIC_API_BASE_URL=http://localhost:8080`（或未设，使用默认）。

3. **执行 53 主路径（手工或 E2E 脚本）**  
   - 旅行者登录 → 创建/提交行程 → 订单进入市场；  
   - 向导登录 → Discover 订单列表 → 抢单 → 右侧弹窗「确认接该项目」；  
   - 双边确认（旅行者/向导各自确认）；  
   - 链下时：mock-pay / set-escrow-address 完成 Escrowed → **链下** `confirm-completion`（非放款）→ 评分路径（若跑通）→ **release**（与 04 §3.4、53 一致）；  
   - 评分页上传/确认 → 双方 confirm-rating（若已实现）。  

4. **留痕（M1）**  
   - 执行完成后：截图或录制「订单步骤条 1→8 与状态一致」、或保存 E2E 报告路径（如 `frontend/playwright-report/index.html`）；在 27 或 CI 中登记「53 主路径 E2E 通过」及日期/环境。

**仅跑 53 主路径 E2E 用例**：在 frontend 目录执行 `npm run e2e -- 53-main-path` 或 `npx playwright test 53-main-path`；用例定义见 `frontend/e2e/53-main-path.spec.ts`（Escrow 步骤条、取消政策区、订单列表→Escrow、Market、行程与预算/保存/确认/报价摘要）。通过后报告默认在 `frontend/playwright-report/index.html`。
