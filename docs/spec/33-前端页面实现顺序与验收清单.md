来自 [13-1 表 2](13-1-UI产品级SSOT与页面规范.md)；实现时按角色控制路由与按钮可见性。

| 角色 | 可访问页面（摘要） | 限制 |
|------|--------------------|------|
| **游客** | Landing、**`/traveltrust`**、**自由市场（`/market`；`/discover`→`/market`）**、OrderFlow（自己订单）、EscrowDetail（参与方）、Profile、TT 社区 | 不可见仲裁/治理/Admin |
| **向导** | Landing、**`/traveltrust`**、**自由市场（`/market`；`/discover`→`/market`）**、OrderFlow、EscrowDetail、Profile、我的接单、TT 社区 | 不可见仲裁裁决、治理投票、Admin |
| **仲裁员** | Dispute（分配案件）、证据与时间线、裁决提交 | 仅分配案件；可执行器触发（若权限） |
| **治理者** | Governance、Proposals、Params | 不可资金操作、仲裁裁决 |
| **观察者（未登录或仅浏览）** | Landing、**`/traveltrust`**、**自由市场（`/market`；`/discover`→`/market`）**、公开 Escrow 状态（只读）、TT 社区仅浏览 | 无写操作；发帖/互动需登录 |

**顶栏**：无角色切换，仅「登录」「注册」及导航（**Web3 旅行 `/`**、**字标 TravelTrust → `/traveltrust`**、自由市场、DID 排行榜、TT 社区）；角色由注册入口（游客 vs 申请向导）与路由/权限区分。
