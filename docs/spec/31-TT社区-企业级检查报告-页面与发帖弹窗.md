## 二、发帖弹窗是否正常

### 2.1 挂载与层级

- **挂载**：通过 `createPortal(..., document.body)` 渲染，不随 Feed  DOM 滚动或裁剪。
- **层级**：`z-[200]`，高于全局 Header（z-40）与其它抽屉，无遮挡问题。
- **全屏**：`fixed inset-0`，移动端/桌面均覆盖视口；顶栏/底栏 `shrink-0`，主内容区 `flex-1 overflow-y-auto min-h-0`，仅主内容滚动。

### 2.2 关闭与退出

- **返回**：顶栏左侧「回到TT社区」按钮，小屏仅图标、sm 及以上带文案；`aria-label`、min-h 44px。
- **关闭**：顶栏右侧 X 按钮，`aria-label` 使用 `community_close`（与返回语义区分）。
- **Esc**：全局监听 `Escape` 调用 `onClose()`。
- **焦点还原**：从 Feed 页「发帖」入口或底部导航「+」打开时记录触发元素（`CommunityPublishContext.openPublish(trigger)` 传参、Feed 注册时 `setFocusReturn(trigger)`），关闭时 `requestAnimationFrame(() => prev?.focus())`，焦点回到触发按钮。

### 2.3 焦点与键盘

- **打开时焦点**：`useEffect` 中 `backButtonRef.current?.focus({ preventScroll: true })`，焦点在返回按钮。
- **焦点陷阱**：Tab/Shift+Tab 在弹窗内可聚焦元素间循环，不逃逸到背后页面。
- **无障碍**：`role="dialog"`、`aria-modal="true"`、`aria-labelledby="publish-drawer-title"`；区块 section + aria-labelledby/aria-describedby。

### 2.4 滚动与动效

- **背景滚动锁定**：弹窗挂载时 `document.body.style.overflow = "hidden"`，卸载时恢复，避免背后 Feed 滚动（企业级常规做法）。
- **入场**：200ms 淡入；`motion-reduce:opacity-100` 尊重「减少动画」偏好。

### 2.5 异常态与反馈

- **发布失败**：父组件可传 `publishError`、`onRetryPublish`，顶栏下展示错误条 + 重试；容器 `role="alert"`、`aria-live="assertive"` 便于读屏播报。
- **上传超大小**：单张 >10MB 时 `uploadError` 提示，文案走 i18n。
- **提交中**：按钮 `disabled`、`aria-busy`、文案「发布中…」+ 旋转图标，防连点。

## 三、弹窗内布局是否符合对标（小红书/INS）

对标 31-发布动态-页面设计与布局最佳实践 与 小红书/INS 发帖流程：

| 要求                     | 实现情况 |
|--------------------------|----------|
| **三区固定**             | ✅ 顶栏（返回 \| 标题 \| 关闭）、主内容可滚动、底栏固定发布；顶/底栏 ≥48px，safe-area-inset-t/b。 |
| **单列顺序**             | ✅ 类型 → 媒体上传 → 正文（+ 话题提示 + 字数）；单列 max-w-2xl 居中，与底栏按钮同宽。 |
| **类型选择**             | ✅ 横向 pill（照片/视频/美食/旅游），选中态高亮，min-h 44px。 |
| **媒体上传**             | ✅ 首图多图时略大（w-28 h-28），其余与添加框同尺寸（w-24 h-24）；虚线「+」+ 0/9；排序（‹ ›）、删除（×），触控 ≥44px。 |
| **正文**                 | ✅ textarea rows≈5、min-h 120px；字数 x/1000，≥90% 警告色，达上限高亮；`aria-live="polite"`。 |
| **话题/标签**            | ✅ 正文下方辅助说明「添加话题: #…」，不占主流程。 |
| **主 CTA**               | ✅ 底栏唯一主按钮「发布」、全宽 max-w-2xl、min-h 48px；未填正文禁用 +「填写正文后即可发布」提示。 |
| **分区与留白**           | ✅ 类型/媒体/正文各独立 section，圆角卡片 + 组内 gap-2、组间 space-y-6；主内容区底部 pb-12/sm:pb-14，不贴底栏。 |

结论：**弹窗内布局与 31 最佳实践及对标产品（小红书/INS）发帖流程一致。**
