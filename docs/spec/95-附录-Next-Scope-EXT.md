## §0-EXT · Post-Freeze Controlled Development Mode（Start Development）

> **定位**：在 **Baseline**（**95** 含 **v1.4.305** / **v1.4.306** 冻结语义及后续 **Release** 校注如 **v1.4.315**）、**Execution**（**96** 系）、**GO Decision Entry**（**[go-live-checklist#go-decision-entry-point](../go-live-checklist.md#go-decision-entry-point)**）、**Gate**（**B-421** **`exit 0`**）已满足之后，进入 **Post-Freeze Controlled Development Mode**。本节规定 **工作分支与登记表义务**；**完成语义 / EXT→Baseline 迁表** 仍以 **§2-EXT** 为准；**禁止改写基线** 与 **§2-EXT.5**、**§7-EXT.UI** 规则 **5** **对读取严**。

### 一、开发范围

- **允许**：在分支 **`feature/ui-and-95-expansion`** 上实施 **Next Scope** 开发与文档更新（**merge 回** **main** 仍须按组织 **PR / 保护分支** 流程，**禁止**绕过评审直接推 **main**）。
- **禁止**：以 PR **改写** **主文** **Baseline**（**F-001～F-033** 既有行语义）、**主文** **§8.2** / **§9** 既有行语义（**须**走 **§2-EXT.4** 大版本迁表与 **Release Gate** 方可成为新基线）。

### 二、新增功能处理（强制）

每个新增能力 **必须** 登记入 **本附录**：

1. **§3-EXT** → 新 **F**（**F-034+**，连续编号）。
2. **§8.2-EXT** → 与 **F** 一一对应的测试矩阵（**UT / API·IT / 93 / E2E / 负例 / 行完成**）。
3. **§7-EXT** / **§7-EXT.UI** → 页面、路由或 **纯 UI** backlog（规则见 **§7-EXT.UI**）。
4. **§9-EXT** → 风险（**ISS-EXT-***，如有）。

**版本注记**：与 **EXT** 同批的 **95**/**本附录** **Version** 校注须 **≥ v1.4.308**（**§2-EXT** 语义已立）；PR 描述 **须** 能指回当次 **附录 Version** 与 **F-0xx**。

### 三、开发约束

1. **禁止破坏** **Baseline** 行为（**主文** **F-001～033** / **§8.2** / **§9** 冻结面）。
2. **禁止隐式修改** 旧 **F**；若某 PR **触及** 基线代码路径，**须**在 PR / **§12-EXT** 写明 **影响范围** 与 **为何未迁表**。
3. **每个** **§3-EXT** 能力 **须** 具备：**API 正路径**（可跑）、**至少一项** **UT** 或 **API·IT**、设计 **可扩展** 至 **93** / **E2E**（与 **§8.2-EXT** 五格一致）。

### 四、验证要求（本地）

每个新增 **须** 可在本地或 CI 复现：

- **build / lint**（前后端按仓库惯例）。
- **`cargo test`**（涉 **Rust** 变更时）。
- **Playwright**（涉 **UI** / **E2E** 面时）。
- 证据链 **可落入** **`report.json`** 口径（**R-001** / **R-002** / **validate-regression-report.py** 同源）。

### 五、UI 优化规则

- **纯 UI** → **§7-EXT.UI**（**Functional Upgrade** 触发时 **必须** 升为 **§3-EXT** 新 **F**，见 **§7-EXT.UI** 正文）。
- **影响流程 / 契约 / 真值** → **直接** **§3-EXT** 新 **F** + **§8.2-EXT**。

### 六、执行输出（每轮 PR / 里程碑须回答）

- **新增** **F-0xx** 编号与 **§3-EXT** 行摘要。
- **§8.2-EXT** 覆盖情况（五格 + **行完成**）。
- **是否影响 Baseline**（**须**为 **否**；若为 **是** → **停止**并按 **§2-EXT.4** 策划迁表）。
- **是否新增** **ISS-EXT**（编号与关闭条件）。

**执行原则：** **主线冻结，分支扩展**；**新增入表，验证优先**；**不动已成，持续演进**。
