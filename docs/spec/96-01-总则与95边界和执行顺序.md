## §0.0 95 ↔ 96 Execution Linkage（摘要）

**95** = **完成标准**（**SSOT**：**§3 / §8.2 / §9**；**§0.2 / §12.4**）。**96** = **如何跑通**（执行与编排：**96-15** 主线 **Tier A→B→C**；**96-13**/**96-16** 体验与全路由证据；**96-17** **多重身份**（**`/did-rank` 四脊签 + 账号/向导钱包**）核对；**96-18** **商家/主理人准入费·TTG** **Target** 设计（**§12** 文档闭环 ↔ **04-附录-HTTP** / **DDL §10.7** / **93 §8.4** / **95-附录 F-034～038** / **97**；**Hub ≥v1.4.19**/**§4** 互指底 **95 ≥v1.4.321**）；本分册 **差集 + §0.3 一束**）。**GO** 须 **完成 ∧ 跑通**；**B-421**（`scripts/check-runbook-golive-doclink-gate.sh`）**exit 0** 为 **文档链 GO 前置硬门禁**（与 **93 / R-002 / 缺口单人多角色自签** 并联）。**全文**见 **[96-索引 · Declaration](96-索引-全链路外生产验收分册.md#95-96-execution-linkage-declaration)**。

**全仓库规划方向（工程默认）：** **先本地 + 测试网跑通**（证据与脚本矩阵见 **[TT-9600](../runbook/TT-9600-96-HUB-LOCAL-VERIFICATION-PACK.md)**、示例 **[TT-9618](../runbook/TT-9618-onboarding-local-testnet.md)**、根 **[README](../../README.md)**），再进入 **主网真链 / Production GO**（**[go-live-checklist](../go-live-checklist.md#go-decision-entry-point)**）；**禁止**用阶段 A 冒充阶段 B。

**原则：** 没有 **96**，**95** 只是表；没有 **95**，**96** 没有标准。

**相对 95 的不可替代价值（编排 / 证据 / NFR）、NO-GO 归因速查、非生产 **Soft GO** 语义：** 全文见 **[96-索引 · 96 · 相对 95 的不可替代价值](96-索引-全链路外生产验收分册.md#96-core-value-why)**（锚 **`#nogo-attribution`** / **`#soft-go-non-production`**）。**GitHub CI 不可用时** 的 **96** 全分册本地清单、证据模板与脚本矩阵：**[TT-9600](../runbook/TT-9600-96-HUB-LOCAL-VERIFICATION-PACK.md)**。
