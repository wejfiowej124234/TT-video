## 维度6：区块链事件 & 状态机 - 100% ✅ [NEW DOC 36]

### 新建文档

**位置**: `docs/spec/36-区块链事件与状态机完整文档.md`

### 内容

1. **Order 生命周期状态机**
   ```
   Draft → Created → Accepted → Escrowed → {Completed|Disputed}
                                   ↓
                          Disputed → {Refunded|PartiallyRefunded|Slashed}
   ```
   - 10 个状态
   - 合法转移表
   - 资金流向映射

2. **Escrow.sol 状态转移**
   - 6 个链上状态 (None/Created/Funded/Completed/Refunded/Disputed/Resolved)
   - 6 个事件与对应的 Orders 转移
   - 每个事件的参数详解

3. **Chain vs Chain_off 模式对比**
   ```
   | 维度 | Chain | Chain_off |
   |-----|-------|-----------|
   | Escrow | 链上合约 | DB 模拟 |
   | 资金 | on-chain transfer | DB 记录 |
   | 状态源 | Escrow.status | orders.status |
   | 终态 | N-finality + ReadOnly | DB ACID |
   ```

4. **完整三层流程**
   ```
   Escrow.sol Events
       ↓ (Indexer)
   event_log 表
       ↓ (Handler)
   orders_projection 表
       ↓ (API)
   前端 / 仲裁系统 / 执行器
   ```

5. **N-Finality 确认机制**
   - 区块重组 (reorg) 处理
   - 检查点 (checkpoint) 管理
   - 15+ 深度的确认规则

6. **执行器 (Executor) 上链流程**
   - 裁决提交 → DB 记录
   - Executor 轮询 → 构造交易
   - 签名 → 广播 → Indexer 投影
   - 恢复与重试逻辑

7. **纠纷仲裁完整流程**
   - 证据哈希验证
   - 仲裁员分配与决策
   - 链上 executeResolution 调用
   - 资金最终分配

8. **端到端示例** (2个完整场景)
   - 订单正常完成 (Chain 模式, T0-T9)
   - 订单纠纷处理 (Chain 模式, T<n>-T<n+5>)
