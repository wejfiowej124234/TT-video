## 验收标准

- **全部页面跳转**（路由、Tab、抽屉、弹窗、视图切换）在 **200ms 内**完成**可感知展示**（新页面/新视图可见或明确 loading/骨架/激活态）。
- 数据请求可滞后，但**视觉反馈不可延迟**；禁止点击后长时间白屏或无反馈。

## 测量方式（定稿用）

| 项 | 说明 |
|----|------|
| **工具** | **Lighthouse**（Performance 面板）或自定义「点击到首帧/骨架」计时（`performance.measure` / `performance.mark`）；或 Chrome DevTools Performance 录制。 |
| **环境** | Chrome 本地或 CI（无节流）；慢速网络下以「**骨架 200ms 内必现**」为达标（§4.4.7 J2/D1）。 |
| **样本** | 至少覆盖：路由跳转（如 /market → /escrow/[id]）、Tab 切换（市场 订单/向导）、抽屉打开（订单详情）、弹窗打开（确认接单）；每类至少 **3～5 次**采样，取中位数或 P95。 |

## 实施时定稿

- 发版前由责任人选定**工具+环境+样本**，执行一次测量并留存结果（如 Lighthouse 报告链接、或 `performance.measure` 输出截图）。
- 若采用 CI 自动化，可在 E2E 或前端性能流水线中增加「点击到首帧 &lt; 200ms」断言（实现时定稿）。
