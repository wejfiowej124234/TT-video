## 签核项（逐项 □）

| □ | 项 | 说明 |
|---|----|------|
| ☐ | **与 08-4 无冲突** | 收益流、证券隔离、分红/治理币绑定、Pause/冻结等措辞与已定稿 08-4 一致或已同步升版 |
| ☐ | **与 01 边界一致** | MVP 不发行平台支付币、结算币种、Escrow 与治理代币关系与 01 一致 |
| ☐ | **中英版本对齐** | `01-对外白皮书-草案` 与 `en/01-external-litepaper-draft` 同日版本号、无语义矛盾 |
| ☐ | **禁止性表述已审** | 无保本、无固定收益承诺、无不实证券表述 |
| ☐ | **发布渠道登记** | 固定 URL 或文档路径已登记（官网/GitHub/投资者门户等） |
| ☐ | **83/84 与 FeeRouter 数字** | 对外材料仅使用 **83 v1.1.0+**（**45%/55%**、Global **65/20/15**）与 **84** 表内数字；**不得**再引用 **83 §3.1** 废止的 35/65、70/30 |
| ☐ | **可分配费用分母与正交（84 §1.1.1）** | **45%/55%** 仅相对 **进入 FeeRouter 的可分配订单手续费** 之 **100%** 分母（见 **[84 §1.1.1](../84-第一阶段10国Country-Pool发行参数总表.md)**）；**不得**将 **L1/L2 gas**（用户自付）、**争议仲裁费**、**向导履约质押罚没（`IdentityStakingPool` 系 `slash`；旧称 `Staking.slash` 已弃用）** 画进或叙述为同一套 **45/55** 分子；对外若提及上述路径，须有脚注或独立句段，并与 **[Runbook §7.1](../../../ops/RUNBOOK.md)**、**[01-对外白皮书-草案 §6](01-对外白皮书-草案.md)** / **[en/01 §3](en/01-external-litepaper-draft.md)** 策略一致 |
| ☐ | **TTG 激励 vs 证券隔离** | 若描述 **TTG 质押参与协议费分配**，须与 08-4 **第 2 章**「收益证券隔离」及 **Howey** 风险披露一致；**禁止**「固定收益/股息/股权」表述除非法务书面结论 |
| ☐ | **Country Pool / RegionShare** | 与 **83** 风险披露、**84** 免责声明、**08-4** 扩展条一致；募资页须含**非股权、收益不保证**等价措辞 |
| ☐ | **收益流图示** | 若 PPT/PDF 含手续费分配图，须与 [08-4-附录-收益流闭环图-FeeRouter-Target](../08-4-附录-收益流闭环图-FeeRouter-Target.md) 或经法务批准的等价图一致；图示旁须与 **84 §1.1.1** 一致标注 **gas/仲裁/slash 不在本图 100% 分母内**（或等价法务批准脚注） |
| ☐ | **13-1 表 2-续 与对外稿一致** | 产品内 **`/governance`**（只读池/激励展示 vs 链上 DAO）与 [13-1-UI产品级SSOT与页面规范](../13-1-UI产品级SSOT与页面规范.md) **表 2-续**、[83](../83-区域治理与收益分配-协议白皮书.md) **附录 I.0** 边界一致；**对外稿 / 落地页 / APP** 不得暗示「页面数字即链上真值」或越权承诺，除非已与法务定稿的披露句一致 |
