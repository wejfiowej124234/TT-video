## 4. 关键约束核对

### 4.1 29 核心约束

1. 单一入口：`/discover` 重定向 `/market`，无双入口分流。
2. 页面定位：Market 以撮合为主（订单/向导发现、详情、预约、接单），不直接承担支付执行。
3. 结构完整：Hero + StickyFilterBar + ViewSwitcher + 双栏内容 + Drawer/Modal + 空态/骨架。

### 4.2 28 风格约束

1. 玻璃态用于 Experience 区（市场主场景、筛选条、卡片容器）。
2. Web3 露出克制（Escrow badge/token pill），不在此处叠加重链上交互。

### 4.3 37 i18n/a11y 约束

1. Market 范围翻译键覆盖：
   - 抽取范围：`app/market`, `components/market`, `app/discover`
   - 结果：`total_keys=236`, `missing_zh=0`, `missing_en=0`
2. a11y 证据：
   - `ViewSwitcher` 使用 `role="tablist"/role="tab"/aria-selected`
   - `MarketContent` 错误提示 `role="alert"`
   - loading 和 toast 具备 `role="status"/aria-live`
   - Drawer/Modal 使用 `role="dialog"` + `aria-modal`

### 4.4 收藏与 F-020（2026-06-03 · ① 代码口径）

1. **`/market`** 与 **`/`** 订单收藏共用 **`marketFavoritesStorage.ts`**（**`localStorage`**，**`subscribeMarketFavoritesStorage`** 跨 tab）。
2. **`GET/POST/DELETE /api/v1/me/market-bookmarks`** + **`marketTravelBookmarksSync.ts`** — **① FE best-effort 已接线**（**`/` + `/market`** · **`localstorage-f020-sync-v1`**）→ **②** **MKT-FILT-P2-009** SLA。
3. 与社区 **`postCollect`** 分轨 — 见 **[`LANDING-MARKET-PAGES-CODE-SSOT`](../../../frontend/evidence/GO_local_web3_pages_closure/LANDING-MARKET-PAGES-CODE-SSOT.md)** §6。

### 4.5 子站筛选（2026-06-03 · ① 已闭）

1. **`MarketSubsiteFilterBar`** + **`lib/marketSubsiteFilters.ts`** — URL **`country` · `category` · `sort`**。
2. 列表 **`GET …/market/provider|acquisition/listings?…`**；PG 行 **`meta.source=postgres_catalog`**。
3. **②** staging facet / cursor UI — **[`MARKET-SUBSITE-FILTER-PHASE2-BACKLOG`](../../../frontend/evidence/GO_local_web3_pages_closure/MARKET-SUBSITE-FILTER-PHASE2-BACKLOG.md)**。
