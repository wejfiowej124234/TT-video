## 3. 使用说明

1. **发版是否完成 P0**：**只**以 [缺口与待补-官方总表](../缺口与待补-官方总表.md) **P0 表状态列**为准。  
2. **附录〇是否逐项勾选**：以 [15 附录〇表格](../15-多维度文档与技术检查报告.md#发版前勾选总表) 为准。  
3. **本文件**：用于培训/审计/AI 扫档时**快速跳转**，发现 **P0 与附录〇** 叙述漂移时**先改 SSOT 表**再同步本映射。
