## 1. 映射口径（100% 定义）

本次“100%代码映射”定义为：

1. `frontend/app` 的路由实现（`page.tsx`、`layout.tsx`、`loading.tsx`、`error.tsx`）全部归档到对应 UI/UX 规范。

## 6. 使用方式（逐个排查）

你要求“一个个排查”，建议按这个顺序执行并回填：

1. 先按第 3 章逐路由核对（页面层）。
2. 再按第 4 章逐组件域核对（组件层）。
3. 最后按第 5 章核对 i18n 与 a11y（横切能力）。

每次排查后，把差异回填到对应规范补充文档（13/**86**/21/22/28/29/30/31/37/39），本总表只维护“索引与锚点”；**UI 读序** 以 **[07 §五 5.3](../07-开发流程与顺序.md)** 为准。
