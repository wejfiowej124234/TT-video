### 1.2 关键特性

#### A. 路由优化（减少white屏幕）

```typescript
const NAV_LINK_PROPS = { prefetch: false } as const;  // 避免prefetch的登录/注册等
const NAV_PREFETCH = { prefetch: true } as const;    // 主路由需prefetch

function NavLink({
  href, className, children, onNavStart
}: {...}) {
  return (
    <Link
      href={href}
      prefetch={true}
      onPointerDown={onNavStart}  // ⚠️ 关键：pointerdown即响应，不等click
    >
      {children}
    </Link>
  );
}
```

**实现约束1**：pointerdown 事件触发响应（相比click提前300-500ms），≤200ms内显示进度条。

#### B. 导航进度条

```typescript
const NAV_BAR_DURATION_MS = 400;  // 进度条显示时间

function useNavigatingBar(pathname: string | null) {
  const [show, setShow] = useState(false);
  
  const showBar = useCallback(() => {
    setShow(true);
    // 400ms后自动隐藏
    if (timerRef.current) clearTimeout(timerRef.current);
    timerRef.current = setTimeout(() => setShow(false), NAV_BAR_DURATION_MS);
  }, []);
  
  // pathname变更时触发（实际路由）
  useEffect(() => {
    if (pathname !== prev.current) {
      prev.current = pathname;
      showBar();
    }
  }, [pathname, showBar]);
}
```

**实现约束2**：进度条显示 400ms，贯穿整个路由过程。

## 二、LocaleProvider i18n 实现细节（补充到05 §六 个人中心）

### 2.1 架构

**文件位置**：`frontend/components/LocaleProvider.tsx` + `frontend/lib/i18n.ts` + `frontend/locales/{zh,en}.ts`

### 2.2 核心类型与函数

```typescript
type Locale = "zh" | "en";
const DEFAULT_LOCALE: Locale = "zh";
const LOCALES = ["zh", "en"] as const;

const messages: Record<Locale, Record<string, string>> = {
  zh: zh as unknown as Record<string, string>,
  en: en as unknown as Record<string, string>,
};

function getStoredLocale(): Locale | null {
  return localStorage.getItem("locale") as Locale | null;
}

function setStoredLocale(locale: Locale) {
  localStorage.setItem("locale", locale);
}
```

### 2.3 使用方式

```typescript
export function useTranslation() {
  const ctx = useContext(LocaleContext);
  if (!ctx) throw new Error("useTranslation must be used within LocaleProvider");
  return ctx;
}

// 在组件中
const { t, locale, setLocale } = useTranslation();
const label = t("button_search");  // 自动取当前locale对应值
setLocale("en");  // 切换语言 + 保存localStorage
```

## 二点五、注册页 `/auth/register`（协议四角色 · 底图 · 与 04 对齐）

## 五、Wagmi 与 DApp 配置（补充缺失）

### 5.1 配置位置

**文件**：`frontend/components/Providers.tsx`

```typescript
const config = createConfig({
  chains: [mainnet],
  connectors: [injected()],  // MetaMask、Trust Wallet等
  ssr: true,
  transports: {
    [mainnet.id]: http(),
  },
});

export function Providers({ children }: { children: React.ReactNode }) {
  return (
    <WagmiProvider config={config}>
      <QueryClientProvider client={queryClient}>
        <ViewOnlyAddressProvider>
          <LocaleProvider>
            <MetaProvider>{children}</MetaProvider>
          </LocaleProvider>
        </ViewOnlyAddressProvider>
      </QueryClientProvider>
    </WagmiProvider>
  );
}
```

### 5.2 架构说明

**为什么是 injected()？**
- injected() 支持MetaMask、Trust Wallet、OKX等标准EIP-6963钱包
- WalletConnect + Coinbase 连接器与wagmi v2 reconnect 不兼容（bug）
- 多钱包支持可用 RainbowKit / ConnectKit 库（推荐后续）

**验证链**：mainnet (Ethereum)。如需多链支持，扩展 chains 数组。

### 5.3 补充到05 §三技术选型

> **DApp层配置**：wagmi 2.12+ + viem 2.21+ + WalletConnect v2
>
> **钱包连接**：injected() (MetaMask/Trust/OKX)；多钱包时推荐 RainbowKit 或 ConnectKit
>
> **链**：mainnet (Ethereum)；多链支持见 [06-DApp架构总览](../06-DApp架构总览.md)
>
> **Stablecoin**：USDT/USDC (mainnet)；地址见 lib/constants.ts

```javascript
// tailwind.config.ts container
container: {
```

### 6.2 常见断点使用

```html
<!-- 响应式容器 -->
<div className="container mx-auto px-4 sm:px-6 md:px-8">
  <!-- 64px padding on desktop -->
</div>

<!-- 响应式网格 -->
<div className="grid grid-cols-1 sm:grid-cols-2 md:grid-cols-3 lg:grid-cols-4">
  <!-- 1列 mobile, 2列 tablet, 3列 desktop, 4列 large -->
</div>

<!-- 响应式图片 -->
<Image
  src={url}
  alt={alt}
  sizes="(max-width: 768px) 100vw, (max-width: 1024px) 50vw, 33vw"
/>
```

### 6.3 补充到05 §四仓库骨架

> **响应式设计**：Tailwind CSS + mobile-first
>
> **主要断点**：
> - mobile (<640px)：1列布局，24px padding
> - tablet (640-1024px)：2列布局，32px padding
> - desktop (1024+px)：3-4列布局，48px padding
>
> **图片优化**：Next.js Image 组件 + srcset + sizes
