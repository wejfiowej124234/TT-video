## 4. 关键约束核对

### 4.1 31 页面与边界约束

1. **L1** 已形成：**Feed、Explore、Messages、Friends、Me**（与 **`layout.tsx`** `TABS` 一致；**feedback** 非 L1 Tab）。
2. 社区定位为 UGC 与社交互动，不在社区页执行支付与撮合流程。
3. 消息页支持从订单流程跳入（`?orderId=`），与 53 阶段链路衔接。

### 4.2 30 视觉一致性约束

1. 采用赛博风深色底与霓虹色系，与 DID 视觉体系一致。
2. 社区布局与交互风格未混入 Escrow 资金区的银行级保守视觉。

### 4.3 37 i18n/a11y 约束

1. 社区范围翻译键覆盖：
   - 抽取范围：`app/community`, `components/community`
   - 结果：`total_keys=175`, `missing_zh=0`, `missing_en=0`
2. a11y 证据：
   - layout/路由切换进度条使用 `role="progressbar"`
   - 错误页使用 `role="alert"`
   - 关键弹窗使用 `role="dialog"` + `aria-modal`
   - `CommunityLoginModal` 使用 `useFocusTrap`
