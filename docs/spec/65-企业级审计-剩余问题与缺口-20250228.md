## 三、剩余问题与缺口（按维度）

### 3.1 安全与鉴权

| 编号 | 问题/缺口 | 严重程度 | 落点 | 依据 |
|------|------------|----------|------|------|
| S1 | **鉴权**：有 `DATABASE_URL` 时登录/注册签发不透明 **`tts_<uuid>`** 会话；`extract_user_with_session_check` 在带 Bearer 且配 DB 时 **仅**认 sessions 表，**不**在无效 Bearer 下回退 `X-User-Id`；纯内存模式仍 `bearer_<user_id>`。生产建议 `STRICT_SESSION_GATE=1`，前端须持久化 `traveltrust_session_token`（见 `.env.example`、frontend `getAuthHeaders`）。 | 中→低（仍勿泄露 token / 勿仅依赖 X-User-Id） | `crates/api/src/state.rs`、`chain_off/auth.rs`、`frontend/lib/apiClient/core.ts` | 混合架构报告 §1.2、§九 |
| S2 | **证件下载**：`serve_guide_upload` 已要求登录；**本人**且 URL 匹配 `id_photo` / `language_cert` / **`guide_license_url`** 路径后缀，或 **`admin`/`super_admin`** 可阅（运营审核）。获知裸文件名仍须有效会话 + 权限。 | 低（外链仅填路径时仍须鉴权） | `crates/api/src/routes/guides.rs` | 向导注册审计 F7、申请向导 §七 |
| S3 | **上传限流**：`/api/v1/guides/upload-doc` 已按 **用户 UUID** 进程内窗口限流（`middleware::GUIDE_UPLOAD_*`）；跨实例/绕过 IP 仍建议网关限流。 | 低 | `crates/api/src/routes/guides.rs` | 向导注册审计 F4、混合架构 §九 |

### 3.2 数据与持久化

| 编号 | 问题/缺口 | 严重程度 | 落点 | 依据 |
|------|------------|----------|------|------|
| D1 | **reviews**：在配置 `DATABASE_URL` 时 `review_submit` 已双写 **`reviews`** 表并 hydrate；无 DB 时仍为内存。 | 低（无 DB 部署） | `chain_off/reviews.rs`、`db/reviews.rs`、`startup/hydrate.rs` | 04 §一、附录 DDL §9.5 |
| D2 | **disputes**：在配置 `DATABASE_URL` 时开/结争议路径已双写 **`disputes`** 表并 hydrate；无 DB 时仍为内存。 | 低（无 DB 部署） | `chain_off/disputes.rs`、`db/disputes.rs` | 04 §一、附录 DDL §9.6 |
| D3 | **双写失败仅打 [audit] 日志**：不改变 HTTP 响应，可能出现「内存有、DB 无」 | 低 | 产品/运维定稿：是否 503 或告警 | 混合架构 §1.2 |

## 四、按优先级汇总

**已闭合（与代码一致，详见 §三 问题表 + §五 实施记录）**：**S1**（`tts_*` 会话 + DB 下 Bearer 不回退 `X-User-Id`）、**S2**（证件下载 + `guide_license_url` + admin/super_admin）、**S3**（upload-doc 用户级限流）、**D1/D2**（reviews/disputes 有 DB 时双写+hydrate）。

| 优先级 | 编号 | 描述 | 建议动作 |
|--------|------|------|----------|
| **P0 合规** | C1 | 敏感数据访问控制与保留期限 | 法务/合规定稿 → Runbook 或 08 系列 |
| **P1 扩展** | I1、I2 | KYC/VC、DID Document/链上锚定 | 按产品与链上能力规划接入 |
| **P2 体验** | C4、I3 | 敏感输入清空/脱敏；EIP-55/chainId | 持续验收与可选增强（部分已实施，见 §五） |
| **待产品** | C2、C3 | 向导证/资格证、护照照片必传 | 产品决策后落需求与 04 |
| **运维** | D3 | 双写失败是否 503/告警 | 产品/运维定稿（Runbook §9） |
