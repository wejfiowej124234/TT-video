## 1. 汇率锁定时点

| 时点 | 说明 |
|------|------|
| **订单金额展示** | 前端/市场以**发布时**或**确认行程时**的参考汇率为展示依据；与 08-3 定稿一致。 |
| **结算锁定** | 链上 deposit 以 **settlement_token**（如 USDC）计价；**汇率锁定**建议在 **confirm-final-plan** 或 **deposit 时**由产品定稿（如锁定 USDC 金额即无汇率风险；若多币种则锁定时点成文）。 |
| **争议/退款** | 裁决金额以**合约币种**（USDC）为准；跨币种展示时按**裁决时**或**平台约定**汇率，与 03 一致。 |

---

## 2. 小费口径

| 项 | 说明 |
|------|------|
| **是否进 canonical** | 小费**是否进入** snapshotHash 的 canonical payload 须在 03/08-3 定稿；若进入则字段名与格式见 [80-附录-01](80-附录-01-Canonical-Payload-白皮书.md) §3.7。 |
| **是否可争议** | 小费是否可纳入争议金额、是否单独裁决，与 03 争议流程一致。 |
| **链上支付** | 小费是否进 escrow、是否与主金额一起 release 或单独通道，与合约与 80-附录-02 资金流顺序一致。 |
| **信誉** | 小费是否进入信誉/评价体系见 81、03。 |
