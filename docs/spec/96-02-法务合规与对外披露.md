## §1 P0 · 生产必查

| # | 生产必查项 | 证据 / SSOT | 执行要点 |

| 2.1 | **ToS / 隐私 / Cookie** 在目标环境**可见**且版本与 **[40](40-运营与内容就绪.md)** 一致 | 截图 + 版本锚；**[15 附录〇](15-多维度文档与技术检查报告.md#发版前勾选总表)** | 记录 **URL**、**Git SHA / 内容 hash** 或 CMS 版本号；**staging 与 prod** 分别留痕。 |

| 2.3 | **对外材料** 无死链、与仓库 SSOT 一致 | **`bash scripts/check-runbook-golive-doclink-gate.sh`**（**B-421** / **TT-B421**） | 发版前 **exit 0**；若有 **warn-only** 项，须在 **`report.json` `notes`** 或 **`evidence/GO_96_legal_<YYYYMMDD>/README.md`** 写明 **Owner + 截止**。 |
