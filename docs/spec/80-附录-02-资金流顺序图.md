## 1. 资金流总序（deposit → 终态）

```
旅行者 deposit（transferFrom → Escrow 实例）
         ↓
    [Paid 事件]
         ↓
  ┌──────┴──────┐
  │ 平台费时点   │ 见下表：Completed / PartiallyRefunded / Slashed 时收取；Refunded/Cancelled 不收
  └──────┬──────┘
         ↓
  行程进行中（Escrowed）
         ↓
  ┌──────┴──────────────────────────────────────┐
  │ 双签完成 / 超时自动放款    │    争议 (Disputed)     │
  │ → Completed                 │ → 仲裁 → 执行器上链    │
  │ 平台费从放款中扣除          │ → Refunded / PartiallyRefunded / Slashed │
  │ 向导收到 (总额 - 平台费)    │ 平台费按 01 §5 十收取；仲裁费见下        │
  └─────────────────────────────────────────────┘
```

---

## 2. 平台费收取时点（与 01 §5 十一致）

| 订单终态 | 是否收平台费 | 说明 |
|----------|--------------|------|
| **Completed** | **收** | 从放款中扣除 platform_fee，向导收 (总额 - 平台费) |
| **PartiallyRefunded** | **收** | 按**实际给向导金额**比例或约定收取 |
| **Slashed** | **收** | 按**实际给向导金额**收取 |
| **Refunded**（全额退旅行者） | **不收** | 资金未给向导，平台不扣费 |
| **Cancelled** | **不收** | 未进 Escrow 或已退，不扣费 |

**禁止**：Escrow 阶段提前扣费；争议中预扣费。

---

## 3. 仲裁费（arbFee）与平台费分离

- **arbFee**：openDispute() 时旅行者/发起方支付，进 Escrow **独立槽位**，与订单 token 相同；**不计入平台收入**。
- **裁决后 arbFee**：
  - 争议驳回（维持放款）→ **不退**；
  - 全额支持发起方 → 全退；
  - 部分支持 → 按比例退；
  - 恶意争议 → 可额外扣罚 **stake**（01 §5 十）。
- **重复争议**：disputeCounter 永久递增；arbFee_n = baseFee × 2^(n-1)，上限 ≤ 5×baseFee（08-3）。

---

## 4. 押金与平台费是否互斥

- **平台费**：仅在**资金终态**时从「给向导」或「已锁在合约」部分扣除，不在 deposit 时预扣。
- **押金**（若有）：按 01 §4 服务品质约束，每单接单时可要求按订单金额一定比例的押金；**订单终态后**无差评则退回，有差评则按规则扣除并减信用分；与 slash/信誉联动。**押金与平台费不互斥**：平台费从订单金额流中扣，押金为单独锁定/退回逻辑。

---

## 5. 小费通道（协议层定稿）

- 小费**是否进 snapshot**、**是否可争议**、**是否与主金额同通道链上支付**须在 03/08-3 定稿。
- 若进 escrow：须在资金流顺序中明确**小费分配时点**（与向导主金额同时放款或单独路径）。

---

## 6. 争议执行后资金分配顺序（执行器）

裁决执行时（executeResolution），链上**原子**完成：

1. 按裁决 amounts：**旅行者退款**、**向导所得**、**平台费**（若该终态收取）、**slash 归集**（链上载体以 **`IdentityStakingPool` 系** 与 **`SlashRouter`** 为准；概念侧「金库/销毁/保险口径」与 **81**/**08** 定稿及历史 **StakingInsurancePool** 用语同形，**非**旧 **`Staking.sol`** 合约树）；
2. **arbFee** 按裁决结果退/不退，与主金额分离；
3. 单笔 transfer 失败 → 整体 revert，禁止部分成功（01 资金坏链路 P0-5）。
