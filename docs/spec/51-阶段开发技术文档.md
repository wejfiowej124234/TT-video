### 2.3 企业级别标注要求

本文档采用统一**企业级别标注**，用于排期、验收与发版门禁。所有清单项与流程均按下列标注解读与执行。

| 标注类型 | 含义 | 适用位置 | 执行与验收要求 |
|----------|------|----------|----------------|
| **P0（发版前必做）** | 若本阶段以发版为终点，该项为门禁项，缺一不可 | §四 51-W1、51-W2；§五 发版前 P0 一览；§2.1 DoD 条件 3、4 | 发版前须全部完成并在对应清单打勾；与 07 §四 4.3、08-1 一致 |
| **P1（建议优先）** | 建议本阶段内优先完成；部分项发版前升格为 P0（如 51-W1/W2） | §四 优先级列 P1；§五 第一波/第二波部分项 | 排期时优先；51-D4 发版前为 Evidence 必填（见 §九 9.4） |
| **P2（可选/按需）** | 按资源与排期择机执行，非发版阻塞 | §四 优先级列 P2 | 验收标准见 §四 验收标准列；无门禁强制 |
| **P3（后续迭代）** | 明确留待后续版本或产品排期 | §四 优先级列 P3（如 51-31-4、51-31-27） | 可不纳入本阶段 DoD，仅勾选「已排期/已留痕」即可 |
| **Evidence 必填** | 发版前须产出可追溯产出物，不得占位 | §九 9.4 Evidence 产出物清单；51-D4（checklist-17）；08-2 工单 Evidence 列 | 路径或 manifest.sha256 填实；缺项则不得视为发版就绪 |
| **门禁（Gate）** | 必须通过的检查或审批节点 | 51-W1（闭环检查）、51-W2（闭环流程）；08-1 P0 门禁；27-P14 12 项 | §九 9.1 顺序执行；51-W2 含 07 §四 4.3、08-1、27-P14 |
| **DoD 条件** | 阶段完成定义，四条件全部满足方视为 51 闭环 | §2.1 表 1～4 | 总清单勾选 + 单测/集成/E2E 通过 + 51-W1 勾选通过 + 51-W2 执行通过 |
| **企业级验收** | 与 45/46/33/34/37/13-1 等企业级检查报告逐项对照 | §九 9.3 51-W1 可执行子清单；§八 深度检查 | 45 §8.4、§十二 a11y、37 i18n、13-1 异常态等按 9.3 表逐项勾选 |

**标注使用约定**：

- **§四 总清单**：「优先级」列即 P0/P1/P2/P3 标注；发版前仅 51-W1、51-W2 为 P0，其余 P1 项不自动升格。**51-D4** 标 P1，但因 51-W1 闭环检查依赖 checklist-17 勾选，故发版前 51-D4 未完成则 51-W1 不可通过，§五 发版前 P0 一览将其列为必做（Evidence 必填，见 §九 9.4）。
- **§五 发版前 P0 一览**：仅列发版时必做门禁；与 §2.3 中「P0」「门禁」标注一致。
- **§九**：9.3 为「企业级验收」可执行子清单；9.4 为「Evidence 必填」清单。二者均为企业级别标注的落地位置。
- **新增 51-xxx 时**：须在 §四 明确优先级（P1/P2/P3），若涉及 Evidence 或门禁须同步更新 §九 9.3/9.4 与 §2.3。
