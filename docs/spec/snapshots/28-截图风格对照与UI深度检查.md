## 5. 问题汇总与建议优先级

### 高优先级（与现行 SSOT）

1. **顶栏**：以 **86 §6.0** — L0 **按 pathname 分层**（Home / Cinematic / Dark / Light；与 **13-1**、**`uiSystem.test.ts`** 一致）。
2. **当前页 / 注册 CTA**：**已实现**（暖金/暖棕激活底条、`register` pill）；验收以 **`Header.tsx`** + **`marketingUi.ts`** 为准。
3. **与 Voyago 差异**：若需更强「叠在 Hero 上的玻璃叙事」，**仅**在 **Hero 区内**加强玻璃容器，**不**改 Header 分叉。

### 中优先级（形态更贴近截图 · 可选）

4. **顶栏浮条形态**：可选 — max-width + 居中 + 大圆角浮条；**若采纳须回改 86 §6.0 / 13-1**，与现行 **分层 L0** 矩阵一并评审。
5. **导航居中**：可选 — Logo 左、导航中、操作右。

### 低优先级 / 保持现状

6. **卡片玻璃感**：当前卡片已符合 P28；若需更强电影感，可为自由市场（**`/market`**）首卡加轻微 `backdrop-blur`，非必须。
7. **角色/钱包 pill**：右侧角色、Wallet 可包在半透明 pill 内，与截图「Kyoto, Japan」容器类似，属视觉增强。

## 6. 与 P28 规范的一致性

- **Experience 区**（Landing 正文 / **`/market`** 撮合页 / **`/traveltrust`** 长页）：插画或 **CSS 场域底** + 玻璃容器 + 微徽章；**L0 顶栏** 按路径分层（**86 §6.0**），Landing 杂志感在 **Hero 与表单区**。
- **Console 区**（Escrow/Dispute/订单/个人中心）：**Light** 浅条顶栏，符合「协议像银行」。
- **禁止项**：无大钱包 CTA、无裸色、无 Console 玻璃，已满足。

---

## 7. 实施建议

1. **维持 SSOT**：**不**恢复「仅 Landing 玻璃浅字顶栏」；高优先级 UI 债以 **Hero / 市场卡片 / 协议区** 为主。
2. **再评估中优先级**：浮条、导航居中是否上升为产品决策（需同步 **86 / 13-1**）。
3. **验收**：**`/`** Home 深条 + 暖金激活；**`/market`** Dark 深条；**`/orders/*`** Light 浅条 + 暖棕激活（**`headerNavLinkClasses`**）；注册 pill 随浅/深条变体；协议控制台见 **53 附录 D**。
