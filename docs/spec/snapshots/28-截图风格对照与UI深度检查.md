**对照依据**：Voyago 参考图（浮条玻璃顶栏、大圆角、浅字、插画 Hero）为**视觉对标**，**不覆盖**产品 SSOT。**现行顶栏 SSOT**：[86 §6.0](../86-UI-双系统未来风-风格与动效技术规格.md) + **`Header.tsx`**（`bg-white` + `border-ink-200`、`text-ink-900`、当前页 **`border-b-2`**、注册 **pill**、`WalletStatusMini` **`variant="dark"`**、轻 `backdrop-blur-sm`）。叙事与 Token 仍以 [28](../28-Cinematic-Glassmorphism-Web3融合规范.md)（P28）、[22](../22-Design-Tokens-旅游Web3融合体系-v1.0.md) 为准。  
**结论**：页身（Landing Hero / **`/traveltrust`** 深色壳 / **`/market`** 与 TravelTrust 同系暖场域底）与 P28 禁止项一致；与 Voyago 相比，**顶栏**有意采用**全站白底深字**（扫读与 IA 一致），**不作**首页单独玻璃浅字顶栏。下表保留「截图 vs 实现」维度，**实现列**以仓库代码为准；可选形态（浮条、导航居中）为低优先级。

## 5. 问题汇总与建议优先级

### 高优先级（与现行 SSOT）

1. **顶栏**：维持 **86 §6.0** — **全路由**白底深字、**不**按 pathname 切换玻璃浅字（与 **13-1** 一致）。
2. **当前页 / 注册 CTA**：**已实现**（`border-b-2`、`register` pill）；验收以 **`Header.tsx`** 为准。
3. **与 Voyago 差异**：若需更强「叠在 Hero 上的玻璃叙事」，**仅**在 **Hero 区内**加强玻璃容器，**不**改 Header 分叉。

### 中优先级（形态更贴近截图 · 可选）

4. **顶栏浮条形态**：可选 — max-width + 居中 + 大圆角浮条；**若采纳须回改 86 §6.0 / 13-1**，避免与「全站白顶栏」SSOT 冲突。
5. **导航居中**：可选 — Logo 左、导航中、操作右。

### 低优先级 / 保持现状

6. **卡片玻璃感**：当前卡片已符合 P28；若需更强电影感，可为自由市场（**`/market`**）首卡加轻微 `backdrop-blur`，非必须。
7. **角色/钱包 pill**：右侧角色、Wallet 可包在半透明 pill 内，与截图「Kyoto, Japan」容器类似，属视觉增强。

## 6. 与 P28 规范的一致性

- **Experience 区**（Landing 正文 / **`/market`** 撮合页 / **`/traveltrust`** 长页）：插画或 **CSS 场域底** + 玻璃容器 + 微徽章；**全局顶栏** 已统一为 **白底深字**（与 **86 §6.0** 一致），Landing 杂志感主要体现在 **Hero 与表单区**，而非顶栏玻璃浅字。
- **Console 区**（Escrow/Dispute/订单/个人中心）：顶栏保持非玻璃、深色字，符合「协议像银行」。
- **禁止项**：无大钱包 CTA、无裸色、无 Console 玻璃，已满足。

---

## 7. 实施建议

1. **维持 SSOT**：**不**恢复「仅 Landing 玻璃浅字顶栏」；高优先级 UI 债以 **Hero / 市场卡片 / 协议区** 为主。
2. **再评估中优先级**：浮条、导航居中是否上升为产品决策（需同步 **86 / 13-1**）。
3. **验收**：首页与 **`/market`** 下顶栏为 **白底深字 + active 下划线 + 注册 pill**（**`/discover`→`/market`** 见 **04 §3.4**）；**`/orders/*`** 等页顶栏**同为**白顶栏；协议控制台赛博区见 **53 附录 D**。
