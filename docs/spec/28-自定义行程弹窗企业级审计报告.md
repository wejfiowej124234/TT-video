## 一、已修复项（本轮实现）

| 类别 | 问题 | 修复方式 |
|------|------|----------|
| 键盘/焦点 | 按 Escape 时若景区详情浮层已打开，会直接关闭主弹窗 | 使用 `viewingAttractionRef`，Escape 时先关闭浮层，仅无浮层时再 `onClose()` |
| 键盘/焦点 | 景区浮层打开时 Tab 会跑出浮层进入主表单 | 焦点陷阱按“当前是否有浮层”选择容器：有浮层用 `attractionOverlayRef`，否则用 `dialogRef` |
| 体验 | 点击景区浮层背景无法关闭 | 在浮层根节点增加 `onClick={() => setViewingAttraction(null)}`，内层卡片 `stopPropagation` |
| i18n | 景区浮层关闭按钮与冗余背景按钮写死「关闭」 | 使用 `t("common_close")`，并新增 `common_close`（zh/en） |
| i18n | 总天数下拉选项写死「N 天」 | 使用 `t("market_dayUnit")`，新增 `market_dayUnit`（{{n}} 天 / {{n}} days） |
| i18n | 默认标题写死「城市 · N天行程」 | 使用 `t("market_defaultTitle")`，新增 `market_defaultTitle`（zh/en） |
| i18n | 订单亮点中「景区：」「美食：」「酒店：」写死中文 | 使用 `t("market_highlightAttractions/Food/Hotel")` 构建 highlights |
| 校验/体验 | 人数可输入 0 或 >20，仅提交时报错 | `onChange` 中限制 `headcount = Math.min(20, Math.max(1, v))` |
| 安全/体验 | 封面 URL 输入可粘贴超长字符串（如巨大 data URL） | URL 输入 `maxLength={4096}`，`onChange` 中 `slice(0, 4096)` |

## 二、无障碍（a11y）检查

| 项 | 状态 | 说明 |
|----|------|------|
| 主弹窗 | ✅ | `role="dialog"`、`aria-modal="true"`、`aria-labelledby`、`aria-describedby`（有错误时） |
| 错误信息 | ✅ | `id="custom-itinerary-error"`、`role="alert"`，提交失败时滚动到视野 |
| 焦点陷阱 | ✅ | Tab/Shift+Tab 限制在主弹窗或景区浮层内，按当前层切换容器 |
| 初始焦点 | ✅ | 打开弹窗后约 100ms 聚焦第一个可聚焦元素 |
| 景区浮层 | ✅ | `role="dialog"`、`aria-modal="true"`、`aria-label` 为景区名称，关闭按钮 `aria-label` 已 i18n |
| 表单项 | ✅ | 主要输入均有 `label` + `id`/`htmlFor` 或 `aria-label`（如 GlassSelect） |
| 封面上传 | ✅ | 文件上传用 `sr-only` 的 label，可见为「上传图片」 |

建议（可选）：为「第 N 天」区块增加 `aria-describedby` 指向当日摘要，便于读屏用户快速理解当前区块。

## 三、数据与校验

| 项 | 状态 | 说明 |
|----|------|------|
| 金额格式 | ✅ | 总预算/向导费/交通费使用 `sanitizeDecimalInput`，仅数字与一个小数点、最多 2 位小数 |
| 负值与上限 | ✅ | 提交前校验 `guideFeeNum`、`transportFeeNum` 非负且 ≤ 999999 |
| 人数 | ✅ | 提交时 1–20，输入时已限制在 1–20 |
| 标题/描述长度 | ✅ | 标题 50、描述 500，`maxLength` + `onChange` 截断 + 字数展示 |
| 封面文件 | ✅ | 上传文件 >2MB 时提示并清空，不写入 `form.image` |
| 封面 URL | ✅ | 输入长度限制 4096，防止超长 data URL 或恶意长串 |

可选增强：对 URL 输入做格式校验（仅允许 `http(s):` 或 `data:`），并统一错误提示的 locale key（如 `market_coverUrlInvalid`）。

## 五、与订单详情抽屉的一致性

- **OrderDetailDrawer** 已对城市交通、跨城、向导费、交通费、酒店/餐饮/门票/其他等使用 `order_*` 与 `market_*` 的 i18n，与弹窗侧文案体系一致。
- 订单状态（STATUS_LABEL）在抽屉内仍为硬编码中英混合，若需完整 i18n 可后续为状态增加 `order_statusDraft` 等 key 并替换。

## 六、建议后续优化（非必须）

1. **LocaleProvider 插值**：当前 `t(key)` 不支持 `{{n}}`，多处使用 `.replace("{{n}}", ...)`。可考虑在 Provider 内统一支持第二参数插值，减少重复 replace。
2. **景区浮层初始焦点**：浮层打开时可将焦点设到关闭按钮，便于键盘用户立即关闭。
3. **总预算与拆分关系**：已有「总预算低于向导+交通」提示；若产品需要，可增加「总预算建议包含向导与交通」的说明文案 key。
4. **订单详情抽屉状态文案**：将 `STATUS_LABEL` 改为 `t("order_statusDraft")` 等，实现全页状态文案 i18n。

## 七、深度检查补充（第二轮）

| 类别 | 问题 | 修复/说明 |
|------|------|-----------|
| **Bug** | 向导费/交通费为负或超 999999 时提前 return，但此前已执行 `setSubmitting(true)`，导致提交按钮一直禁用 | 将 `setSubmitting(true)` 移至所有校验通过之后、`try { onSubmit(...) }` 之前，避免提前 return 时未执行 `setSubmitting(false)` |
| **i18n** | 订单亮点中景区/美食列表使用硬编码「、」连接，英文应为 "," | 新增 `market_listSeparator`（zh: "、", en: ", "），构建 highlights 时用 `t("market_listSeparator")` 作为 join 分隔符 |
| **OrderDetailDrawer** | 标题「订单详情」、关闭按钮 aria、图片加载失败、天数/人数/版本、链上托管、状态文案均为硬编码 | 新增 `order_drawerTitle`、`order_closeDrawer`、`order_imageLoadFailed`、`order_dayUnit`、`order_personUnit`、`order_versionLabel`、`order_onChain` 及 `order_status*`，抽屉内全部改为 `t(...)` |

## 八、结论

自定义行程弹窗在**键盘与焦点、Escape 层级、浮层关闭方式、金额与人数校验、标题/描述/封面长度与 URL 长度、提交状态与校验顺序、亮点分隔符与订单详情抽屉 i18n** 方面已满足企业级使用要求；下列为**剩余可优化项**，按优先级排列，不影响当前发布。

---

## 九、剩余可优化项（按优先级）

### 高优先级（体验/一致性）

| 项 | 说明 | 建议 |
|----|------|------|
| **LocaleProvider 插值** | 当前 `t(key)` 不支持 `{{n}}`，弹窗与抽屉内大量 `.replace("{{n}}", ...)`、`.replace("{{min}}", ...)` 等 | 在 Provider 的 `t` 中支持第二参数 `t(key, { n, min, max, amount, city, days })`，内部做字符串替换，减少各组件重复 replace |
| **景区浮层初始焦点** | 打开景区详情浮层后焦点仍在主表单，键盘用户需 Tab 多次才能到关闭按钮 | 浮层挂载后 `useEffect` 内对 `attractionOverlayRef` 下第一个可聚焦元素（关闭按钮）执行 `focus()` |

### 中优先级（体验/健壮性）

| 项 | 说明 | 建议 |
|----|------|------|
| **封面 URL 格式校验** | 仅限制长度 4096，未校验协议（如仅允许 `http(s):` 或 `data:`） | 提交或 onBlur 时校验；非法时提示 `market_coverUrlInvalid`，不写入 `form.image` 或清空 |
| **人数输入 onBlur 兜底** | 用户清空人数后未输入就失焦时，`form.headcount` 可能仍为旧值 | onBlur 时若 `value === ""` 或 `Number(value)` 不在 1–20，则 `setForm(..., headcount: 1)` |
| **「第 N 天」区块 a11y** | 读屏用户难以快速理解当前是第几天、当天有哪些选择 | 为每日区块的标题/容器增加 `aria-describedby` 指向简短摘要（如「第 N 天，城市：北京」） |

### 低优先级（锦上添花）

| 项 | 说明 | 建议 |
|----|------|------|
| **总预算说明文案** | 已有「总预算低于向导+交通」提示 | 可增加「总预算建议包含向导与交通费」的说明 key，放在预算输入下方 |
| **订单卡片「链上托管」** | `OrderCard` 内「Polygon · USDC · 链上托管」仍为硬编码 | 抽成 `order_onChainCard` 或复用 `order_onChain`，与抽屉一致 |
| **GlassSelect 下拉 Escape** | 下拉展开时按 Escape 只关闭下拉，不关主弹窗 | 当前行为合理；若产品要求「Escape 一律先关最内层」已满足（景区浮层→主弹窗） |
| **多语言下 highlights 语言** | 订单创建时用当前 locale 生成 highlights，切换语言后抽屉仍显示创建时语言 | 可接受；若需「始终按当前语言展示」需存结构化数据并在展示时再 `t()` 拼接 |

| **设计 Tokens** | 弹窗与市场页若需严格遵循 Design Tokens（如 22 设计规范），可把圆角/阴影等再对一遍变量 |
