## 文档定位

本表为 **第一阶段** 面向 **10 个国家市场** 的 **Country Pool（国家池）** 发行与募资参数的**单源总表**，可直接拆解用于：

- 白皮书附录或独立章节；
- 融资 PPT 数据页；
- 官网「国家 / 区域」说明；
- APP 认领国家流程与限额展示；
- DAO 治理文档中的额度与阶段定义。

**术语（与 83 对齐）**：本文 **Country / 国家池** 与 [83](83-区域治理与收益分配-协议白皮书.md) 中的 **Region** 在**产品与地理口径上同构**（一国或单一合规区对应一圈）；链上合约命名（RegionVault / Country Pool）以实现与 **14** 为准。

**数据口径**：入境旅行者规模、入境旅游收入等宜以 **UNWTO**、各国旅游局 / 统计局等**官方或权威统计**为复核来源；下表数字为 **拟定展示值**，**每一轮融资前须用最新官方数据重算评分与额度**，并更新本表版本号。

**与 [83](83-区域治理与收益分配-协议白皮书.md) 的关系**：

- **83 v1.1.0+** 与 **84** 共用同一套 **FeeRouter 第一层（45% / 55%）** 与 **Global Pool 内（65% / 20% / 15%）**；**83** 承载 **RegionVault / Seat / Snapshot / DAO 附录** 等完整协议规格。
- **84** 专责 **Phase 1 十国**承销与募资表、**费用 vs 承销分母**（§1.3、§三）、**代币总量内国家桶 vs 个人桶与估值锚**（**§1.5**）、**APP 认领** 与对外融资拆解。
- **旧版 83** 中 **35% / 65%** 与 **70% / 30%** 已迁入 **83 §3.1 历史草案**，**勿**再用于新稿。

#### 1.1.1 可分配平台费用基数（闭合口径）

#### 1.2.1 协议金库与资金流分轨（对内闭合）

**目的**：把 **「用户用稳定币换 TTG / 募资进账」** 与 **「订单可分配手续费经 FeeRouter 进入 §1.1～§1.2」** 写成**两条可审计资金流**，避免对外/对内把「协议金库」与 **Global Pool（本节约束下的手续费路由叙事）** 混为同一物理池或同一分母。

1. **分轨 A — 订单可分配手续费（本节主表）**  
   **基数**为 **§1.1.1** 之 **可分配平台费用 100%** → **§1.1** 第一层 **45% / 55%** → **§1.2** Global Pool 内 **65% / 20% / 15%**。该路径与 **[83](83-区域治理与收益分配-协议白皮书.md) §3**、**[Runbook](../../ops/RUNBOOK.md) §7.1**、**08-4 附录图** 一致；链上真值以合约为准。

2. **分轨 B — 稳定币认购 / 换 TTG（代币发行与金库）**  
   用户以 **USDT/USDC** 等参与 **认购、兑换、融资页**（见 **[85](85-TravelTrust网络落地页-融资级设计与开发规格.md)**、**§1.5**、**[governance-token/02 §2.5](governance-token/02-对内技术规格-草案.md)**）所得稳定币，归属 **协议金库（Treasury）** 及其 **子科目**（研发、运营、安全、基础设施、**储备** 等），**不**自动计入 **§1.1** 分母；**不得**与 **Escrow 订单托管本金** 混路径（**[01](01-总库总览.md)**、**[governance-token/02 §4.7](governance-token/02-对内技术规格-草案.md)**）。**Escrow 托管本金不得通过 Governor 提案直接划付或调用支取**（与 **[governance-token/02 §4.6](governance-token/02-对内技术规格-草案.md)** 金库行一致）。  
   **入账时点（防 API / 索引器 / 会计分歧）**：以 **产品定义的认购或换币成交** 为准——在 **链上交易终局性满足部署约定**（如 **finality N**、receipt 确认）后，稳定币计入 **Treasury 合约地址** 或 **披露之托管/多签地址**；**HTTP 响应、`transfer` 事件、内部台账** 须同一口径登记，**禁止**「前端成功即视为已入金库」与链上状态脱节。

3. **协议金库用途（产品 Target；对外须 08-4 + LEGAL-SIGNOFF）**  
   金库内稳定币可用于 **协议研发、运营、安全、基础设施与协议储备**；**储备**子账可覆盖 **流动性管理** 及经 **治理（Governor/Timelock）+ 披露** 审定的 **规则化** 二级市场操作（例如回购/承接类机制）。**禁止**在对外材料使用 **§1.5** 已列之 **「分红」「固定收益」** 等表述替代本节机制；证券与市场行为边界以法务定稿为准。

4. **§1.2 中「储备（Reserve）20%」与协议金库**  
   该 **20%** 为 **Global Pool 自身 100%** 内的 **储备切片**（手续费叙事）。在会计与实现上 **可** 记为 **协议金库项下「储备」子科目**，或经 **治理 / 多签 / 已披露程序** **划转、映射** 至 **`GovernanceTreasury`**（或 **[contracts/README](../../contracts/README.md)** 部署清单中的等价地址）。**不自动等同于** **`GovernanceTreasury`（或托管地址）的即时链上余额展示**；**不得**工程理解为「手续费一入账即**自动归集**至金库」——是否归集、何时归集以 **合约事件 + 治理参数** 为准。**不**改变 **§1.2** 三行比例之**解释结构**，亦**不**与 **分轨 B** 混账，除非经 **07 §二 2.4** 同批修订披露与图示。

5. **「TTG 质押者 65%」≠ 全体持币按比例分红**  
   **65%** 指 **Global Pool 内部**划给 **TTG 质押激励** 叙事之份额；**不是**「向所有 TTG 持有人按持仓比例分配公司利润」。与 **向导订单 USDC 质押（[81](81-经济模型-向导质押与订单押金.md)）** 区分；对外措辞仍遵守 **§1.5** 与 **[83 §19](83-区域治理与收益分配-协议白皮书.md)**。

## 二、国家定价模型（写入白皮书正文可用）

**国家评分**（归一化后用于定级与额度带内取值）：

\[
\text{国家评分} = 0.6 \times f(\text{入境旅行者规模}) + 0.4 \times g(\text{入境旅游收入 / 消费能力})
\]

其中 \(f\)、\(g\) 为团队选定的**单调归一化函数**（如对数标度 + 分位裁剪），须在数据附录或对内规格中给出版本，避免复盘时不可复算。

**等级与费用侧上限档位**（与 §四 主表「**国家池额度**」列同义；单位为 **占 §1.1 基数 100% 的百分点**，用于治理与产品展示「该国天花板」，**非**当期必然兑现流量）：

| 等级 | 定义 | 各国费用侧上限档位（百分点） |
|------|------|------------------------------|
| S | 全球核心旅游国 | 4.0～4.5 |
| A | 高价值市场 | 2.0～3.0 |
| B | 中等市场 | 1.0～2.0 |
| C | 小市场 | 0.5～1.0 |

单国在带内取值由评分排序与治理程序最终确认。

## 七、APP 认领国家机制（产品必选流程）

1. 用户选择国家 / 区域。  
2. 存入 **USDT / USDC**（或治理批准的同风险等级稳定币）。  
3. 资金进入对应 **Country Pool**（链上托管与限额逻辑以实现为准）。  
4. 达到该国家 **募资目标** 后 **自动关闭** 该轮次（**无硬顶列**；目标见 **country-pool-fundraise-governance-v1**）。  
5. 用户获得 **国家 DAO 份额 / 凭证**（命名以实现与 08-4 披露为准）。  
6. **锁仓** → **质押**（若产品要求）→ 按规则参与 **国家可分配费用桶（45%）** 侧 **协议可分配费用参与**（**非**「国家分红」口语，见 **§1.5**）。

**约束**：后端不得改写池内余额与分配比例；**链上为准**与 **83**、**14** 对齐。

## 八、模型要点（对外叙事可用，非收益承诺）

- 投资人可理解「按国家池认购」的资产边界与阶段上限。  
- 价值与现金流叙事锚定在 **平台费用与已披露协议分配机制**（**非**承诺「分红」或公司利润分配），而非二级炒作。  
- 国家维度与 DAO 披露有利于扩展至更多国家（例如远期 **50 国** 路线图须单独版本表）。  
- 须配合 **83** 的风险披露与 **08-4** 证券隔离表述；**不得**承诺固定收益或等同于股权。  
- **向导质押（81）** 与 **TTG 质押** 为不同合约与不同风险，对外文案须分称；避免「质押即分红」等表述，改用 **§1.5** 推荐用语。
