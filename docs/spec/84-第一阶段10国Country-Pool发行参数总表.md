## 文档定位

本表为 **第一阶段** 面向 **10 个国家市场** 的 **Country Pool（国家池）** 发行与募资参数的**单源总表**，可直接拆解用于：

- 白皮书附录或独立章节；
- 融资 PPT 数据页；
- 官网「国家 / 区域」说明；
- APP 认领国家流程与限额展示；
- DAO 治理文档中的额度与阶段定义。

**术语（与 83 对齐）**：本文 **Country / 国家池** 与 [83](83-区域治理与收益分配-协议白皮书.md) 中的 **Region** 在**产品与地理口径上同构**（一国或单一合规区对应一圈）；链上合约命名（RegionVault / Country Pool）以实现与 **14** 为准。

**数据口径**：入境游客规模、入境旅游收入等宜以 **UNWTO**、各国旅游局 / 统计局等**官方或权威统计**为复核来源；下表数字为 **拟定展示值**，**每一轮融资前须用最新官方数据重算评分与额度**，并更新本表版本号。

**与 [83](83-区域治理与收益分配-协议白皮书.md) 的关系**：

- **83 v1.1.0+** 与 **84** 共用同一套 **FeeRouter 第一层（45% / 55%）** 与 **Global Pool 内（65% / 20% / 15%）**；**83** 承载 **RegionVault / Seat / Snapshot / DAO 附录** 等完整协议规格。
- **84** 专责 **Phase 1 十国**承销与募资表、**费用 vs 承销分母**（§1.3、§三）、**代币总量内国家桶 vs 个人桶与估值锚**（**§1.5**）、**APP 认领** 与对外融资拆解。
- **旧版 83** 中 **35% / 65%** 与 **70% / 30%** 已迁入 **83 §3.1 历史草案**，**勿**再用于新稿。

## 一、收益拆分规则（本版对外口径）

### 1.1 第一层（国家维度）

**基数**：**可分配平台费用** 记为 **100%**，**定义见 §1.1.1**（与 [Runbook §7.1](../../ops/RUNBOOK.md) **仲裁费/罚没正交** 一致）。

#### 1.1.1 可分配平台费用基数（闭合口径）

1. **计入本 100% 分母的**：按产品与合约规则 **进入 FeeRouter（或等效链上归集入口）** 的 **订单相关可分配手续费**（allowlist 稳定币计价）。**§1.1 表内 45% + 55%** 仅对该分母生效。  
2. **明确不计入、不扣减本基数**：各参与方为**自身**链上交易支付的 **L1/L2 网络 gas**；由交易发送方另行承担，**不**从本 **100%** 中扣除。  
3. **与 FeeRouter 第一层正交（不参与 45/55 拆分）**：**争议仲裁费 / 仲裁运营成本**、**向导 `Staking.slash` 罚没的质押品（如 USDC）** 等 — 归宿与会计科目见 **[Runbook](../../ops/RUNBOOK.md) §7.1** 专表；**禁止**与「可分配手续费」混同一条分配公式（与 [08-4-对外口径包](08-4-对外口径包.md) 收益流、**82 §六 T5** 一致）。  
4. **若未来**将「争议处理费从基数扣除」等纳入产品决策，须同步修订本条、**08-4**、**Runbook §7.1** 并 bump **84** 版本。

| 去向 | 比例 |
|------|------|
| 国家可分配费用桶（按国再分 / 对齐 Country Pool 叙事） | **45%** |
| Global Pool | **55%** |

### 1.2 第二层（Global Pool）

| 去向 | 占 Global Pool |
|------|----------------|
| TTG 质押者 | **65%** |
| 储备（Reserve） | **20%** |

### 1.3 两套「百分比」分母（必读，避免误读）

| 维度 | 含义 | 本版数字 |
|------|------|----------|
| **费用归因** | 相对 **§1.1 基数 100%**（可分配平台费用） | **45%** / **55%** |
| **承销 / 份额上限** | 相对 **「国家/区域相关份额」总承销盘子**（与 TTG 总盘子关系在代币 SSOT 写死） | **25%** 为国家池相关承销**总上限** |
| **Phase 1 十国（承销侧）** | 首轮动用上列 **25%** 承销桶中约 **一半** | **≈50%**（即约 **12.5%** 总承销，与代币经济定稿数对齐后不得口头漂移） |

**禁止误用**：**25%（承销）** 与下表 **「国家池额度」百分点之和 29**（与 **§四** 主表十行加总一致）**不得**在同一分母下相加比较——前者锚 **Token/份额**，后者锚 **费用展示上限（百分点）**，见 **§三**。

### 1.4 费用侧：「第一阶段 ≈ 50% 国家池」校验（闭合）

- **国家可分配费用桶** = **45%**（§1.1）。
- **「首轮开放」列**（§四）：各国 Phase 1 **切入费用路由的展示强度**，以 **占 §1.1 基数 100% 的百分点** 计。
- 十国 **首轮开放** 合计：  
  `3+3+3.5+3.5+2+2+1.5+1.5+1+1` = **22 百分点**。
- **22 ÷ 45 ≈ 48.9%** ↔ 产品表述 **「第一阶段十国约占国家池（费用侧）一半」**。

### 1.5 代币总量 100% 内：国家承销桶与个人承销桶 · 估值锚 · 对外措辞（合规）

**供给结构（与 §1.3「25%」衔接）**：治理代币（工作名 **TTG**，以实现与 **代币 SSOT** 为准）**总供应量 100%** 的**行级分解**见 [governance-token/02-对内技术规格-草案](governance-token/02-对内技术规格-草案.md) **§2.5**（**占位可修订**，与下列两桶叙事一致）。其中：

| 桶（工作名） | 典型上限（相对 **100% 总量**） | 认购/融资叙事 |

| **国家池相关承销** | **≤25%**（见 **§1.3**；十国表为本桶 Phase 1 用法之一） | 经 **Country Pool / RegionShare** 等路径，参与 **§1.1 中 45% 国家可分配费用桶** 之下、按 **83** Snapshot/Claim 的**区域侧**规则 |
| **个人 / 全局承销**（非国家桶） | **其余份额**由 **代币 SSOT** 单列（公募、生态、团队、顾问等子桶之和 = **75% − 未计入国家桶的保留**等，**以定稿表为准**） | **协议级**参与：与 **§1.1 之 55% Global Pool** 及 [83](83-区域治理与收益分配-协议白皮书.md) 已披露之 TTG 激励/治理规则一致；**不**因仅持有「个人桶」代币而**自动**取得 **45% 国家桶**内按国 Snapshot/Claim 资格（除非**另行**持有该国 **RegionShare** 或治理另有规定） |

## 二、国家定价模型（写入白皮书正文可用）

**国家评分**（归一化后用于定级与额度带内取值）：

\[
\text{国家评分} = 0.6 \times f(\text{入境游客规模}) + 0.4 \times g(\text{入境旅游收入 / 消费能力})
\]

其中 \(f\)、\(g\) 为团队选定的**单调归一化函数**（如对数标度 + 分位裁剪），须在数据附录或对内规格中给出版本，避免复盘时不可复算。

**等级与费用侧上限档位**（与 §四 主表「**国家池额度**」列同义；单位为 **占 §1.1 基数 100% 的百分点**，用于治理与产品展示「该国天花板」，**非**当期必然兑现流量）：

| 等级 | 定义 | 各国费用侧上限档位（百分点） |
|------|------|------------------------------|
| S | 全球核心旅游国 | 4.0～4.5 |
| A | 高价值市场 | 2.0～3.0 |
| B | 中等市场 | 1.0～2.0 |
| C | 小市场 | 0.5～1.0 |

单国在带内取值由评分排序与治理程序最终确认。

## 三、列定义与加总校验

### 3.1 主表（§四）各列含义

| 列名 | 定义 |
|------|------|
| **国家池额度** | 该国 **全周期名义上限档位**（**费用百分点**，同 §二）。**不是**当期从 FeeRouter 实际划出的流量；**不是**承销 25% 分母上的百分比。 |
| **首轮开放** | Phase 1 该国 **费用路由展示份额**（**费用百分点**）；十国合计 **22**，且 **22/45≈48.9%**，见 **§1.4**。 |
| **募资目标 / 硬顶** | 该国 **法币承销**目标与上限（万元人民币）；与 **费用百分点** 的换算须在 **代币 SSOT** 中给 **固定公式或查表**（本文不代替该换算）。 |

### 3.2 加总（避免「29 > 25」与分母混读）

| 项目 | 数值 | 说明 |
|------|------|------|
| **首轮开放** 合计 | **22 百分点** | 相对 **100% 可分配费用**；占 **45% 国家桶** 的 **≈48.9%**。 |
| **国家池额度** 合计 | **29 百分点** | 十国 **上限** 之和（**§四** 主表「国家池额度」列逐行相加：`4+4+4.5+4.5+2.5+2.5+2+2+1.5+1.5=29`）；**不**表示单次结算同时划出 29%；**任一周期** 进入「按国分配」路径的流量仍受 **FeeRouter ≤45%** 与 **83** Snapshot 规则约束。 |
| **承销「国家池总上限 25%」** | **25%** | 相对 **区域/国家份额总承销盘子**；**与 29 费用百分点无直接可比性**（分母不同，勿数值直连比较）。 |

### 3.4 「治理币总量固定」与募资目标：必须统一的估值锚（易混读说明）

**先澄清**：主表 **「国家池额度（费用百分点）」** 描述的是 **可分配平台费用** 在 **§1.1 基数 100%** 下的 **路由/展示上限权重**（费用侧），**不是**「该国占 **TTG / RegionShare 固定总供应量** 的百分之几」。二者 **单位不同**，**不能**把「中国 4.0」口头说成「拿了 4% 治理币总量」——除非在 **代币 SSOT** 里 **另行定义** 费用权重与 token 分配的一一映射，并在对外稿中 **同一句话写清**。

**你关心的自洽性（法币募资 ↔ 固定总量）**：若治理代币（或国家池可认购份额）**总量与轮次配售计划**已定，则 **各国「募资目标 / 硬顶」** 在数学上应对齐 **同一个锚**，例如（择一在 **代币 SSOT + 本文** 写死，避免投资人各按各的「市值」脑补）：

| 锚定方式（示例） | 含义 | 与主表关系 |
|------------------|------|------------|
| **A. 承销份额优先** | 先定 Phase 1 各国占 **国家池承销子桶**（如相对 **§1.3** 所述 **25%** 总承销盘子）的 **份额 \(s_i\)**，再 **`募资_i ≈ 单价 × 分配代币_i`**，且 **`分配代币_i ∝ s_i`** | **募资目标** 与 **`s_i` 成比例**；**费用百分点** 可与 \(s_i\) **相关但不必数值相等**（一个是链上费用路由，一个是本轮卖了多少份额） |
| **B. 费用权重派生份额** | 规定 **\(s_i\)** 与 **「首轮开放」或「国家池额度」** 按 **固定函数** 生成（如正比于首轮开放百分点），再反算法币募资 | 表中 **募资** 须 **按该函数重算**，保证「**万元 / 百分点**」在规则下 **可解释** |
| **C. 总盘子倒推** | 先定 **本轮 FDV（或总募资）** 与 **各国故事权重**，再拆 **募资_i**；**费用百分点** 单独由治理与协议定 | 允许 **募资与费用% 非线性**，但须在 **白皮书 / 84** 写明 **「两列独立维度、不设隐含线性市值」**，避免读者误用「4.0% ↔ 6000 万」外推法国、日本 |

**当前主表（§四）状态**：**募资目标 / 硬顶** 为 **拟定展示值**；按 **国家池额度** 粗算 **募资目标（万元）÷ 国家池额度（百分点）** **在国与国之间并不恒定**（例如同一表内会落在约 **1200～2000 万元/百分点** 量级），说明 **尚未**采用 **单一比例标尺** 锁定——**不是笔误**，而是 **代币 SSOT 未定稿前的占位**。**定稿前必须**：在 **governance-token 对内规格或代币经济单页** 选定 **A/B/C 之一**，**重算或重述** 本表募资列，并同步 **82/83/08-4/governance-token/03**。

### 3.5 §四 主表企业级定稿门禁（融资列）

## 七、APP 认领国家机制（产品必选流程）

1. 用户选择国家 / 区域。  
2. 存入 **USDT / USDC**（或治理批准的同风险等级稳定币）。  
3. 资金进入对应 **Country Pool**（链上托管与限额逻辑以实现为准）。  
4. 达到该国家 **募资目标** 或 **硬顶规则** 后 **自动关闭** 该轮次。  
5. 用户获得 **国家 DAO 份额 / 凭证**（命名以实现与 08-4 披露为准）。  
6. **锁仓** → **质押**（若产品要求）→ 按规则参与 **国家可分配费用桶（45%）** 侧 **协议可分配费用参与**（**非**「国家分红」口语，见 **§1.5**）。

**约束**：后端不得改写池内余额与分配比例；**链上为准**与 **83**、**14** 对齐。

## 八、模型要点（对外叙事可用，非收益承诺）

- 投资人可理解「按国家池认购」的资产边界与阶段上限。  
- 价值与现金流叙事锚定在 **平台费用与已披露协议分配机制**（**非**承诺「分红」或公司利润分配），而非二级炒作。  
- 国家维度与 DAO 披露有利于扩展至更多国家（例如远期 **50 国** 路线图须单独版本表）。  
- 须配合 **83** 的风险披露与 **08-4** 证券隔离表述；**不得**承诺固定收益或等同于股权。  
- **向导质押（81）** 与 **TTG 质押** 为不同合约与不同风险，对外文案须分称；避免「质押即分红」等表述，改用 **§1.5** 推荐用语。
