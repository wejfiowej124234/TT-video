**状态**：`Target`（文档已建；链上治理代币未发行前，实现状态以代码与 01/08-4 为准）  
**受众**：产品、架构、法务（对外稿）、工程（对内稿）  
**维护**：治理或经济模型负责人；**对外正文措辞变更须与 [08-4-对外口径包](08-4-对外口径包.md) 及 ToS 一致**。

## 一、为何单独成册

治理币涉及 **合规叙事、证券属性边界、对外披露与对内实现** 的分工，不宜散落在阶段文档中。本编号 **82** 为治理币主题的**唯一编号入口**；正文分册放在 **`governance-token/`** 目录，便于版本管理与权限控制（例如对外 PDF 从内链导出、对内保留实现细节）。

## 三、与总库及合规的硬约束对齐

- **[01-总库总览](01-总库总览.md)**：**MVP 不发行平台支付币**；结算以 allowlist 稳定币（如 USDC）为准；治理代币若引入，**不得**替代旅行订单计价与 Escrow 结算币种，除非单独产品决策并全量更新 01/04/14/08-4。
- **[08-1-战略与合规风险检查清单](08-1-战略与合规风险检查清单.md)**：治理升级、Timelock、多签与「治理币与升级安全模型」等条款优先。
- **[08-4-对外口径包](08-4-对外口径包.md)**：收益流、**是否分红/是否与治理币价值绑定**、证券隔离等 **必须与对外白皮书一致**；对外白皮书定稿前以 08-4 为上限约束。
- **[81-经济模型-向导质押与订单押金](81-经济模型-向导质押与订单押金.md)**：当前链上质押示例为 **ERC-20 质押品（如 USDC）**，与「治理代币」分属不同设计对象；对内规格中须区分 **质押资产** vs **治理/激励代币**。
- **[49-阶段建议-下一阶段方向与优先级](49-阶段建议-下一阶段方向与优先级.md) §G**：治理与激励产品步骤与占位接口；细化规则时以本文档分册为补充 SSOT。
- **[83-区域治理与收益分配-协议白皮书](83-区域治理与收益分配-协议白皮书.md)**：多区域 **Region/Seat/Share**、Vault 与分配、DAO 权限边界、Buyout/Snapshot/Claim 及 **附录 I/J**（职责矩阵与状态机总图）；与治理币叙事、Fee/Treasury 口径交叉时须三方（83/82/08-4）一致。
- **[84-第一阶段10国Country-Pool发行参数总表](84-第一阶段10国Country-Pool发行参数总表.md)**：第一阶段 **Country Pool** 国家表与 **45%/55%**、承销 vs 费用分母；**已与 83 v1.1.0+ §3 合并为同一套 FeeRouter 叙事**，对外数字以 **83 §3 + 84 §一** 为双锚、**08-4 附录图** 为展示单页；后续**任一侧**改百分数须按 [07 §2.4](07-开发流程与顺序.md) **同批**改对侧、附录图与 **governance-token/03**，并跑 `check-governance-doc-linkage.sh`。

## 四、企业级发布门禁（摘要）

1. 对外白皮书：**法务书面定稿** + 版本号/日期 + 与 08-4 交叉审阅无冲突。  
2. 对内规格：任何链上代币/新增表/路由变更须同步 **04 §3.4**、**14**、ABI 单源与 CI 门禁。  
3. **禁止**：对外稿出现「保证收益」「等同于股权/分红」等表述；详见对外白皮书「合规与表述边界」节。  
4. **文档联动**：新增或重大修订 `82` / `83` / `84` / `governance-token/*` 时，须按 [07-开发流程与顺序 §2.4](07-开发流程与顺序.md) 更新 [00-文档索引](00-文档索引.md)、[00-最终版架构图对应模块清单总表](00-最终版架构图对应模块清单总表.md) §二点五、**[07](07-开发流程与顺序.md) §零 0.3**（及 [00-文档体系与阅读串联](00-文档体系与阅读串联.md) 兼容壳关键词；若索引已含可核对，不得长期漂移）；合并前须通过 `scripts/check-governance-doc-linkage.sh`（见 [.github/workflows/governance-doc-linkage-gate.yml](../../.github/workflows/governance-doc-linkage-gate.yml)）。  
5. **法务签核**：对外白皮书（中/英）定稿前须完成 [governance-token/LEGAL-SIGNOFF-CHECKLIST](governance-token/LEGAL-SIGNOFF-CHECKLIST.md)。
