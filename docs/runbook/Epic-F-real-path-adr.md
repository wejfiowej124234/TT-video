# ADR · Epic F — E2E「真实路径」载体（钉死）

**状态**：Accepted  
**日期**：2026-04-09  
**范围**：**Epic F** 发布前 **E2E 三项包** 中，**后续 F-08** 自动化所依赖的 **唯一钉死真实路径**（本 ADR **不**新增测试、**不**改代码）。

**互证**：[Epic-F-e2e-three-pack-ladder.md](./Epic-F-e2e-three-pack-ladder.md) · [01 §9 发布与 E2E（P2）](../spec/01-总库总览.md) · [07 §二 2.1](../spec/07-开发流程与顺序.md#21-顺序约束简要) · [Epic D 表 · F 行](./Epic-D-indexer-ops-readonly-ladder.md)

---

## 1. 真实路径载体（二选一 · 已选定）

| 选项 | 说明 | **本仓库裁定** |
|------|------|----------------|
| **A** | **本地链 + 本地 API**（如 **Docker Compose**、**Anvil/本地 RPC**、**`scripts/start_dev.sh` / `start-api-with-seed`** 等 dev stack） | **✅ 采用** — **Epic F 自动化「真实路径」= A** |
| **B** | **固定 fixture + 真实 handler**（测试进程加载仓库内 fixture，请求命中 **非 mock** 的 API handler） | **❌ 不采用** 作为 F-08 **钉死**载体（可在**未来**另开 ADR 作为 CI 无链补充，**不得**替代本条对「真实状态机」的默认解释） |

**理由（摘要）**：**01 §9** 第一项 **正常放款** 依赖 **链上托管/释放** 与 **API 状态机** 同栈可观测；**本地链 + 本地 API** 与现有 **[Runbook §2.55 / §12.5](../../ops/RUNBOOK.md)**、**[110](../spec/110-阶段开发链上索引器与事件同步器.md)** 运维叙事一致，且避免将「真实路径」弱化为仅测 handler 而不触链。

---

## 2. 自动化覆盖哪一项、哪一条状态机

| 问题 | **钉死答案** |
|------|----------------|
| **三项中自动化先做哪一项？** | **仅** **「正常放款」**（对应留痕文件 **`e2e-normal-release.md`** / [F-02](./Epic-F-e2e-three-pack-ladder.md#epic-f-f02-e2e-artifacts)）。 |
| **状态机路径（等价叙述）** | **下单（或等价订单创建）→ 经托管/支付相关可达状态 → 正常释放/结算完成**（具体 REST/链上步骤以当次实现与 **04** 订单·托管段落为准；本 ADR **不**枚举易变路由名以免与代码漂移）。 |

**明确**：**争议三终态**、**三条超时路径** — **当前阶段不纳入本条「自动化钉死路径」**；见 **§4**。

## 3. 不得 mock 的范围（仅引用 · 改正文须另开 TT）

以下 **禁止** 在 **F-08 真实路径** 自动化中 **mock**、**桩掉** 或 **替换为假实现**（与 **[Epic F 全程硬边界](./Epic-F-e2e-three-pack-ladder.md#epic-f-全程硬边界)**、**[Epic D · F](./Epic-D-indexer-ops-readonly-ladder.md)** 一致）：

- **B-115**、**B-116**、**P5**（含 **P5-1～P5-5** 等已登记程序族）所涉 **链上读/投影/分配/导出** 等 **已封口语义路径**。
- **权威入口（只读引用，本 ADR 不修改正文）**：
  - **[04-后端与API · 硬边界与封口互指](../spec/04-后端与API.md)**（含 **B-115 / B-116 / P5**、**Epic** 封口句）。
  - **证据收口文档**（示例）：**`evidence/GO_P5_*_CLOSE.md`**、**`evidence/GO_B115_CLOSE.md`**、**`evidence/GO_B116_*`** 等 — 以仓库内实际 **GO_*** 文件名为准。
  - **缺口 / 母表**：**[缺口与待补-官方总表](../spec/缺口与待补-官方总表.md)**、**[任务母表](../任务母表.md)** 中 **B-115 / B-116 / P5** 行（索引用）。

**允许**：对 **非上述封口域** 的外部依赖（如第三方 KYC、地图、非本仓支付网关）按项目惯例 mock — **不得** 以此绕过 **§2** 所要求 **真实状态机** 的 **链 + API** 观测。

1. **哪条路径是「真实路径」？** → **本地链 + 本地 API**（**§1 选项 A**）。
