## 3. 场景表（桌面推演 · 四场景）

> **约定**：下列 **「预期」** 为 **讨论** **提纲** **，** **非** **单测** **断言** **；** **实链** **复现** **须** **独立** **环境** **与** **变更** **单** **。**

| ID | 故障画像 | 讨论要点（须覆盖） | 预期处置方向（口播级） |
|----|----------|-------------------|-------------------------|
| **S1** | **RPC 间歇超时 / 429 / 5xx**，`indexer-tick` **失败或空跑** | **`GET …/internal/indexer-status`** 中 **`last_block` / lag** 是否停滞；**tick** **503** **`reorg_suspected`** **vs** **纯 RPC 错** **区分**；是否 **暂停** **定时 tick** **直至** **RPC** **恢复** | **只读** **先**：**status** → **admin observability**（若已部署）；**不写** **回滚** **除非** **另** **Runbook** **条件** **满足** |
| **S2** | **RPC 可用但返回与配置不一致**（如 **chainId** **对不上**） | 与 **母表** **B-175** **叙事** **对齐**：**reconcile** **嵌套** **`rpc_chain_id_vs_config`** **类** **探针** **（** **见** **110/实现对读** **）**；**禁止** **在** **未** **确认** **配置** **前** **对** **生产** **批量** **rewind** | **先** **校** **`.env` / 密钥** **与** **`GET /meta`** **`chain_id`** **；** **再** **定** **是否** **切换** **端点** |
| **S3** | **finality 滞后**导致 **`awaiting_finality`** **或** **上界** **长期** **不** **前进** | **110 §3.3** **finality** **与** **`to_block`** **裁剪** **；** **业务** **是否** **可** **接受** **「** **投影** **滞后** **」** **只读** **展示** | **产品** **/ ** **值班** **共** **议** **是否** **公告** **延迟** **；** **索引** **侧** **通常** **不** **降** **FINALITY_N** **除非** **规格** **变更** |
| **S4** | **计划内切换** **备份** **`CHAIN_RPC_URL`** | **滚动** **重启** **顺序** **、** **回滚** **判据** **（** **新** **端** **错误率** **）** **；** **证据** **：** **可选** **`write-indexer-evidence.sh`** **快照** **路径** **（** **见** **RUNBOOK** **§2.55** **）** | **变更** **单** **+** **双人** **复核** **后** **再** **切** **；** **本** **桌面** **演练** **可** **仅** **走** **检查** **清单** **不** **真** **切** |
