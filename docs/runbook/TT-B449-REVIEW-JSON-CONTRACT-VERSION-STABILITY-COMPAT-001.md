## §1 · 三类分支下的字段合约矩阵（目标态 · 实现须与此一致）

**说明**：下表描述 **`review` 对象** **内** **与** **权重** **相关的** **三个** **键** **。** **`score`/`comment`/当事方** **id** **等** **不** **在本表** **展开** **（** **由** **P07** **其它** **TT** **约束** **）** **。** **若** **实现** **与** **下表** **冲突** **，** **以** **代码** **修正** **或** **经** **评审** **后** **更新** **本** **Runbook** **§1** **（** **须** ** bump** **文档** **版本** **）** **。**

### §1.1 分支定义

| 分支代号 | 场景（摘要） | 与现网机读关系（占位） |
|----------|--------------|------------------------|
| **A · 成功** | **首次** **提交** **评审** **成功** **，`review` **含** **本次** **计算** **的** **breakdown** | **无** **`db_pool`** **或** **`db_pool`** **且** **`insert_review` → `Ok(true)`** **均** **须** **满足** **§1.2** **成功** **列** **（** **B-447** **已** **约束** **两** **路径** **数值** **一致** **）** **。** |
| **B · 幂等** | **`db_pool`** **下** **重复** **提交** **，`insert_review` → `Ok(false)`** **且** **取回** **已** **存** **评审** **→** **HTTP** **200** | **与** **B-444** **一致** **。** |
| **C · 边界** | **订单** **金额** **/** **账龄** **等** **处于** **B-448** **已** **覆盖** **的** **边界** **，** **但** **HTTP** **路径** **仍为** **成功** **200** **（** **非** **错误** **体** **）** | **响应** **在** **`weight*`** **字段** **上** **须** **与** **分支** **A** **同** **一** **套** **存在性** **/** **`null`** **规则** **；** **数值** **细节** **由** **B-448** **/** **核心** **单测** **锚** **。** |

### §1.2 字段矩阵（目标契约）

| 分支 | **`weight`** | **`weight_breakdown`** | **`weight_breakdown_note`** |
|------|----------------|------------------------|-----------------------------|
| **A · 成功** | **必须** **出现** **；** **JSON** **number** **；** **有限** | **必须** **出现** **；** **JSON** **object** **（** **结构** **键** **集** **/** **顺序** **以** **B-448** **/** **`json_weight_breakdown`** **为准** **）** | **必须** **不出现** **（** **键** **省略** **；** **不得** **为** **`null`** **以免** **与** **分支** **B** **混淆** **）** **。** |
| **B · 幂等** | **必须** **出现** **；** **JSON** **number** **（** **来自** **持久化** **）** **；** **有限** | **必须** **出现** **且** **值为** **JSON** **`null`** **（** **不重放** **本次** **请求** **的** **分解** **）** | **必须** **出现** **；** **JSON** **string** **，** **当前** **枚举** **值** **为** **`persisted_review_inputs_not_replayed`** |
| **C · 边界** | 同 **A** | 同 **A** | 同 **A** |

**`null` 语义小结**：**成功** **与** **边界** **成功** **路径** **不得** **带** **`weight_breakdown_note`** **键** **；** **幂等** **路径** **须** **同时** **提供** **`weight_breakdown: null`** **与** **明示** **`weight_breakdown_note`** **字符串** **。**
