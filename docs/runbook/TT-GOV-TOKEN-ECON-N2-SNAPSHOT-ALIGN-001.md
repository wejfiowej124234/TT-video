## §1 · 锚点（固定）

对账 **必须** **声明** **且** **全程** **引用** **同一** **锚点**，避免 **「链上读在 B、投影读在 B+k」** **混为** **一次** **结论**。

### 1.1 主锚：`block_number`

- **来源**：**`chain_reads.json` → `block_number`**（**十进制** **整数**）。
- **语义**：**`cast`** **/** **RPC** **执行** **`totalSupply`** **/** **`balanceOf`** **时** **的** **参考** **块**（**与** **N1** **脚本** **实现** **一致**）。
- **证据**：**`chain_reads.json`** **须** **随** **N2** **证据包** **一并** **归档**（**可复制** **或** **SHA256** **引用**）。

### 1.2 辅锚（并列写出）

| 字段 | 用途 |
|------|------|
| **`chain_id`** | **与** **`GET /meta` → `chain.chain_id`** **对拍**（**须** **一致**） |
| **`timestamp`**（**Unix**） | **人机** **可读** **时间戳**；**不** **单独** **作为** **数值** **相等** **判据** |
| **`token`** | **TTG** **合约** **地址**（**与** **`GET /meta`** **/** **`.env`** **同源**） |

### 1.3 锚点冻结句（验收记录须粘贴）

> **本** **次** **N2** **对账** **锚点**：**`chain_id=<…>`**，**`block_number=<…>`**，**`chain_reads.json`=<路径或哈希>**。

## §5 · PASS / SUSPECT / FAIL

### 5.1 PASS

同时满足：

- **锚点** **§1** **已** **写明** **且** **与** **`chain_reads.json`** **一致**。
- **`total_supply`** **与** **`treasury_balance`** **在** **投影侧** **与** **N1** **字符串** **数值** **相等**（**或** **已** **文档化** **的** **wei** **舍入** **规则** **下** **相等**）。
- **索引器** **checkpoint** **与** **锚点** **块** **的** **关系** **符合** **§6**（**含** **「** **允许** **落后** **」** **条款** **）**。

### 5.2 SUSPECT

任一成立（**须** **在** **`n2_verdict.md`** **写** **原因**）：

- **投影** **落点** **未** **完全** **实现** **（** **仅** **地址** **/** **`chain_id`** **一致** **）**。
- **数值** **一致** **但** **checkpoint** **落后** **于** **§6.1** **上限** **仍** **在** **容忍** **内** **（** **见** **§6.2** **）**。
- **API** **声明** **「** **最新** **」** **且** **无法** **绑定** **到** **`block_number`** **（** **仅** **配置** **级** **一致** **）**。

### 5.3 FAIL

任一成立：

- **`chain_id`** **或** **TTG** **/** **金库** **地址** **与** **`chain_reads.json`** **/** **`.env`** **/** **`/meta`** **冲突**（**与** **N1** **并列** **时** **优先** **修** **配置** **）**。
- **`total_supply`** **或** **`treasury_balance`** **在** **可** **比较** **条件** **下** **明确** **不等** **且** **无** **已** **批准** **豁免** **说明**。
- **索引器** **checkpoint** **落后** **锚点** **超过** **§6.1** **硬** **上限** **且** **无** **计划** **内** **说明**。

## §6 · 允许延迟（索引器 / API）

### 6.1 块级延迟（建议默认 · 可 per-env 覆盖）

| 参数 | 建议默认值 | 说明 |
|------|------------|------|
| **`Δ_block_max`（软）** | **32** | **checkpoint** **≥** **`block_number`** **−** **32** **时** **允许** **标** **SUSPECT** **（** **若** **数值** **仍** **对齐** **）** **或** **PASS** **（** **若** **项目** **政策** **允许** **）** |
| **`Δ_block_max`（硬）** | **128** | **超过** **则** **不得** **标** **PASS** **（** **至少** **SUSPECT** **；** **数值** **漂移** **时** **FAIL** **）** |

**记录要求**：**`n2_snapshot.json`** **或** **并列** **日志** **须** **含** **索引器** **checkpoint** **块** **高** **（** **或** **等价** **字段** **）** **与** **`block_number`** **的** **差值**。

### 6.2 时间级延迟（辅助）

- **API** **响应** **时间** **与** **`chain_reads.json.timestamp`** **差** **> 15** **分钟** **时**：**在** **`n2_verdict.md`** **注明** **「** **观测** **时间** **窗** **」**；**不** **单独** **作为** **FAIL** **除非** **与** **链上** **重放** **冲突**。

### 6.3 与 N1 的时间顺序

- **推荐** **顺序**：**先** **冻结** **N1** **`chain_reads.json`**，**再** **拉取** **投影** **（** **同一** **运维** **窗口** **内** **）**。**若** **顺序** **相反**，**须** **在** **证据** **中** **说明** **并** **倾向** **SUSPECT**。
