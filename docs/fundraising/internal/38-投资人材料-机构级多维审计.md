## 0. 方法与边界（① 本地 / 文案与结构）

- **证据范围**：`docs/fundraising/external/`（01–06、00、04 storyboard、en/ 镜像）、`export-ready/` 机读产物说明、`internal/33` 导出纪律、`36` 设计系统、`ir_ic_appendix` IC 附录、`build-investor-pitch-deck` 主 Deck 逻辑；**未**对 PDF 像素级逐页开版、**未**做 **②③** 链上/生产数据核验。  
- **评分**：每维 **1–5 分**（5 = 同阶段机构材料中上；3 = 可用但需补强；1–2 = 显著缺口）。分数为**相对当前「未签核、NDA 数字外置」策略**下的合理性，不与已上市公司全套材料对标。  
- **与仓库纪律一致**：不宣称 **③** 生产/主网已验收；不将 **①** 本地绿或本审计当作法务签核替代。

## 2. 主要发现（缺口 · 漏洞 · 重复 · 弱表达）

### 2.1 缺口 / 漏洞（真实不一致或易误导）

| # | 现象 | 影响 |
|---|------|------|
| V1 | `export-ready/README.md` 曾写主 Deck **18 页**，与当前 **15 页** 及 storyboard 头部不一致 | **2026-05** 已与 **15p** / README 主表对齐；本条保留为历史根因记录 |
| V2 | **en/00-README.md** 主表曾缺少 **`04-IC-Memo`** 独立行（与 CN **04b**、`00-START-HERE` 不对称） | **2026-05-15** 已补 **04b** 行并与 Demo 默认读序表述对齐 |
| V3 | **07** 无独立对外 `.md` 成稿，叙事依赖脚本内 brief | 部分基金要求「可 diff 的 Tokenomics 单一 Markdown 真源」时被动 |

### 2.2 重复（信息经济学角度）

- **主链六步 / 子系统表**：在 **01、03、05、06、04 长文章节、Deck、07 图** 多次出现——**正确**的重复是「记忆锚」，**负**重复是同一句话无增量（例如「不是发币项目」可在 **03 保留**，在 **06 摘要** 缩为半句指回 03）。  
- **100/45/55 与分母正交**：02、05、06、Deck、IC 附录均出现——建议保留 **06 一处最完整**，其余用 **「见白皮书 §06」** 级交叉引用缩短（P1）。

### 2.3 弱表达 / 不够「诱人」（在合规约束下的可改进空间）

- **投资故事缺「时间压缩的胜利」**：可在**不讲数字**前提下，增加「若 12–18 个月执行顺利，行业默认指标会动哪一根」（定性，如争议处理成本、供给复购）— 见 P2。  
- **Why Win**：偏「我们在做什么」；缺一句 **「因此谁能输掉更少 / 谁能更快规模化」** 的零和/结构判断（仍可不点名竞品）。  
- **Demo**：若视频与 Deck 不同步更新，叙事张力会断层 — 在 **33** 或 **19** 增加「Demo 与 Release 对拍」勾选项（P1）。

## 4. 结论（给维护者的一句）
