## 用途

记录 **谁、在何时、以何种媒介、收到哪一类资料**（含 Data Room 临时链接、PDF 包、会议只读材料），满足企业级 **最小留痕** 与事后审计。

## 单次外发流程（①）

| 步 | 动作 |
|----|------|
| 1 | `bash scripts/gates/ir-preview-send-preflight.sh`（或分步：`ir-outbound-status` + `release-investor-lp-pack`） |
| 2 | 确认 zip 为当次 `release`（preflight 会提示 PDF 是否新于 zip） |
| 3 | [IR-PRE-SEND-MANUAL-001](../IR-PRE-SEND-MANUAL-001.md) 勾选（preview 邮件见 **§7**） |
| 4 | 发送 **仅** `dist/TravelTrust-Investor-Materials-v{release}.zip`（或书面批准的单 PDF） |
| 5 | 下表 **新增一行**（实值）；跨境同步 [board/distribution-log.md](../board/distribution-log.md) |

## 规则

1. **签核前**材料不得登记为「已对外定稿」；状态须标注 `draft` 或「预览」。
2. **Data Room** 链接若带时效，须在备注写 **失效日期**。
3. 与 **cap table、未审计财务** 相关行，须注明 **仅限 NDA 下**。
