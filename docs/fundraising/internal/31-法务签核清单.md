## 签核项（逐项 □）

| □ | 项 | 说明 |
|---|----|------|
| ☐ | **对外披露包一致** | 收益流、证券隔离、分红/治理币绑定、Pause/冻结等措辞与已定稿对外披露包一致或已同步升版 |
| ☐ | **MVP 边界一致** | 不发行平台支付币、结算币种、Escrow 与治理代币关系表述一致 |
| ☐ | **中英版本对齐** | `06-Whitepaper.md` 与 `en/05-Litepaper.md` 同日版本号、无语义矛盾 |
| ☐ | **禁止性表述已审** | 无保本、无固定收益承诺、无不实证券表述 |
| ☐ | **发布渠道登记** | 固定 URL 或文档路径已登记（官网/投资者门户等） |
| ☐ | **FeeRouter 数字** | 对外材料仅使用已定稿的 **45%/55%** 与 Global **65/20/15**（或法务批准等价表述）；不得使用已废止分账叙事 |
| ☐ | **可分配费用分母与正交** | **45%/55%** 仅相对进入费路由器的可分配订单手续费；**不得**将 gas、仲裁费、向导履约罚没与 45/55 混为同一分子而无脚注 |
| ☐ | **TTG 激励 vs 证券隔离** | 若描述 TTG 参与协议费分配，须含 Howey 类风险披露；禁止固定收益/股息/股权表述（除法务书面结论） |
| ☐ | **Country Pool / RegionShare** | 募资页须含**非股权、收益不保证**等价措辞 |
| ☐ | **收益流图示** | 若含手续费分配图，须与法务批准的 FeeRouter 图示一致；图示旁标注 gas/仲裁/slash 不在本图分母内（或等价脚注） |
| ☐ | **产品与对外稿一致** | App/网站治理相关展示不得暗示「页面数字即链上真值」或越权承诺 |
