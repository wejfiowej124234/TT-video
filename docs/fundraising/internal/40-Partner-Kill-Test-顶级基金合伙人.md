## 0. 方法：三个阅读窗口里 Partner 实际「看到什么」

**模拟对象**：顶级基金 **Partner** 合成视角（a16z / Sequoia / Paradigm / Coinbase Ventures 的**交集**——增长、品牌、监管、链上原语、交易所生态各自权重不同，**拒投理由**在交集上往往更狠）。

| 窗口 | 典型行为 | 材料范围（按你们当前包） |
|------|----------|---------------------------|
| **30 秒** | 封面 + 快速扫标题与图；Demo 若自动播则瞟 5–10 秒 | 主 Deck **第 1–2 页** + 矢量缩略印象 + **Demo 首帧** |
| **3 分钟** | 顺序翻完主 Deck 或跳读矢量/费/矩阵 | 主 Deck **15 页**走一遍（约 12s/页） |
| **10 分钟** | 主 Deck + IC Memo 扫读 + 白皮书目录/摘要 + Demo 片段 | **15p + IC 8p + 06 摘要/目次 + 2–3 min Demo** |

**Kill 目标**：以「**为什么不投**」为默认结论，记录**第一反应拒投点**与**故事断裂**。

## 1. 分窗口：第一反应拒投点 & 故事断裂

### 1.1 三十秒（「电梯误杀」）

| 现象 | Partner 脑内旁白 | 类型 |
|------|------------------|------|
| 封面像 **通用 infra + travel** 组合 | 「又一个 trust layer」 | 无聊 / 品类疲劳 |
| 第 2 页 **长串能力词**无数字 | 「没有 traction hook，我为什么要翻下去」 | **第一反应拒投** |
| Demo **占位或弱制作** | 「产品证据链没准备好就来见 Partner」 | **可信度致命** |
| **无公司/轮次/金额**（有意省略则正常） | 「不知道是啥轮、啥估值、啥条款」— 30s 内直接 **defer** | 信息空洞（非错，但 Kill） |

**故事断裂**：30s 内**没有把「非发币旅行项目」钉进视觉**（仅靠文字则 Partner 会默认 **Web3 travel coin**）。

---

### 1.2 三分钟（「Deck 速杀」）

| 现象 | Partner 脑内旁白 | 类型 |
|------|------------------|------|
| **第 4–5 页**双矢量连续 | 「图很漂亮，**链上证据**呢？」 | 可信度 / **无聊页风险**（若口述缺席） |
| **第 13 页** 竞争矩阵（Web2 / 链上对照） | 「像 MBA slide，**差异化可执行**在哪」 | 无聊 / 泛 |
| **第 8 页** 可演示但无环境 UI | 「说了 demo，**是不是 staging**？」 | 可信度 |
| **第 9 页** 系统性优势 vs 第 4–5 | 「**重复**主链叙事，信息增量低」 | **无聊页** |
| **第 10 页** FeeRouter（披露边界） | Paradigm/CB：**「钱从哪来、谁付」**仍悬空；Sequoia：**「单位经济」**看不到 | **价值捕获疑点** |
| **第 6、11、12 页**（Why now / 路线图 / GTM） | 「全是定性；** wedge 市场**一句没有」 | **市场怀疑** |
| **第 13 页** 竞争矩阵 | 「**OTA 18 个月抄你**」防御未在 3 分钟内建立 | **竞争压力** |
| **第 15 页** 收口 | 「**NDA** 出现第三次了」 | 故事断裂（推 NDA 像没干货） |

---

### 1.3 十分钟（「IC + 白皮书 + Demo」）

| 材料 | Partner 脑内旁白 | 类型 |
|------|------------------|------|
| **IC Memo** | 「Why Now / Why Us 与主 Deck **高度同构**」— 增量若不足则 **IC 页白读** | 重复 / 无聊 |
| **IC 结论槽位** | a16z：**「结论框架不是结论」**；若前面无数字仍 **难进 IC** | Token/股权叙事仍弱 |
| **Whitepaper** | 「长、合规、**读税高**；兴奋点在 **§10 以后** 才起来」 | 无聊 / 疲劳 |
| **Demo** | brief 仍允许占位 → **「为什么不投」直接 +1** | 产品演示不足 |

**故事断裂**：主 Deck 说 **「双栖可嵌入」**，白皮书 **§09–10** 才展开 — **3 分钟窗口根本读不到**，Partner 脑中 **「嵌入案例」为空**。

## 2. 按基金「偏置」的额外一刀（仍合成在 Partner 一人）

| 基金文化偏置 | 多出来的 Kill 点 |
|--------------|-------------------|
| **a16z** | 要 **「为什么你能做大平台」**；公开层缺 **密度/网络效应数据** → 易 **「respectful pass」** |

| **Paradigm** | 要 **链上原语与价值累积**；TTG **可选** + 费 **L1 only** → **「crypto 回报故事薄」** |
| **Coinbase Ventures** | 合规与 **零售触达**敏感；**KOL/披露**若口述不慎 → **合规警觉** |

## 3. 一句话致命问题（Partner 可直接甩出）

以下任一答不好，**当场进入「谢谢分享」模式**：

1. **「过去 90 天，哪一个指标你们敢用名誉担保——不必公开，口头一句？」**（你们策略是 NDA → Partner 预期 **口头仍要有锚**）  
2. **「若 TTG 永不发行，你们靠什么在 5 年里让股东级回报成立？」**  
3. **「给我一笔**非团队**资金在链上的**托管—释放**闭环：环境、地址、浏览器链接。」**  
4. **「GetYourGuide / Airbnb 加 Stripe Connect 和争议团队，你们**哪三条**在 12 个月内**不可复制**？」**  
5. **「你们第一个**必须打赢**的地理或品类 wedge 是什么——不能说『全球』。」**

## 4. 按杀伤力排序：**Top 10 Kill Reasons**

| 排名 | Kill Reason | 典型基金反应 | 主关联材料 |
|------|-------------|--------------|------------|
| **K1** | **无 traction 数字锚**（公开策略下） | 「故事正确，**证据不足**，不占用 IC」 | Deck 2–3、8、11；06 摘要 |
| **K2** | **Demo 不能证明真钱/真用户** | 「**产品演示不足** = 默认未就绪」 | Demo mp4 / brief |
| **K3** | **旅游 × Crypto 双高难度**默认降权 | 「要**异常强**的 wedge；你们还在讲全栈」 | GTM、Why now |
| **K4** | **价值捕获 = 可分配费**，但**采用未证** | 「**费路由是结果不是起点**」 | FeeRouter、06 §06 |
| **K5** | **TTG 可选** → Token 基金问「**那 crypto 仓位理由**」 | **Token 不成立点**（对纯 token mandate） | 06、IC |
| **K6** | **竞争：OTA + 支付 + 争议外包**可复制叙事 | 「**护城河在 PPT 里不在合同里**」 | 竞争矩阵、06 §03附 |
| **K7** | **矢量页信息量大、证据量低** | 「**无聊 + 炫技**」风险 | 第 4–5 页 |
| **K8** | **「全在 NDA」疲劳** | 「**可信度问题**：是不是在藏坏消息」 | 6、11–12、15 |
| **K9** | **IC Memo 与主 Deck 同构** | 「**10 分钟没有新增信息**」 | IC 2–4 vs Deck |
| **K10** | **白皮书长 + 免责密** | 「**读不完 = 不兴奋**」 | 06 开篇节奏 |
