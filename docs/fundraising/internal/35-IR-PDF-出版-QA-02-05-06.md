## 工具链已做修补（仍须人工翻页确认）

- **目录**：`toc: false` + **`ir-native-toc.lua`** 将目录写成**可见列表与内链**（LibreOffice 不展开 Word `TOC` 域时 PDF 不再空白）；免责声明标题 `{.unnumbered .unlisted}` **不列入**目录条目；正文编号仍由 `numbersections` 起算。
- **版式顺序**：封面 → **目录** → **免责声明** → 正文（由 native-toc 与前置分页块拼装）。
- **表格**：首行标记 **`w:tblHeader`**，跨页时尽量**重复表头**（取决于 LO 渲染）。
- **标题悬底 / 孤行**：导出后对 **Heading*** 统一 `keep_with_next` / `keep_together` / `widow_control`；对 **Normal** 等开 `widow_control`。
- **封面与首页**：`reference-ir.docx` 使用「首页不同」页眉页脚；**装订顺序**：封面（仅标题）→ 目录 → 免责声明 → 正文。

## 每份 PDF 通用检查（逐页）

- [ ] **封面**：标题/副标题居中、品牌色清晰；封面**无**页眉页脚条。
- [ ] **法律免责声明**：全文可读；**语言版本**主免责语文与材料语言一致（中英对照块顺序符合 CN/EN 构建）。
- [ ] **目录**：「目录 / Contents」；**不含**免责声明条目；层级与正文 **H1–H3** 一致；无空项。
- [ ] **页眉**：正文段 `TravelTrust` + IR + Confidential；与封面/目录叠放观感可接受。
- [ ] **页脚**：页码连续 + `General information only — not an offer`。
- [ ] **章节首页**：05/06 在 **`##` 两位数字章**（含 `03附`）前有分页。
- [ ] **标题与紧随段落**：无明显「标题在页底、正文在下一页」的悬底。
- [ ] **正文**：混排无缺字；行距/段距均匀。
- [ ] **引用框**：`Quote` 样式一致。
- [ ] **表格**：宽表不裁切；**跨页**处有表头或至少不断裂成单字行。
- [ ] **分页**：无表格仅一行孤立在次页；列表无断头露尾。
