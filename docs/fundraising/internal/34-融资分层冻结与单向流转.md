## 1. 分层（已冻结，后续只增不改层界）

| 路径 | 定性 | 谁能看 |
|------|------|--------|
| **`docs/fundraising/internal/`** | **团队内部融资工作仓**：决策、台账、工作包、会议模板、BD、制作指南、导出与审阅清单、Data Room **索引**（非正文搬运） | 团队 + 授权职能（法务/财务等） |
| **`docs/fundraising/external/`** | **唯一投资人对外交付仓**：可直接导出给投资人的叙事与材料源（[33](33-投资人Data-Room导出包与IR法务终审清单.md)） | 投资人 / 路演 / 初阶 DD（通过导出包，**不**开整仓） |
| **`data-room/`、`legal/`、`board/`** | 原件、法档、分发与投后 **运维/索引** | **非**投资人默认包内目录；与 `internal/` 同属「不对外导出」侧 |

新增融资类 Markdown：**先判定受众**——只给团队 → `internal/`（或与本冻结一致的运维目录）；给投资人 → **只**放 `external/`（中英维护 `en/`）。

## 2. 禁止重复正文（单一叙事真源）

- **投资人向事实叙事、路演口径、白皮书/Litepaper/FAQ/Deck 叙事**：**`external/` 独占**正文；`internal/` **不得**再贴一份同职能长文（避免双真源）。
- **过程类、决策表、任务母表、渠道复盘、会议纪要、DD 索引**：**`internal/` 独占**；**不得**把会议纪要、内部定损结论整段贴入 `external/`。
- **允许**：`internal/` 用 **一行指针** 指向 `external/` 某文件（「对外叙事见 …」）；**禁止**：把 `external/06` 全文复制进 `internal/` 当「内部白皮书」——应链向 `external/` 或引用 `docs/spec/` 工程真源（数字仍以 spec 与 registry 维护侧为准）。

## 3. 禁止跨层回流

- **外 → 内回流**：禁止将 **`external/` 正文再拷贝回 `internal/`** 作为「内部版 SSOT」替代工程或地图——内部若需对齐对外，**只更新 `external/`** 或 **在 internal 写差分/待办**，不双份存正文。
- **内 → 外回流**：禁止将 **`internal/`** 工作稿、签核清单全文、Data Room 运维段落 **粘贴进 `external/`**；对外所需信息应 **改写**为投资人可读句并落在 `external/` **唯一处**。
- **`docs/spec/`**：协议与参数真源 **仍属 spec**；`external/` 只可 **叙事一致**，不得在对外文中写 **`docs/spec/...` 路径**（现有门禁已拦）。

## 4. 机读闸（与你的纪律一致）

- `scripts/gates/check-fundraising-ir-governance.py`：**`external/`** 不得含内部路径泄漏，且 **Markdown 链接不得指向** `internal/`、`board/`、`data-room/`、`legal/`。
- `scripts/tools/export-investor-dataroom.py`：**仅**复制 `external/` 为投资人包。

## 5. 修订本条款

解冻或改层界须：**Owner + 法务/IR 书面共识**，并同步改 **00 地图**、**本页 Version/Status**、门禁（若有新路径）。

**基础设施收盘**（见 **§6**）期间：新增机读闸、导出步骤、registry 轨道等，**视同**扩展文档基础设施，须先履行 **§6** 解冻程序，再适用本条。

## 6. 基础设施收盘（不再扩展）

融资文档体系已达 **内部融资与机构沟通可用基线**（自评约 85/100 量级，**非**生产或法律闭包）。**后续不再立项扩展**文档基础设施。

- **对外**：一律使用 [33 — 投资人 Data Room 导出与 IR+法务终审](33-投资人Data-Room导出包与IR法务终审清单.md) 生成的目录或 **zip**，**不**以整仓代替交付物。
- **迭代**：仅通过 **真实法务签核、投资人反馈、实际分发与 Data Room 流程** 驱动；日常以修订 **`external/` / `internal/` 正文** 及 [19](19-对外分发与访问登记.md) / [board](../board/README.md) 登记为主。

解冻「不再扩展」须：**Owner + 法务/IR 书面共识**，并更新 **本页 Version/Status**、根 [README](../README.md)「后续口径」段与 **00 地图**。
