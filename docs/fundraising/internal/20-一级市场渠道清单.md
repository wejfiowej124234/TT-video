## 先说结论：一级市场不是一个网站，而是一组融资与发售渠道

在 Web3 里，大家口中的“一级市场”通常不是单一地方，而是几类渠道的集合：

1. Launchpad / 发售平台
2. 交易所早期发售入口
3. 社区型募资平台
4. 私募 / 机构 / 天使网络
5. 项目自建承接页 + 社区 + 白名单体系

所以产品经理的工作，不是只找一个平台去上，而是先把渠道地图和资料包建立起来。

## 这 10 个渠道，产品经理分别要研究什么

不是只记住名字和网址，而是至少研究下面这些：

1. 平台主要面向哪类项目。
2. 它更像募资入口、曝光入口还是社区承接入口。
3. 它通常需要什么资料。
4. 它对项目阶段有什么要求。
5. 它对法域、KYC、合规有什么限制。
6. 它更看重项目叙事、社区热度、真实产品，还是交易所关系。

## PM 在一级市场这件事上具体要做什么

### 一、建立渠道地图

1. 先把目标渠道分门别类。
2. 标出每个渠道的官网、类型、特点。
3. 标出适配度高低。

### 二、建立资料包

1. 把官网、Deck、One Pager、FAQ、视频、社媒链接整理成可投递版本。
2. 做中英文两个版本的准备。
3. 确保所有资料都和当前真实边界一致。

### 三、建立缺口清单

1. 哪些资料我们已经有。
2. 哪些资料不完整。
3. 哪些资料完全没有。
4. 谁负责补齐。

### 四、建立优先级顺序

1. 先研究最头部、最常见的渠道。
2. 再研究更匹配项目阶段的渠道。
3. 不要一上来同时冲所有平台。

## 低标准和高标准的区别

### 低标准

- 只知道几个平台名字
- 只会说想上一级市场
- 没有资料包
- 没有官网和链接总表
- 没有渠道优先级

### 高标准

- 有完整渠道清单
- 有标准投递资料包
- 有中英文材料
- 有承接页和社媒矩阵
- 有缺口表和推进表

## 最后一句话

在这个项目里，一级市场不是“以后再说”的工作，而是这位产品经理必须提前准备好的外部融资与渠道体系。她要做的不只是写融资方案，而是把“资料、渠道、承接、内容、社区、平台”全部串起来。
